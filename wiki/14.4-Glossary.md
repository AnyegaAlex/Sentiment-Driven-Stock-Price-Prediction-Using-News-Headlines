## Overview

This glossary provides definitions for key terms used throughout the Tickflow documentation. Terms are organized by category: financial, technical, machine learning, and acronyms.

---

## Financial Terms

### Bollinger Bands
A technical indicator that consists of a moving average and two standard deviation bands above and below it. Used to measure market volatility. The bands widen during high volatility and narrow during low volatility.

### Bullish
A market sentiment indicating that prices are expected to rise. Bullish sentiment is associated with positive news, strong earnings, or overall market optimism.

### Bearish
A market sentiment indicating that prices are expected to fall. Bearish sentiment is associated with negative news, weak earnings, or overall market pessimism.

### Moving Average (MA)
A technical indicator that calculates the average price of a security over a specific number of periods. Used to identify trends and potential support/resistance levels.

**Types:**
- **SMA (Simple Moving Average):** Equal weighting of all prices in the period
- **EMA (Exponential Moving Average):** More weight given to recent prices

### Resistance Level
A price level where selling interest is strong enough to prevent the price from rising further. When price approaches resistance, it often reverses downward.

### RSI (Relative Strength Index)
A momentum oscillator that measures the speed and change of price movements. RSI ranges from 0 to 100.

| RSI Value | Interpretation |
|-----------|----------------|
| > 70 | Overbought (potential sell signal) |
| 50 - 70 | Bullish momentum |
| 30 - 50 | Bearish momentum |
| < 30 | Oversold (potential buy signal) |

### Sentiment Score
A numerical value that represents market sentiment based on news analysis. Ranges from -1.0 (very negative) to +1.0 (very positive).

| Score Range | Sentiment Label |
|-------------|-----------------|
| > 0.2 | Positive (Bullish) |
| -0.2 to 0.2 | Neutral |
| < -0.2 | Negative (Bearish) |

### Support Level
A price level where buying interest is strong enough to prevent the price from falling further. When price approaches support, it often bounces upward.

### Technical Indicator
A mathematical calculation based on historical price, volume, or other data. Used to analyze market trends and make predictions.

### Volatility
A measure of how much the price of a security fluctuates over time. High volatility indicates large price swings; low volatility indicates stability.

## Technical Terms

### API (Application Programming Interface)
A set of rules and protocols that allows different software applications to communicate with each other. Tickflow's API enables programmatic access to stock data, predictions, and analysis.

### API Key
A unique identifier used to authenticate API requests. Tickflow uses API keys for external access with rate limiting and usage tracking.

### Backend
The server-side portion of an application that handles data processing, business logic, and API responses. Tickflow's backend is built with Django and Django REST Framework.

### Cache
A temporary storage layer that stores frequently accessed data to improve performance. Tickflow uses Redis for caching API responses, database queries, and session data.

### CORS (Cross-Origin Resource Sharing)
A security mechanism that allows restricted resources on a web page to be requested from another domain. Tickflow configures CORS to allow frontend access.

### Endpoint
A specific URL path that corresponds to a particular API resource. For example, `/api/v1/stock-analysis/` is an endpoint.

### Frontend
The client-side portion of an application that users interact with directly. Tickflow's frontend is built with React and Vite.

### JSON (JavaScript Object Notation)
A lightweight data interchange format that is easy for humans to read and write and easy for machines to parse and generate. Tickflow uses JSON for API requests and responses.

### JWT (JSON Web Token)
A compact, URL-safe token that represents claims between two parties. Tickflow uses JWT for frontend authentication.

| JWT Component | Description |
|---------------|-------------|
| **Header** | Algorithm and token type |
| **Payload** | Claims (user ID, expiry) |
| **Signature** | Verifies token integrity |

### Middleware
Software that sits between the request and response in a web application. Tickflow uses middleware for authentication, rate limiting, logging, and CORS.

### Rate Limiting
A technique that limits the number of requests a client can make to an API within a specific time period. Tickflow uses rate limiting to prevent abuse.

### Swagger
A tool for designing, building, and documenting REST APIs. Tickflow uses Swagger (via drf-spectacular) for interactive API documentation.

## Machine Learning Terms

### Accuracy
A performance metric that measures the proportion of correct predictions among all predictions made.

**Formula:** `(TP + TN) / (TP + TN + FP + FN)`

### Confidence Score
A measure of how certain the model is about its prediction. Ranges from 0% to 100%. Higher confidence indicates stronger model conviction.

### Drift Detection
The process of identifying when a model's performance has degraded over time due to changes in data distribution. Tickflow monitors drift to trigger model retraining.

### F1 Score
A performance metric that balances precision and recall. It is the harmonic mean of precision and recall. More useful than accuracy for imbalanced datasets.

**Formula:** `2 * (Precision * Recall) / (Precision + Recall)`

### FinBERT
A variant of BERT (Bidirectional Encoder Representations from Transformers) fine-tuned on financial news for sentiment analysis. Tickflow uses FinBERT for sentiment scoring.

### Hybrid Model
A model that combines multiple approaches. Tickflow uses a hybrid model combining LSTM, sentiment analysis, and technical indicators.

### LSTM (Long Short-Term Memory)
A type of recurrent neural network designed to handle sequential data and capture long-term dependencies. Tickflow uses LSTM for stock prediction.

### Model Drift
The degradation of a model's performance over time due to changes in data distribution or market conditions.

### Precision
A performance metric that measures the proportion of true positive predictions among all positive predictions.

**Formula:** `TP / (TP + FP)`

### PyTorch
An open-source machine learning framework. Tickflow uses PyTorch for the LSTM model.

### Recall
A performance metric that measures the proportion of actual positive cases correctly identified.

**Formula:** `TP / (TP + FN)`

### scikit-learn
An open-source machine learning library for Python. Tickflow uses scikit-learn for performance metrics and ML utilities.

### Sentiment Analysis
The process of determining the emotional tone behind a text. Tickflow uses FinBERT for sentiment analysis of financial news.

### Transformer
A deep learning architecture used for natural language processing. FinBERT is based on the transformer architecture.
