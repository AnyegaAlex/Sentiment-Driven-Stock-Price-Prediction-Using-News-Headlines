# 3.4 News and Sentiment API

**File:** `/wiki/3.4-News-Sentiment-API.md`

---

## Overview

The News and Sentiment API provides access to financial news articles with sentiment analysis for a given stock symbol. The endpoint retrieves news from multiple sources, performs sentiment analysis using FinBERT, and returns structured data with sentiment scores, confidence levels, and source reliability rankings.

---

## Endpoint

**Method:** `GET`

**URL:** `/api/v1/news/get-news/`

**Authentication:** Required (API Key or JWT)

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `symbol` | string | Yes | — | Stock ticker (e.g., AAPL, TSLA) |
| `refresh` | boolean | No | `false` | Force refresh from source, bypassing cache |

---

## Request Examples

### curl

```bash
curl -H "X-API-Key: your_api_key_here" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/news/get-news/?symbol=AAPL&refresh=false"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/news/get-news/"
headers = {"X-API-Key": API_KEY}
params = {
    "symbol": "AAPL",
    "refresh": False
}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";
const url = new URL("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/news/get-news/");
url.searchParams.append("symbol", "AAPL");
url.searchParams.append("refresh", "false");

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

## Response Schema

### Top-Level Fields

```json
{
  "success": true,
  "data": {
    "symbol": "AAPL",
    "news": [
      {
        "id": "abc123",
        "title": "Apple Reports Strong Earnings",
        "summary": "Apple Inc. reported Q3 earnings...",
        "source": "Reuters",
        "source_reliability": 85,
        "published_at": "2026-07-24T10:00:00Z",
        "sentiment": "positive",
        "confidence": 0.92,
        "key_phrases": ["iPhone sales", "earnings beat"],
        "url": "https://example.com/article",
        "banner_image_url": "https://example.com/image.jpg"
      }
    ],
    "count": 10,
    "refresh_queued": false,
    "cache_stale": false
  },
  "code": 200,
  "timestamp": "2026-07-24T10:00:00.123456Z"

```

---

### Field Descriptions

#### Top-Level Fields

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | string | Stock ticker |
| `news` | array | List of news articles with sentiment |
| `count` | integer | Total number of articles returned |
| `refresh_queued` | boolean | Whether a background refresh was queued |
| `cache_stale` | boolean | Whether the cache data is stale |

#### News Article Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique article identifier |
| `title` | string | Article headline |
| `summary` | string | Article summary or description |
| `source` | string | News source name (e.g., Reuters, Bloomberg) |
| `source_reliability` | integer | Reliability score (1-100) based on source trustworthiness |
| `published_at` | string | ISO 8601 timestamp of publication |
| `sentiment` | string | Sentiment classification: `positive`, `negative`, or `neutral` |
| `confidence` | float | Confidence score (0.0 to 1.0) for the sentiment classification |
| `key_phrases` | array | Extracted key phrases from the article |
| `url` | string | URL to the original article |
| `banner_image_url` | string | URL to the article's banner image (if available) |

## Sentiment Scoring

Sentiment is classified using FinBERT, a pre-trained transformer model fine-tuned on financial news.

### Classification Rules

| Sentiment Score | Classification |
|-----------------|----------------|
| > 0.2 | Positive |
| -0.2 to 0.2 | Neutral |
| < -0.2 | Negative |

### Confidence Interpretation

| Confidence | Interpretation |
|------------|----------------|
| > 0.8 | High confidence |
| 0.6 - 0.8 | Moderate confidence |
| < 0.6 | Low confidence |

---

## Source Reliability Ranking

Source reliability is scored on a scale of 1 to 100, based on the credibility and accuracy history of the news source.

| Reliability Score | Tier | Sources |
|-------------------|------|---------|
| 80-100 | Tier 1 | Reuters, Bloomberg, CNBC, Wall Street Journal, Financial Times |
| 50-79 | Tier 2 | Yahoo Finance, MarketWatch, Seeking Alpha |
| 1-49 | Tier 3 | Less established sources, blogs |

---

## Cache Behavior

The endpoint uses Redis caching to improve performance and reduce external API calls.

| Scenario | Behavior |
|----------|----------|
| Cache hit (data < 30 min old) | Returns cached data immediately |
| Cache hit (data > 30 min old) | Returns cached data and queues background refresh |
| Cache miss | Fetches fresh data from external sources |
| `refresh=true` | Bypasses cache and fetches fresh data |

---

## Data Sources

The endpoint aggregates news from multiple sources:

| Source | Type | Reliability |
|--------|------|-------------|
| Alpha Vantage | Primary | High |
| Finnhub | Secondary | Medium |
| Yahoo Finance | Fallback | Medium |

### Fallback Chain

1. Try Alpha Vantage first
2. If Alpha Vantage fails, try Finnhub
3. If Finnhub fails, try Yahoo Finance
4. If all sources fail, return cached data with `cache_stale: true`

## Error Scenarios

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| 400 | 2001 | Missing `symbol` parameter |
| 400 | 2002 | Invalid `symbol` format |
| 401 | 1001/1002 | Invalid or missing API key |
| 429 | 3001 | Rate limit exceeded |
| 500 | 9003 | External API error (data source unavailable) |

### Example Error (External API Failure)

```json
{
  "success": false,
  "error": "External API error. Data source unavailable.",
  "code": 9003,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.
