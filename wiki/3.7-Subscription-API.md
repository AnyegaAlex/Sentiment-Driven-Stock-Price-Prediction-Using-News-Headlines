# 3.7 Subscription API

**File:** `/wiki/3.7-Subscription-API.md`

---

## Overview

The Subscription API allows users to subscribe their email address to receive notifications, alerts, and updates from Tickflow. This endpoint is used for newsletter signups, alert notifications, and marketing communications.

---

## Endpoint

**Method:** `POST`

**URL:** `/api/v1/subscribe/`

**Authentication:** Required (API Key or JWT)

---

## Request Body

The request body must be JSON with the following structure:

```json
{
  "email": "user@example.com"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `email` | string | Yes | Valid email address to subscribe |

---

## Request Examples

### curl

```bash
curl -X POST \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com"}' \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/subscribe/"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/subscribe/"
headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
}
data = {"email": "user@example.com"}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";

fetch("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/subscribe/", {
  method: "POST",
  headers: {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ email: "user@example.com" })
})
.then(response => response.json())
.then(data => console.log(data));
```

## Response Schema

### Success Response (New Subscription)

```json
{
  "success": true,
  "message": "Subscribed successfully.",
  "code": 201,
  "timestamp": "2026-07-24T10:00:00.123456Z"
}
```

### Success Response (Reactivated Subscription)

```json
{
  "success": true,
  "message": "Subscription reactivated.",
  "code": 200,
  "timestamp": "2026-07-24T10:00:00.123456Z"
}
```

### Error Response

```json
{
  "success": false,
  "error": "Email already subscribed.",
  "code": 4002,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

---

## Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request succeeded |
| `message` | string | Human-readable status message |
| `code` | integer | HTTP status code or error code |
| `timestamp` | string | ISO 8601 timestamp of the response |
| `request_id` | string | Unique request identifier (error responses only) |

---

## Subscription States

| State | Description | HTTP Status |
|-------|-------------|-------------|
| New Subscription | Email not previously subscribed | 201 |
| Reactivated | Email was previously unsubscribed, now reactivated | 200 |
| Already Active | Email is already subscribed and active | 400 |

---

## Email Validation

The endpoint validates email addresses using Django's built-in email validation.

**Valid formats:**
- `user@example.com`
- `user.name@domain.com`
- `user+tag@domain.com`

**Invalid formats:**
- Missing @ symbol
- Missing domain
- Invalid characters
- Empty email

## Error Scenarios

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| 400 | 2001 | Missing email parameter |
| 400 | 2004 | Invalid email format |
| 400 | 4002 | Email already subscribed and active |
| 401 | 1001/1002 | Invalid or missing API key |
| 429 | 3001 | Rate limit exceeded |
| 500 | 9001 | Internal server error |

## Usage Notes

### Idempotency

The subscription endpoint is idempotent. Multiple requests with the same email will:

1. First request: Create a new subscription (201)
2. Subsequent requests with active subscription: Return already subscribed error (400)
3. Subsequent requests with inactive subscription: Reactivate subscription (200)

### Unsubscription

To unsubscribe, users should use the unsubscribe link provided in email communications. Direct API unsubscription is not currently supported through this endpoint.

### Email Notifications

Subscribed users will receive:
- Weekly market summaries
- Price alerts (if enabled)
- News alerts (if enabled)
- Product updates and announcements

---

## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.
