## Overview

This page provides solutions for common issues encountered when using or deploying Tickflow. It covers database, CORS, rate limiting, API key, authentication, and frontend issues. Use this page as a quick reference for troubleshooting.

## Database Issues

### Issue: Database Connection Failed

**Error:** `could not connect to server: Connection refused`

**Cause:**
- PostgreSQL service is not running
- Incorrect database credentials
- Database host is not accessible

**Diagnosis:**
```bash
# Check if PostgreSQL is running
# macOS:
brew services list | grep postgresql

# Linux:
sudo systemctl status postgresql

# Check connection string
echo $DATABASE_URL
```

**Solutions:**

1. **Start PostgreSQL:**
   ```bash
   # macOS:
   brew services start postgresql@16

   # Linux:
   sudo systemctl start postgresql
   ```

2. **Verify credentials:**
   - Check `DATABASE_URL` in `.env`
   - Ensure database exists: `psql -U postgres -l`
   - Verify user permissions: `psql -U tickflow_user -d tickflow_db -c "\l"`

3. **Wait for Render database:**
   - Render free tier may be hibernating
   - Access the service to wake it up

### Issue: SSL Connection Error

**Error:** `SSL connection has been closed unexpectedly`

**Cause:**
- SSL is required but not configured
- Incorrect SSL settings in `DATABASE_URL`

**Solutions:**

1. **Add SSL requirement:**
   ```bash
   DATABASE_URL=postgresql://user:pass@host:port/db?sslmode=require
   ```

2. **Check Render database:**
   - Render PostgreSQL requires SSL
   - Use the internal URL provided by Render

### Issue: Relation Does Not Exist

**Error:** `relation "authentication_apikey" does not exist`

**Cause:**
- Migrations not run
- Database not initialized

**Solutions:**

```bash
# Run migrations
python manage.py migrate

# Check migration status
python manage.py showmigrations

# Run specific app migrations
python manage.py migrate authentication
```

## CORS Issues

### Issue: CORS Error in Production

**Error:** `No 'Access-Control-Allow-Origin' header is present on the requested resource`

**Cause:**
- Frontend URL not in `CORS_ALLOWED_ORIGINS`
- Incorrect `FRONTEND_URL` in environment variables

**Diagnosis:**
```bash
# Check current CORS settings
curl -I https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/health/
```

**Solutions:**

1. **Add frontend URL to settings.py:**
   ```python
   CORS_ALLOWED_ORIGINS = [
       "https://sentiment-driven-stock-price-predic.vercel.app",
       "http://localhost:5173",
       "http://localhost:4173",
   ]
   ```

2. **Verify environment variable:**
   ```bash
   FRONTEND_URL=https://sentiment-driven-stock-price-predic.vercel.app
   ```

3. **Check CORS middleware:**
   - Ensure `corsheaders.middleware.CorsMiddleware` is at the top of `MIDDLEWARE`

### Issue: CORS Error in Development

**Error:** `CORS policy: No 'Access-Control-Allow-Origin' header`

**Cause:**
- Frontend running on a different port than allowed
- `withCredentials` mismatch

**Solutions:**

1. **Add development origin:**
   ```python
   CORS_ALLOWED_ORIGINS = [
       "http://localhost:5173",
       "http://localhost:4173",
   ]
   ```

2. **Set `withCredentials` to `false` in development:**
   ```javascript
   // client.js
   withCredentials: false,
   ```

## Rate Limiting Issues

### Issue: 429 Too Many Requests

**Error:** `429 Too Many Requests` with `Retry-After` header

**Cause:**
- Rate limit exceeded for your user or API key

**Diagnosis:**
```bash
# Check current rate limit usage
curl -I https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/?symbol=AAPL \
  -H "X-API-Key: your_api_key"
```

**Solutions:**

1. **Wait for reset:**
   - Check `Retry-After` header for wait time
   - Rate limits reset automatically

2. **Implement backoff:**
   ```javascript
   function apiRequestWithBackoff(url, options) {
     const delay = 1000;
     let retries = 3;
     
     while (retries > 0) {
       try {
         const response = await fetch(url, options);
         if (response.status === 429) {
           const retryAfter = parseInt(response.headers.get('Retry-After')) || delay;
           await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
           retries--;
           continue;
         }
         return response;
       } catch (error) {
         retries--;
         if (retries === 0) throw error;
         await new Promise(resolve => setTimeout(resolve, delay));
       }
     }
   }
   ```

3. **Optimize usage:**
   - Cache responses
   - Batch requests
   - Reduce request frequency

### Issue: Rate Limit Headers Missing

**Error:** Rate limit headers are not present

**Cause:**
- `RateLimitHeadersMiddleware` not in `MIDDLEWARE`
- Authentication failed before rate limit check

**Solutions:**

1. **Add middleware:**
   ```python
   MIDDLEWARE = [
       # ...
       'authentication.middleware.RateLimitHeadersMiddleware',
   ]
   ```

2. **Verify authentication:**
   - Ensure API key is valid
   - Check that user is authenticated

## API Key Issues

### Issue: Invalid API Key

**Error:** `Invalid or inactive API key.` (Code: 1001)

**Cause:**
- API key is incorrect
- API key has been revoked
- API key has expired

**Diagnosis:**
```bash
# Check API key status
python manage.py list_apikeys
```

**Solutions:**

1. **Generate a new API key:**
   ```bash
   python manage.py generate_apikey "Production Frontend"
   ```

2. **Check key status:**
   ```python
   from authentication.models import UserAPIKey
   key = UserAPIKey.objects.get(name='Production Frontend')
   print(f"Active: {key.is_active}")
   print(f"Expires at: {key.expires_at}")
   ```

3. **Reactivate key (if revoked accidentally):**
   ```python
   key = UserAPIKey.objects.get(name='Production Frontend')
   key.is_active = True
   key.save()
   ```

### Issue: Missing API Key

**Error:** `API key required. Please provide X-API-Key header.` (Code: 1002)

**Cause:**
- API key header not included in request
- Header name is incorrect

**Solutions:**

1. **Include header correctly:**
   ```bash
   curl -H "X-API-Key: your_api_key" \
     "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/?symbol=AAPL"
   ```

2. **Check header name:**
   - Header must be `X-API-Key` (case-sensitive)
   - Not `Authorization` (that's for JWT)

## Authentication Issues

### Issue: JWT Token Expired

**Error:** `401 Unauthorized` with `Token expired` message

**Cause:**
- Access token has expired (60 minutes)
- Refresh token not used correctly

**Diagnosis:**
```javascript
// Check token expiry
const token = localStorage.getItem('accessToken');
const payload = JSON.parse(atob(token.split('.')[1]));
console.log('Expires at:', new Date(payload.exp * 1000));
```

**Solutions:**

1. **Refresh token automatically:**
   ```javascript
   // Response interceptor
   apiClient.interceptors.response.use(
     (response) => response,
     async (error) => {
       if (error.response?.status === 401) {
         const refreshToken = localStorage.getItem('refreshToken');
         if (refreshToken) {
           const response = await apiClient.post('/auth/refresh/', { refresh: refreshToken });
           const newToken = response.data.data?.access || response.data.access;
           localStorage.setItem('accessToken', newToken);
           error.config.headers.Authorization = `Bearer ${newToken}`;
           return apiClient(error.config);
         }
       }
       return Promise.reject(error);
     }
   );
   ```

2. **Manual token refresh:**
   ```bash
   curl -X POST https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/auth/refresh/ \
     -H "Content-Type: application/json" \
     -d '{"refresh": "your_refresh_token"}'
   ```

### Issue: Invalid Credentials

**Error:** `Invalid credentials. Please check your username and password.`

**Cause:**
- Incorrect username or password
- User account is inactive

**Diagnosis:**
```python
# Check user in Django shell
from django.contrib.auth import get_user_model
User = get_user_model()
user = User.objects.get(username='testuser')
print(f"Active: {user.is_active}")
```

**Solutions:**

1. **Verify username and password**
2. **Reset password:**
   ```bash
   python manage.py changepassword username
   ```

3. **Activate user:**
   ```python
   user.is_active = True
   user.save()
   ```

### Issue: Email Not Verified

**Error:** `Please verify your email before logging in.`

**Cause:**
- User registered but didn't verify email
- Verification link expired

**Solutions:**

1. **Resend verification email:**
   ```bash
   curl -X POST https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/auth/resend-verification/ \
     -H "Content-Type: application/json" \
     -d '{"email": "user@example.com"}'
   ```

2. **Manually verify (development only):**
   ```python
   user.email_verified = True
   user.save()
   ```

## Frontend Issues

### Issue: Build Fails

**Error:** `npm run build` fails

**Cause:**
- Missing dependencies
- Environment variables not set
- Syntax errors

**Diagnosis:**
```bash
# Check build logs
npm run build --verbose

# Check environment variables
echo $VITE_API_BASE_URL
```

**Solutions:**

1. **Clear and reinstall dependencies:**
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

2. **Check environment variables:**
   ```bash
   VITE_API_BASE_URL=http://localhost:8000
   VITE_API_KEY=your_api_key
   VITE_USE_MOCK_DATA=false
   ```

3. **Update Vite config:**
   ```javascript
   export default defineConfig({
     // ...
     build: {
       sourcemap: true,
       rollupOptions: {
         output: {
           manualChunks: {
             vendor: ['react', 'react-dom', 'react-router-dom'],
           },
         },
       },
     },
   });
   ```

### Issue: Frontend Not Loading

**Error:** Blank page or infinite loading spinner

**Cause:**
- API call failing
- JavaScript error
- Authentication issue

**Diagnosis:**
```javascript
// Check browser console for errors
console.log('Environment:', import.meta.env.MODE);
console.log('API URL:', import.meta.env.VITE_API_BASE_URL);

// Check localStorage
console.log('User:', localStorage.getItem('user'));
console.log('Token:', localStorage.getItem('accessToken'));
```

**Solutions:**

1. **Check API connectivity:**
   ```bash
   curl https://sentiment-driven-stock-price-prediction.onrender.com/health/
   ```

2. **Verify API key is set:**
   - Check `VITE_API_KEY` in environment variables

3. **Check authentication:**
   ```javascript
   const { user, isLoading, isAuthenticated } = useAuth();
   console.log('User:', user);
   console.log('Authenticated:', isAuthenticated);
   console.log('Loading:', isLoading);
   ```

### Issue: API Calls Failing

**Error:** Network errors in browser console

**Cause:**
- API URL incorrect
- CORS issues
- Network connectivity

**Diagnosis:**
```bash
# Check API URL from frontend
curl -I https://sentiment-driven-stock-price-prediction.onrender.com/health/
```

**Solutions:**

1. **Verify `VITE_API_BASE_URL`:**
   - Should not include `/api/v1` (interceptor adds it)
   - Example: `https://sentiment-driven-stock-price-prediction.onrender.com`

2. **Check CORS:**
   - See [CORS Issues](#cors-issues) above

3. **Enable mock data for testing:**
   ```bash
   VITE_USE_MOCK_DATA=true
   ```

## Performance Issues

### Issue: Slow API Response

**Error:** API responses taking > 2 seconds

**Cause:**
- Large database queries
- External API latency
- Cache miss

**Diagnosis:**
```python
# Enable query logging
LOGGING = {
    'loggers': {
        'django.db.backends': {
            'level': 'DEBUG',
        },
    },
}
```

**Solutions:**

1. **Check slow queries:**
   ```sql
   SELECT query, total_time, calls
   FROM pg_stat_statements
   ORDER BY total_time DESC
   LIMIT 10;
   ```

2. **Add indexes:**
   ```python
   class Meta:
       indexes = [
           models.Index(fields=['user_id', 'date']),
           models.Index(fields=['stock_symbol']),
       ]
   ```

3. **Enable caching:**
   ```python
   # settings.py
   CACHES = {
       'default': {
           'BACKEND': 'django_redis.cache.RedisCache',
           'LOCATION': REDIS_URL,
       }
   }
   ```

### Issue: High Memory Usage

**Error:** Memory usage > 80%

**Cause:**
- Large data processing
- Memory leaks
- Too many workers

**Solutions:**

1. **Reduce worker count:**
   ```bash
   gunicorn ... --workers 2
   ```

2. **Optimize queries:**
   ```python
   # Use only required fields
   predictions = Prediction.objects.only('id', 'stock_symbol', 'predicted_movement')
   ```

3. **Increase memory allocation:**
   - Render: Upgrade to higher tier
