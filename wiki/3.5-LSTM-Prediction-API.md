# 3.5 LSTM Prediction API

**File:** `/wiki/3.5-LSTM-Prediction-API.md`

---

## Overview

The LSTM Prediction API provides stock movement predictions using a Long Short-Term Memory (LSTM) neural network. The model analyzes sentiment scores and technical indicators to generate directional predictions with confidence scoring. When the LSTM model is unavailable, the endpoint falls back to sentiment-based predictions.

---

## Endpoint

**Method:** `GET`

**URL:** `/api/v1/lstm-predict/`

**Authentication:** Required (API Key or JWT)

---

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `symbol` | string | Yes | Stock ticker (e.g., AAPL, TSLA) |
| `news` | string | No | News headline or text to incorporate into sentiment analysis |

---

## Request Examples

### curl

```bash
curl -H "X-API-Key: your_api_key_here" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/lstm-predict/?symbol=AAPL&news=Apple%20earnings%20beat"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/lstm-predict/"
headers = {"X-API-Key": API_KEY}
params = {
    "symbol": "AAPL",
    "news": "Apple earnings beat estimates"
}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";
const url = new URL("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/lstm-predict/");
url.searchParams.append("symbol", "AAPL");
url.searchParams.append("news", "Apple earnings beat estimates");

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

## Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `symbol` | string | Stock ticker |
| `prediction` | string | Directional prediction: `UP`, `DOWN`, or `HOLD` |
| `confidence` | float | Confidence score (0-100%) |
| `sentiment_score` | float | Sentiment score (-1.0 to 1.0) used in the prediction |
| `close_price` | float | Latest closing price (only present when available) |
| `timestamp` | string | ISO 8601 timestamp of the prediction |
| `fallback` | boolean | Whether the prediction used sentiment-only fallback |
| `message` | string | Additional information about the prediction |

## How the LSTM Works

### Model Architecture

The LSTM model has the following architecture:

| Component | Specification |
|-----------|---------------|
| Input size | 7 features |
| Hidden size | 32 units |
| Number of layers | 1 |
| Output size | 1 (sigmoid) |

### Input Features

The model uses 7 features for prediction:

| Feature | Description |
|---------|-------------|
| Sentiment Score | FinBERT sentiment score from news |
| MA7 | 7-day Simple Moving Average |
| MA21 | 21-day Simple Moving Average |
| STD21 | 21-day Standard Deviation |
| RSI14 | 14-day Relative Strength Index |
| UpperBB | Upper Bollinger Band |
| LowerBB | Lower Bollinger Band |

### Training Process

- **Loss Function:** BCELoss (Binary Cross Entropy)
- **Optimizer:** Adam
- **Learning Rate:** 0.001
- **Epochs:** 100

### Prediction Output

The model outputs a probability (0-1) using sigmoid activation:

- Probability >= 0.5 → `UP`
- Probability < 0.5 → `DOWN`
- Confidence = max(probability, 1 - probability) * 100

---

## Fallback Behavior

The LSTM predictor falls back to sentiment-only predictions when:

| Scenario | Fallback Reason |
|----------|-----------------|
| Model file not found | Missing `stock_prediction_model.pth` |
| Insufficient price history | Less than 200 days of data |
| Feature computation error | Missing or invalid technical indicators |
| Model inference error | PyTorch runtime error |

**Fallback Logic:**

1. Analyze sentiment using FinBERT
2. If sentiment_score > 0.2 → `UP`
3. If sentiment_score < -0.2 → `DOWN`
4. Else → `HOLD`
5. Confidence = min(abs(sentiment_score) * 100, 90) + 10

## Accuracy Tracking

### Performance Metrics

| Metric | Value |
|--------|-------|
| Overall Accuracy | 63% |
| Predictions Tracked | 5,000+ |
| Resolution Period | 7 days |

### Accuracy Calculation

1. Prediction is made with a confidence score
2. After 7 days, the actual movement is recorded
3. Accuracy is calculated as: `correct / total * 100`

### Accuracy Labels

| Status | Description |
|--------|-------------|
| `Pending` | Waiting for resolution (7 days) |
| `Correct` | Prediction matched actual movement |
| `Incorrect` | Prediction did not match actual movement |

## Prediction Saving

Each LSTM prediction is automatically saved to the prediction history database:

- **User Association:** Predictions are linked to the authenticated user (if JWT)
- **Source:** `lstm` for LSTM predictions, `sentiment` for fallback
- **Fields:** symbol, movement, confidence, sentiment_score, created_at, price_at_prediction

## Error Scenarios

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| 400 | 2001 | Missing `symbol` parameter |
| 400 | 5001 | Prediction failed (model error) |
| 401 | 1001/1002 | Invalid or missing API key |
| 429 | 3001 | Rate limit exceeded |
| 500 | 9001 | Internal server error |

## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.

The LSTM predictor is controlled by these environment variables:

| Variable | Description | Default |
|----------|-------------|---------|
| `ENABLE_LSTM` | Enable LSTM predictions | `False` |
| `LSTM_MODEL_PATH` | Path to the model file | `models/stock_prediction_model.pth` |
