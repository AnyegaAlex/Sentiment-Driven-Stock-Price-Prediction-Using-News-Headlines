# 7.4 Testing

**File:** `/wiki/7.4-Testing.md`

---

## Overview

This page defines the testing strategy for the Tickflow project. Comprehensive testing ensures code quality, prevents regressions, and provides confidence when deploying changes. The project uses a multi-layered testing approach covering unit, integration, and end-to-end tests.

---

## Testing Philosophy

| Principle | Description |
|-----------|-------------|
| **Test Early** | Write tests as you develop, not after |
| **Test Often** | Run tests frequently during development |
| **Test Thoroughly** | Cover edge cases and failure scenarios |
| **Test Automatically** | Run tests in CI/CD pipelines |
| **Test Independently** | Tests should not depend on each other |

---

## Test Types

| Type | Purpose | Tools | Coverage Target |
|------|---------|-------|-----------------|
| **Unit Tests** | Test individual functions and methods | pytest (Python), Vitest (JavaScript) | 80%+ |
| **Integration Tests** | Test interactions between components | pytest, Django Test Client | 70%+ |
| **End-to-End Tests** | Test full user journeys | Playwright | Critical paths |
| **API Tests** | Test API endpoints | pytest, Django REST Framework | 85%+ |

```python
# tests/unit/stocks/test_utils.py
import pytest
from django.utils import timezone
from datetime import timedelta
from stocks.utils import calculate_performance_metrics
from stocks.models import Prediction
from authentication.models import User


@pytest.mark.django_db
class TestCalculatePerformanceMetrics:
    def test_empty_queryset_returns_zero_metrics(self):
        """Test that an empty queryset returns all zeros."""
        queryset = Prediction.objects.none()
        result = calculate_performance_metrics(queryset)
        
        assert result['accuracy'] == 0
        assert result['precision'] == 0
        assert result['recall'] == 0
        assert result['f1'] == 0
    
    def test_correct_predictions_metrics(self):
        """Test metrics with 2 correct, 1 incorrect prediction."""
        user = User.objects.create(username='testuser')
        
        predictions = [
            Prediction.objects.create(
                user=user,
                stock_symbol='AAPL',
                predicted_movement='up',
                actual_direction='up',
                is_correct=True,
                date=timezone.now().date(),
                confidence=0.7,
                source='lstm'
            ),
            Prediction.objects.create(
                user=user,
                stock_symbol='AAPL',
                predicted_movement='up',
                actual_direction='up',
                is_correct=True,
                date=timezone.now().date(),
                confidence=0.8,
                source='lstm'
            ),
            Prediction.objects.create(
                user=user,
                stock_symbol='AAPL',
                predicted_movement='up',
                actual_direction='down',
                is_correct=False,
                date=timezone.now().date(),
                confidence=0.6,
                source='lstm'
            ),
        ]
        
        queryset = Prediction.objects.all()
        result = calculate_performance_metrics(queryset)
        
        assert result['accuracy'] == 66.7  # 2/3 correct
        assert result['f1'] > 0
    
    def test_sklearn_unavailable_fallback(self):
        """Test fallback when sklearn is not available."""
        # This test assumes SKLEARN_AVAILABLE is False
        # Mock the SKLEARN_AVAILABLE flag
        with patch('stocks.utils.SKLEARN_AVAILABLE', False):
            queryset = Prediction.objects.none()
            result = calculate_performance_metrics(queryset)
            
            assert result['accuracy'] == 0
            assert result['precision'] == 0
            assert result['recall'] == 0
            assert result['f1'] == 0
```

### JavaScript Unit Tests

**File Location:** `frontend/src/__tests__/`

**Example: Unit Test for `useAuth` Hook**

```javascript
// frontend/src/__tests__/hooks/useAuth.test.js
import { renderHook, act } from '@testing-library/react';
import { useAuth } from '@/hooks/useAuth';
import { AuthProvider } from '@/context/AuthContext';
import apiClient from '@/services/client';

jest.mock('@/services/client');

const wrapper = ({ children }) => (
  <AuthProvider>{children}</AuthProvider>
);

describe('useAuth', () => {
  beforeEach(() => {
    jest.clearAllMocks();
    localStorage.clear();
    sessionStorage.clear();
  });

  test('should initialize with default state', () => {
    const { result } = renderHook(() => useAuth(), { wrapper });
    
    expect(result.current.user).toBeNull();
    expect(result.current.isAuthenticated).toBe(false);
    expect(result.current.isLoading).toBe(true);
    expect(result.current.error).toBeNull();
  });

  test('should handle successful login', async () => {
    const mockUser = { id: 1, username: 'testuser', onboarded: true };
    const mockResponse = {
      data: {
        data: {
          access: 'mock-access-token',
          refresh: 'mock-refresh-token',
          user: mockUser,
        },
      },
    };
    
    apiClient.post.mockResolvedValue(mockResponse);
    
    const { result } = renderHook(() => useAuth(), { wrapper });
    
    await act(async () => {
      const response = await result.current.login('testuser', 'password', false);
      expect(response.success).toBe(true);
      expect(response.user).toEqual(mockUser);
    });
    
    expect(result.current.user).toEqual(mockUser);
    expect(result.current.isAuthenticated).toBe(true);
  });

  test('should handle login failure', async () => {
    apiClient.post.mockRejectedValue(new Error('Invalid credentials'));
    
    const { result } = renderHook(() => useAuth(), { wrapper });
    
    await act(async () => {
      const response = await result.current.login('wronguser', 'wrongpass', false);
      expect(response.success).toBe(false);
      expect(response.error).toBeDefined();
    });
    
    expect(result.current.user).toBeNull();
    expect(result.current.isAuthenticated).toBe(false);
  });

  test('should handle logout', async () => {
    // First login to set up authenticated state
    const mockUser = { id: 1, username: 'testuser' };
    apiClient.post.mockResolvedValue({
      data: {
        data: {
          access: 'mock-token',
          refresh: 'mock-refresh',
          user: mockUser,
        },
      },
    });
    
    const { result } = renderHook(() => useAuth(), { wrapper });
    
    await act(async () => {
      await result.current.login('testuser', 'password', false);
    });
    
    expect(result.current.isAuthenticated).toBe(true);
    
    await act(async () => {
      await result.current.logout();
    });
    
    expect(result.current.user).toBeNull();
    expect(result.current.isAuthenticated).toBe(false);
    expect(localStorage.getItem('user')).toBeNull();
  });
});
```

## Integration Testing

### Backend Integration Tests

**File Location:** `tests/integration/`

**Example: Integration Test for Stock Analysis Endpoint**

```python
# tests/integration/stocks/test_views.py
import pytest
from django.urls import reverse
from rest_framework.test import APIClient
from rest_framework import status
from authentication.models import User, UserAPIKey


@pytest.mark.django_db
class TestStockAnalysisView:
    def setup_method(self):
        self.client = APIClient()
        self.user = User.objects.create_user(
            username='testuser',
            password='testpass123',
            email='test@example.com'
        )
        self.api_key_obj, self.api_key = UserAPIKey.create_key(
            self.user,
            name='Test Key'
        )
        self.url = reverse('stock-analysis')
    
    def test_stock_analysis_requires_authentication(self):
        """Test that stock analysis requires API key."""
        response = self.client.get(self.url, {'symbol': 'AAPL'})
        assert response.status_code == status.HTTP_401_UNAUTHORIZED
    
    def test_stock_analysis_with_valid_key(self):
        """Test stock analysis with valid API key."""
        self.client.credentials(HTTP_X_API_KEY=self.api_key)
        response = self.client.get(self.url, {'symbol': 'AAPL'})
        assert response.status_code == status.HTTP_200_OK
        assert response.data['success'] is True
        assert 'data' in response.data
        assert response.data['data']['symbol'] == 'AAPL'
        assert 'company' in response.data['data']
        assert 'technicalIndicators' in response.data['data']
    
    def test_stock_analysis_missing_symbol(self):
        """Test stock analysis with missing symbol."""
        self.client.credentials(HTTP_X_API_KEY=self.api_key)
        response = self.client.get(self.url)
        assert response.status_code == status.HTTP_400_BAD_REQUEST
        assert response.data['success'] is False
        assert 'symbol' in response.data['error'].lower()
    
    def test_stock_analysis_invalid_symbol(self):
        """Test stock analysis with invalid symbol."""
        self.client.credentials(HTTP_X_API_KEY=self.api_key)
        response = self.client.get(self.url, {'symbol': 'INVALID'})
        # Should fall back to static data
        assert response.status_code == status.HTTP_200_OK
        assert response.data['data']['symbol'] == 'INVALID'
```

## End-to-End Testing

### Playwright Tests

**File Location:** `tests/e2e/`

**Example: Critical User Flow Test**

```javascript
// tests/e2e/user-flow.spec.js
import { test, expect } from '@playwright/test';

test.describe('Critical User Flow', () => {
  test('should complete full user journey', async ({ page }) => {
    // 1. Navigate to landing page
    await page.goto('/');
    await expect(page.locator('h1')).toBeVisible();

    // 2. Navigate to signup
    await page.click('text=Sign Up');
    await expect(page).toHaveURL('/signup');

    // 3. Fill signup form
    await page.fill('[name="username"]', 'testuser');
    await page.fill('[name="email"]', 'test@example.com');
    await page.fill('[name="password"]', 'Test@123456');
    await page.fill('[name="password2"]', 'Test@123456');
    await page.click('button[type="submit"]');
    
    // 4. Wait for email verification page
    await expect(page.locator('text=Check your email')).toBeVisible();

    // 5. Simulate email verification (using code)
    await page.goto('/verify-email');
    await page.fill('[name="code"]', '123456');
    await page.click('button[type="submit"]');
    await expect(page.locator('text=Email verified')).toBeVisible();

    // 6. Login
    await page.goto('/login');
    await page.fill('[name="username"]', 'testuser');
    await page.fill('[name="password"]', 'Test@123456');
    await page.click('button[type="submit"]');
    await expect(page).toHaveURL('/onboarding');

    // 7. Complete onboarding
    // Step 1: Profile
    await page.fill('[name="nickname"]', 'Test User');
    await page.click('button:has-text("Continue")');
    
    // Step 2: Preferences
    await page.selectOption('[name="investmentGoal"]', 'growth');
    await page.selectOption('[name="riskTolerance"]', 'moderate');
    await page.selectOption('[name="experienceLevel"]', 'intermediate');
    await page.click('button:has-text("Continue")');
    
    // Step 3: Watchlist
    await page.fill('[name="symbol-input"]', 'AAPL');
    await page.click('button:has-text("Add")');
    await page.click('button:has-text("Continue")');
    
    // Step 4: Complete
    await page.click('button:has-text("Go to Dashboard")');
    await expect(page).toHaveURL('/dashboard');

    // 8. Analyze a stock
    await page.fill('[name="symbol-search"]', 'AAPL');
    await page.click('button:has-text("Analyze")');
    await expect(page.locator('text=Analysis Results')).toBeVisible();
    await expect(page.locator('text=Recommendation')).toBeVisible();

    // 9. Check predictions
    await page.click('text=Prediction History');
    await expect(page).toHaveURL('/predictions');
    await expect(page.locator('table')).toBeVisible();

    // 10. Update profile
    await page.click('[aria-label="User menu"]');
    await page.click('text=Profile');
    await expect(page).toHaveURL('/profile');
    
    await page.click('text=Edit Profile');
    await page.fill('[name="nickname"]', 'Updated User');
    await page.click('button:has-text("Save")');
    await expect(page.locator('text=Profile updated')).toBeVisible();

    // 11. Logout
    await page.click('[aria-label="User menu"]');
    await page.click('text=Logout');
    await expect(page).toHaveURL('/login');
  });
});
```

## Running Tests

### Commands

| Command | Description |
|---------|-------------|
| `python manage.py test` | Run all Django tests |
| `python manage.py test authentication` | Run tests for specific app |
| `pytest` | Run tests with pytest |
| `pytest --cov` | Run tests with coverage |
| `cd frontend && npm test` | Run Vitest tests |
| `cd frontend && npm test:coverage` | Run tests with coverage |

## Testing Best Practices

### Backend

1. **Use Factories** – Use factory-boy or similar for test data
2. **Isolate Tests** – Each test should be independent
3. **Mock External APIs** – Mock yfinance, Alpha Vantage, etc.
4. **Test Edge Cases** – Test with empty data, invalid input, etc.
5. **Test Error Scenarios** – Test 400, 401, 429 responses

### Frontend

1. **Test User Interactions** – Click, type, submit
2. **Test API Calls** – Mock API responses
3. **Test State Changes** – Verify state after interactions
4. **Test Error States** – Show error messages
5. **Test Loading States** – Show loading indicators

### E2E

1. **Test Critical Paths** – Login, onboarding, dashboard
2. **Test Real Browser** – Test in actual browser environment
3. **Test with Real Data** – Use real API keys in test environment
4. **Test Mobile Responsive** – Test on different viewport sizes
