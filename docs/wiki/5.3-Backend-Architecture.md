## Overview

This page provides a detailed overview of the Tickflow backend architecture. The backend is built with Django and Django REST Framework, following a modular application structure. It handles authentication, data storage, API endpoints, external API integrations, and machine learning inference.

---

## Technology Stack

| Component | Technology | Purpose |
|-----------|------------|---------|
| Web Framework | Django 5.1 | Core application framework |
| API Framework | Django REST Framework | REST API development |
| Database | PostgreSQL 16 | Primary data storage |
| Cache | Redis 7 | Caching and rate limiting |
| Authentication | JWT + API Keys | User and API authentication |
| ORM | Django ORM | Database abstraction |
| Async Tasks | Celery 5.3 | Background tasks (optional) |

## Middleware Chain

The middleware chain processes requests in the following order:

| Order | Middleware | Purpose |
|-------|------------|---------|
| 1 | `CorsMiddleware` | Cross-Origin Resource Sharing configuration |
| 2 | `RequestLoggingMiddleware` | Logs request details and timing |
| 3 | `SecurityMiddleware` | Security headers and HTTPS enforcement |
| 4 | `WhiteNoiseMiddleware` | Static file serving |
| 5 | `SessionMiddleware` | Session management |
| 6 | `CommonMiddleware` | Common Django settings |
| 7 | `CsrfViewMiddleware` | CSRF protection |
| 8 | `AuthenticationMiddleware` | Django authentication |
| 9 | `MessageMiddleware` | Message handling |
| 10 | `XFrameOptionsMiddleware` | Clickjacking protection |
| 11 | `APIKeyMiddleware` | API key authentication for external API calls |
| 12 | `RateLimitHeadersMiddleware` | Rate limit headers in responses |
| 13 | `DeprecationMiddleware` | Deprecation headers for legacy endpoints |

### APIKeyMiddleware Flow

```
1. Request arrives
2. Check if path is in PUBLIC_PATHS (skip authentication)
3. Try JWT authentication
4. If JWT fails, check X-API-Key header
5. Hash the key and validate against database
6. If valid, attach user and API key object to request
7. If invalid, return 401 Unauthorized
```

### RequestLoggingMiddleware

```python
# authentication/middleware.py
class RequestLoggingMiddleware:
    def __call__(self, request):
        # Generate request ID
        request_id = request.headers.get('X-Request-ID', str(uuid.uuid4()))
        request.request_id = request_id
        
        # Store start time
        request._start_time = time.time()
        
        response = self.get_response(request)
        
        # Log request completion
        duration = time.time() - request._start_time
        log_data = {
            'method': request.method,
            'path': request.path,
            'status_code': response.status_code,
            'duration_ms': round(duration * 1000, 2),
            'request_id': request_id,
            'ip': request.META.get('REMOTE_ADDR'),
        }
        
        if hasattr(request, 'user') and request.user.is_authenticated:
            log_data['user_id'] = request.user.id
            log_data['username'] = request.user.username
        
        logger.info(f"Request completed: {log_data}")
        
        return response
```

## Caching Strategy

### Cache Layers

| Cache Layer | Purpose | TTL |
|-------------|---------|-----|
| **API Response Cache** | Stock analysis, technical indicators, predictions | 5-10 minutes |
| **Database Query Cache** | Frequently accessed data | 5 minutes |
| **Session Cache** | User sessions | 60 minutes |
| **Rate Limit Cache** | Rate limit tracking | 60 seconds |

### Cache Implementation

```python
# settings.py
CACHES = {
    'default': {
        'BACKEND': 'django_redis.cache.RedisCache',
        'LOCATION': REDIS_URL,
        'OPTIONS': {
            'CLIENT_CLASS': 'django_redis.client.DefaultClient',
            'SOCKET_CONNECT_TIMEOUT': 10,
            'SOCKET_TIMEOUT': 5,
            'IGNORE_EXCEPTIONS': True,
        },
        'KEY_PREFIX': 'sentiment_analysis',
    }
}

# Usage in views
from django.core.cache import cache

def get_stock_analysis(symbol):
    cache_key = f"stock_analysis_{symbol}"
    cached = cache.get(cache_key)
    if cached:
        return cached
    
    data = compute_analysis(symbol)
    cache.set(cache_key, data, timeout=300)  # 5 minutes
    return data
```

### Fallback Behavior

| Scenario | Fallback |
|----------|----------|
| Redis unavailable | Django LocMemCache |
| Cache miss | Compute fresh data |
| Cache stale | Return cached data, refresh in background |

## Error Handling

### Exception Hierarchy

```
Exception
├── AuthenticationError (401)
│   ├── InvalidAPIKeyError
│   ├── MissingAPIKeyError
│   └── InvalidJWTError
├── ValidationError (400)
│   ├── MissingParameterError
│   ├── InvalidParameterError
│   └── ValidationFailedError
├── RateLimitError (429)
├── ResourceNotFoundError (404)
└── ServerError (500)
    ├── DatabaseError
    ├── ExternalAPIError
    └── InternalServerError
```

### Error Response Format

```json
{
  "success": false,
  "error": "Human-readable error message",
  "code": 1001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456",
  "details": {}
}
```

### Error Handler Utility

```python
# authentication/utils.py
def error_response(message, code, status_code=400, details=None, request_id=None):
    response = {
        "success": False,
        "error": message,
        "code": code,
        "timestamp": datetime.utcnow().isoformat() + 'Z',
    }
    if details:
        response["details"] = details
    if request_id:
        response["request_id"] = request_id
    
    return Response(response, status=status_code)

def success_response(data=None, message=None, code=200):
    response = {
        "success": True,
        "code": code,
        "timestamp": datetime.utcnow().isoformat() + 'Z',
    }
    if data is not None:
        response["data"] = data
    if message:
        response["message"] = message
    
    return Response(response, status=code)
```
