## Overview

This guide will get you running Tickflow in under 5 minutes. You will set up the backend, generate an API key, and make your first prediction.

---

## Prerequisites

Before starting, ensure you have the following installed:

| Requirement | Version | Verification Command |
|-------------|---------|---------------------|
| Python | 3.12+ | `python --version` |
| Node.js | 20+ | `node --version` |
| PostgreSQL | 16+ | `psql --version` |
| Redis | 7+ (optional) | `redis-server --version` |
| Git | Latest | `git --version` |

## Step 1: Clone the Repository

```bash
git clone https://github.com/AnyegaAlex/Sentiment-Driven-Stock-Price-Prediction-Using-News-Headlines.git
cd sentiment_driven_stock_price_prediction_engine
```

---

## Step 2: Set Up the Backend

### Create Virtual Environment

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

```bash
cp .env.example .env
```

Edit `.env` and set the required variables:

```bash
SECRET_KEY=your-secret-key-here
DEBUG=True
DATABASE_URL=postgresql://user:password@localhost:5432/tickflow
ALPHA_VANTAGE_KEY=your-alpha-vantage-key
```

### Run Migrations

```bash
python manage.py migrate
python manage.py createcachetable
```

### Generate an API Key

```bash
python manage.py generate_apikey "Development"
```

Save the generated key. You will use it in Step 4.

### Start the Backend Server

```bash
python manage.py runserver
```

The backend will be available at `http://localhost:8000`.

---

## Step 3: Set Up the Frontend

### Navigate to Frontend Directory

```bash
cd frontend
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

```bash
cp .env.example .env.development
```

Edit `.env.development`:

```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_API_KEY=your-api-key-from-step-2
VITE_USE_MOCK_DATA=false
```

### Start the Frontend Server

```bash
npm run dev
```

The frontend will be available at `http://localhost:5173`.

---

## Step 4: Make Your First API Call

Using the API key generated in Step 2, make a request to the Stock Analysis endpoint.

### curl Example

```bash
curl -H "X-API-Key: your_api_key_here" \
  "http://localhost:8000/api/v1/stock-analysis/?symbol=AAPL"
```

### Python Example

```python
import requests

API_KEY = "your_api_key_here"
url = "http://localhost:8000/api/v1/stock-analysis/"
params = {"symbol": "AAPL"}
headers = {"X-API-Key": API_KEY}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript Example

```javascript
const API_KEY = "your_api_key_here";
const url = "http://localhost:8000/api/v1/stock-analysis/?symbol=AAPL";

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` |
| `relation does not exist` | Run `python manage.py migrate` |
| `401 Unauthorized` | Verify API key is correct and active |
| `Port already in use` | Change port: `python manage.py runserver 8001` |
| `CORS error` | Verify FRONTEND_URL in .env matches your frontend URL |
