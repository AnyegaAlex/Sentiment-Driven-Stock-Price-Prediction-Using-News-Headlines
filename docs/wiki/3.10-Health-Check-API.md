# 3.10 Health Check API

**File:** `/wiki/3.10-Health-Check-API.md`

---

## Overview

The Health Check API provides a simple endpoint for monitoring the availability and status of the Tickflow backend. It is used by monitoring tools, load balancers, and deployment pipelines to verify that the service is running correctly. This endpoint does not require authentication.

---

## Endpoint

**Method:** `GET`

**URL:** `/health/`

**Authentication:** Not required

---

## Request Examples

### curl

```bash
curl https://sentiment-driven-stock-price-prediction.onrender.com/health/
```

### Python

```python
import requests

url = "https://sentiment-driven-stock-price-prediction.onrender.com/health/"
response = requests.get(url)

```

### JavaScript (Fetch)

```javascript

```

---

## Response Schema

### Success Response

```json
{
  "status": "ok",
  "redis": false,
  "timestamp": "2026-07-24T10:00:00.123456Z"
}
```

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `status` | string | Service status: `ok` (healthy) or `error` (unhealthy) |
| `redis` | boolean | Redis connection status: `true` (connected) or `false` (disconnected) |
| `timestamp` | string | ISO 8601 timestamp of the health check |

### Render Health Checks

Render automatically pings the health check endpoint for service health monitoring.

### Custom Monitoring

```python
import requests
import time

def check_health():
    try:
        response = requests.get(
            "https://sentiment-driven-stock-price-prediction.onrender.com/health/",
            timeout=5
        )
        
        if response.status_code == 200:
            data = response.json()
            if data.get('status') == 'ok':
                print(f"Service healthy. Redis: {data.get('redis', False)}")
                return True
        
        print(f"Health check failed: {response.status_code}")
        return False
        
    except requests.exceptions.Timeout:
        print("Health check timed out")
        return False
    except requests.exceptions.ConnectionError:
        print("Health check connection failed")
        return False

# Usage
is_healthy = check_health()
```

## Usage Notes

### Deployment Verification

The health endpoint is used in deployment pipelines to verify that the service is running correctly after deployment.

```bash
# Wait for service to become healthy
while true; do
  STATUS=$(curl -s -o /dev/null -w "%{http_code}" \
    https://sentiment-driven-stock-price-prediction.onrender.com/health/)
  if [ "$STATUS" = "200" ]; then
    echo "Service is healthy"
    break
  fi
  echo "Waiting for service..."
  sleep 5
done
```

### Load Balancer Integration

The health endpoint is used by load balancers to determine if a service instance is healthy and should receive traffic.

### Cron Job Monitoring

The health endpoint can be used to monitor the health of cron jobs and background tasks.

---

## Rate Limiting

The health check endpoint is exempt from rate limiting to ensure monitoring tools can always access it.
