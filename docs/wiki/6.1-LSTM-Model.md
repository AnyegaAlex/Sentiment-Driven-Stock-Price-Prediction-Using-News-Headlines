## Overview

This page provides a detailed reference for the LSTM (Long Short-Term Memory) neural network model used in Tickflow for stock movement prediction. The model is a key component of the ML pipeline and is responsible for generating directional predictions with confidence scores.

---

## Model Architecture

### Overview

The LSTM model is a neural network designed for time series prediction. It takes 7 input features and outputs a probability score indicating the likelihood of an upward movement.

**Model File:** `stocks/lstm_predictor.py`

## Input Features

The model takes 7 input features, combining sentiment analysis and technical indicators.

### Feature Descriptions

| Feature | Source | Description | Range |
|---------|--------|-------------|-------|
| **Sentiment Score** | FinBERT | Sentiment analysis from news | -1.0 to 1.0 |
| **MA7** | yfinance | 7-day Simple Moving Average | Variable |
| **MA21** | yfinance | 21-day Simple Moving Average | Variable |
| **STD21** | yfinance | 21-day Standard Deviation | Variable |
| **RSI14** | yfinance | 14-day Relative Strength Index | 0 to 100 |
| **UpperBB** | yfinance | Upper Bollinger Band | Variable |
| **LowerBB** | yfinance | Lower Bollinger Band | Variable |

### Feature Engineering

```python
# stocks/lstm_predictor.py
def compute_lstm_features(symbol: str) -> dict:
    """
    Download historical price data and compute the 7 features required by the model.
    """
    data = yf.download(symbol, period="2y", progress=False, auto_adjust=True)
    
    if data.empty or len(data) < 200:
        return None
    
    df = data[['Close']].copy()
    df['MA7'] = df['Close'].rolling(window=7).mean()
    df['MA21'] = df['Close'].rolling(window=21).mean()
    df['STD21'] = df['Close'].rolling(window=21).std()
    
    # RSI 14
    delta = df['Close'].diff()
    gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
    loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
    rs = gain / loss
    df['RSI14'] = 100 - (100 / (1 + rs))
    
    # Bollinger Bands
    df['UpperBB'] = df['MA21'] + (df['STD21'] * 2)
    df['LowerBB'] = df['MA21'] - (df['STD21'] * 2)
    
    df.dropna(inplace=True)
    if df.empty:
        return None
    
    latest = df.iloc[-1]
    return {
        'MA7': latest['MA7'],
        'MA21': latest['MA21'],
        'STD21': latest['STD21'],
        'RSI14': latest['RSI14'],
        'UpperBB': latest['UpperBB'],
        'LowerBB': latest['LowerBB'],
        'Close': latest['Close'],
    }
```

## Training Process

### Training Implementation

```python
# stocks/train_lstm.py (conceptual)
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

def train_model(train_data, val_data, epochs=100):
    model = LSTMModel(input_size=7, hidden_size=32, output_size=1)
    criterion = nn.BCELoss()
    optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
    
    train_loader = DataLoader(train_data, batch_size=32, shuffle=True)
    val_loader = DataLoader(val_data, batch_size=32, shuffle=False)
    
    for epoch in range(epochs):
        # Training
        model.train()
        train_loss = 0
        for batch in train_loader:
            features, labels = batch
            optimizer.zero_grad()
            outputs = model(features)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()
            train_loss += loss.item()
        
        # Validation
        model.eval()
        val_loss = 0
        correct = 0
        total = 0
        with torch.no_grad():
            for batch in val_loader:
                features, labels = batch
                outputs = model(features)
                loss = criterion(outputs, labels)
                val_loss += loss.item()
                
                predictions = (outputs >= 0.5).float()
                correct += (predictions == labels).sum().item()
                total += labels.size(0)
        
        accuracy = correct / total
        print(f"Epoch {epoch+1}/{epochs}: Train Loss: {train_loss/len(train_loader):.4f}, Val Loss: {val_loss/len(val_loader):.4f}, Accuracy: {accuracy:.4f}")
    
    # Save model
    torch.save(model.state_dict(), 'models/stock_prediction_model.pth')
```

## Model Loading

### Loading the Model

```python
# stocks/lstm_predictor.py
def _load_model(self):
    """Load the LSTM model from the .pth file."""
    try:
        if not os.path.exists(self.model_path):
            logger.warning(f"LSTM model not found at {self.model_path}")
            return
        
        model = LSTMModel(self.input_size, self.hidden_size, self.output_size)
        state_dict = torch.load(self.model_path, map_location=self.device)
        model.load_state_dict(state_dict)
        model.to(self.device)
        model.eval()
        self.model = model
        logger.info(f"LSTM model loaded from {self.model_path}")
    except Exception as e:
        logger.error(f"Failed to load LSTM model: {e}")
        self.model = None
```

## Inference

### Prediction Process

```
1. Receive request (symbol, optional news text)
2. Check if model is loaded
   └── If not loaded, use sentiment fallback
3. Compute technical indicators from yfinance
   └── If insufficient data, use sentiment fallback
4. Compute sentiment score from news text (or recent news)
5. Build feature vector (7 features)
6. Run model inference
   └── Features → LSTM → Sigmoid → Probability
7. Convert probability to prediction
   └── >= 0.5 → UP, < 0.5 → DOWN
8. Calculate confidence score
9. Save prediction to database
10. Return prediction response
```

### Inference Code

```python
# stocks/lstm_predictor.py
def predict(self, symbol: str, news_text: str = "") -> dict:
    # 1. Check model availability
    if self.model is None:
        return get_sentiment_fallback(symbol, news_text)
    
    # 2. Compute technical features
    tech_features = compute_lstm_features(symbol)
    if tech_features is None:
        return get_sentiment_fallback(symbol, news_text)
    
    # 3. Compute sentiment score
    sentiment_result = analyze_sentiment(news_text) if news_text else {'label': 'neutral', 'score': 0.0}
    label = sentiment_result.get('label', 'neutral')
    score = sentiment_result.get('score', 0.0)
    sentiment_score = score if label == 'positive' else -score if label == 'negative' else 0.0
    
    # 4. Build feature vector
    features = np.array([
        float(sentiment_score),
        float(tech_features['MA7']),
        float(tech_features['MA21']),
        float(tech_features['STD21']),
        float(tech_features['RSI14']),
        float(tech_features['UpperBB']),
        float(tech_features['LowerBB'])
    ], dtype=np.float32)
    
    # 5. Run inference
    input_tensor = torch.tensor(features, device=self.device).unsqueeze(0).unsqueeze(1)
    with torch.no_grad():
        output = self.model(input_tensor)
        prob = torch.sigmoid(output).item()
    
    # 6. Convert to prediction
    prediction = 'UP' if prob >= 0.5 else 'DOWN'
    confidence = round((prob if prob >= 0.5 else 1 - prob) * 100, 1)
    
    # 7. Return result
    return {
        'prediction': prediction,
        'confidence': confidence,
        'sentiment_score': round(sentiment_score, 3),
        'close_price': float(tech_features['Close']),
        'fallback': False,
        'message': 'LSTM prediction successful'
    }
```

## Model Limitations

### Known Limitations

| Limitation | Description | Mitigation |
|------------|-------------|------------|
| **Data Requirements** | Requires 200+ days of historical price data | Fallback to sentiment-only |
| **Market Volatility** | Performance degrades in highly volatile markets | Lower confidence scores |
| **News Availability** | Requires news data for sentiment analysis | Use recent news from database |
| **Model Accuracy** | 63% accuracy – not suitable for high-stakes trading | Use as decision support |
| **Training Data** | May not capture regime changes | Regular retraining recommended |

### Fallback Scenarios

| Scenario | Fallback | Response |
|----------|----------|----------|
| Model file not found | Sentiment-only | `fallback: true` |
| Insufficient price history | Sentiment-only | `fallback: true` |
| Feature computation error | Sentiment-only | `fallback: true` |
| Model inference error | Sentiment-only | `fallback: true` |

### When to Use LSTM

| Use Case | Recommendation |
|----------|----------------|
| Long-term investing | ✅ Use LSTM with lower confidence |
| Short-term trading | ✅ Use LSTM with higher confidence |
| High-volatility stocks | ⚠️ Use with caution, check confidence |
| Low-liquidity stocks | ⚠️ May have insufficient data |
| News-driven stocks | ✅ Use LSTM + sentiment |
