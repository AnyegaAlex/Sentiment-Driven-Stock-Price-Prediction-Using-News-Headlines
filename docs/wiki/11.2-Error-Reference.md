# 11.2 Error Reference

**File:** `/wiki/11.2-Error-Reference.md`

## Overview

This page provides a complete reference for all error codes returned by the Tickflow API. Understanding these error codes will help you diagnose and resolve issues quickly. Each error code includes a description, HTTP status code, and recommended resolution steps.

---

## Error Response Format

All error responses follow a consistent format:

```json
{
  "success": false,
  "error": "Human-readable error message",
  "code": 1001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456",
  "details": {}
}
```

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Always `false` for error responses |
| `error` | string | Human-readable error message |
| `code` | integer | Numeric error code for programmatic handling |
| `timestamp` | string | ISO 8601 timestamp |
| `request_id` | string | Unique request identifier for tracing |
| `details` | object | Additional error context (optional) |

## Error Code Categories

| Code Range | Category | Description |
|------------|----------|-------------|
| **1000-1999** | Authentication | API key, JWT, or authentication errors |
| **2000-2999** | Validation | Invalid parameters or request data |
| **3000-3999** | Rate Limiting | Rate limit exceeded |
| **4000-4999** | Resource | Resource not found or unavailable |
| **5000-5999** | Internal | Server-side errors |

## Complete Error Code Reference

### Authentication Errors (1000-1999)

| Code | HTTP Status | Description | Resolution |
|------|-------------|-------------|------------|
| 1001 | 401 | Invalid API key | Generate a new API key. Verify the key is correctly copied. |
| 1002 | 401 | Missing API key | Add `X-API-Key` header to the request. |
| 1003 | 401 | Expired API key | Generate a new API key or extend the expiry date. |
| 1004 | 401 | Revoked API key | Generate a new API key. Revoked keys cannot be reactivated. |
| 1005 | 401 | Invalid JWT token | Refresh the token using the refresh token endpoint. |
| 1006 | 401 | Expired JWT token | Use the refresh token to get a new access token. |
| 1007 | 401 | Missing JWT token | Add `Authorization: Bearer <token>` header. |
| 1008 | 401 | Token blacklisted | Token has been revoked. Login again to get a new token. |
| 1009 | 403 | Email not verified | Verify your email address before accessing this resource. |
| 1010 | 403 | Onboarding incomplete | Complete the onboarding process before proceeding. |

### Validation Errors (2000-2999)

| Code | HTTP Status | Description | Resolution |
|------|-------------|-------------|------------|
| 2001 | 400 | Missing required parameter | Add the required parameter to the request. |
| 2002 | 400 | Invalid parameter value | Check the parameter format and valid values. |
| 2003 | 400 | Invalid symbol format | Use valid stock symbols (e.g., AAPL, TSLA). |
| 2004 | 400 | Invalid email format | Provide a valid email address. |
| 2005 | 400 | Password validation failed | Password must be at least 8 characters and not too common. |
| 2006 | 400 | Validation failed | Check the `details` field for specific validation errors. |
| 2007 | 400 | Invalid date format | Use ISO 8601 date format (YYYY-MM-DD). |
| 2008 | 400 | Invalid JSON body | Check the request body for JSON syntax errors. |
| 2009 | 400 | Invalid risk type | Valid values: `low`, `medium`, `high`. |
| 2010 | 400 | Invalid hold time | Valid values: `short-term`, `medium-term`, `long-term`. |
| 2011 | 400 | Invalid time range | Valid values: `7d`, `30d`. |
| 2012 | 400 | Invalid outcome filter | Valid values: `correct`, `incorrect`. |
| 2013 | 400 | Invalid source filter | Valid values: `lstm`, `sentiment`. |

### Rate Limiting Errors (3000-3999)

| Code | HTTP Status | Description | Resolution |
|------|-------------|-------------|------------|
| 3001 | 429 | Rate limit exceeded | Wait for the period specified in `Retry-After` header. |
| 3002 | 429 | API key rate limit exceeded | 200 requests/minute limit. Wait 60 seconds. |
| 3003 | 429 | User rate limit exceeded | 1000 requests/hour limit. Wait for the hour to reset. |
| 3004 | 429 | Anonymous rate limit exceeded | 100 requests/hour limit. Wait for the hour to reset. |

### Resource Errors (4000-4999)

| Code | HTTP Status | Description | Resolution |
|------|-------------|-------------|------------|
| 4001 | 404 | Resource not found | Verify the resource ID or symbol exists. |
| 4002 | 400 | Email already subscribed | Email is already in the subscription list. |
| 4003 | 404 | User not found | Verify the user ID or username exists. |
| 4004 | 404 | Prediction not found | Verify the prediction ID exists. |
| 4005 | 404 | Symbol not supported | The symbol is not in the supported symbols list. |
| 4006 | 400 | Watchlist symbol already exists | The symbol is already in your watchlist. |

### Internal Errors (5000-5999)

| Code | HTTP Status | Description | Resolution |
|------|-------------|-------------|------------|
| 5001 | 400 | Prediction failed | Model error. Check the error message for details. |
| 5002 | 503 | External API error | Data source unavailable. Retry later. |
| 5003 | 503 | News fetch failed | News source unavailable. Retry later. |

### Server Errors (9000-9999)

| Code | HTTP Status | Description | Resolution |
|------|-------------|-------------|------------|
| 9001 | 500 | Internal server error | Contact support with the `request_id`. |
| 9002 | 500 | Database error | Check database connection and logs. |
| 9003 | 503 | External API error | Data source unavailable, retry later. |
| 9004 | 500 | Rate limiter error | Internal rate limiting issue, contact support. |

## Common Error Examples

### Authentication Error (Invalid API Key)

```json
{
  "success": false,
  "error": "Invalid or inactive API key.",
  "code": 1001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

**Resolution:**
1. Generate a new API key: `python manage.py generate_apikey "Production"`
2. Verify the key is correctly copied
3. Check if the key is active and not expired

### Authentication Error (Missing API Key)

```json
{
  "success": false,
  "error": "API key required. Please provide X-API-Key header.",
  "code": 1002,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

**Resolution:**
1. Add `X-API-Key: your_api_key` header to the request
2. Verify the header name is spelled correctly

### Validation Error (Invalid Symbol)

```json
{
  "success": false,
  "error": "Invalid symbol format.",
  "code": 2003,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

**Resolution:**
1. Use valid stock symbols (e.g., AAPL, TSLA)
2. Symbols must be 1-10 alphanumeric characters

### Rate Limit Error

```json
{
  "success": false,
  "error": "Rate limit exceeded. Please try again later.",
  "code": 3001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456",
  "details": {
    "limit": 200,
    "remaining": 0,
    "reset_in_seconds": 45
  }
}
```

**Resolution:**
1. Check `Retry-After` header for wait time
2. Implement exponential backoff in your client
3. Cache responses to reduce request volume

### Resource Not Found

```json
{
  "success": false,
  "error": "Prediction not found.",
  "code": 4004,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456",
  "details": {
    "prediction_id": 12345
  }
}
```

**Resolution:**
1. Verify the prediction ID exists
2. Check if the prediction belongs to the authenticated user

## Debugging Tips

### 401 Unauthorized

**Possible causes:**
- Invalid API key
- Expired JWT token
- Missing authentication header
- Revoked or expired API key

**Diagnostic steps:**
1. Verify the API key is correct and active
2. Check the JWT token expiry
3. Ensure the header is correctly formatted

### 400 Bad Request

**Possible causes:**
- Missing required parameters
- Invalid parameter values
- Malformed request body
- Validation errors

**Diagnostic steps:**
1. Check the `details` field for specific errors
2. Verify all required parameters are included
3. Validate parameter formats

### 429 Too Many Requests

**Possible causes:**
- Rate limit exceeded
- API key rate limit (200/minute)
- User rate limit (1000/hour)
- Anonymous rate limit (100/hour)

**Diagnostic steps:**
1. Check `Retry-After` header
2. Monitor `X-RateLimit-Remaining` header
3. Review your request patterns

### 500 Internal Server Error

**Possible causes:**
- Database connection issues
- External API failures
- Unhandled exceptions
- Resource constraints

**Diagnostic steps:**
1. Check the server logs
2. Verify database connectivity
3. Contact support with the `request_id`

## Error Handling Best Practices

### Client-Side Error Handling

```javascript
function handleApiError(error) {
  if (error.code === 1001 || error.code === 1002) {
    // Authentication error – refresh API key
    regenerateApiKey();
  } else if (error.code === 3001) {
    // Rate limit error – wait and retry
    const retryAfter = error.details?.reset_in_seconds || 60;
    setTimeout(() => retryRequest(), retryAfter * 1000);
  } else if (error.code >= 2000 && error.code < 3000) {
    // Validation error – show user feedback
    showValidationError(error.details);
  } else if (error.code >= 4000 && error.code < 5000) {
    // Resource error – show not found message
    showNotFoundError();
  } else if (error.code >= 9000) {
    // Server error – log and alert
    logError(error);
    showServerError();
  }
}
```

### Retry with Exponential Backoff

```javascript
async function apiRequestWithRetry(url, options, maxRetries = 3) {
  let retryCount = 0;
  let delay = 1000;

  while (retryCount < maxRetries) {
    try {
      const response = await fetch(url, options);
      if (response.status === 429) {
        const retryAfter = parseInt(response.headers.get('Retry-After')) || delay;
        await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
        retryCount++;
        delay *= 2;
        continue;
      }
      return response;
    } catch (error) {
      retryCount++;
      if (retryCount >= maxRetries) throw error;
      await new Promise(resolve => setTimeout(resolve, delay));
      delay *= 2;
    }
  }
}
```
