# 3.6 Prediction History API

**File:** `/wiki/3.6-Prediction-History-API.md`

---

## Overview

The Prediction History API provides access to historical predictions generated by the LSTM model and sentiment-based fallback. It supports filtering by symbol, date range, outcome status, and pagination. This endpoint is essential for users tracking their prediction performance and for quantitative analysis.

---

## Endpoint

**Method:** `GET`

**URL:** `/api/v1/prediction-history/`

**Authentication:** Required (API Key or JWT)

---

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `symbol` | string | No | — | Filter by stock ticker (e.g., AAPL) |
| `date_from` | string | No | — | Filter by date range start (ISO 8601 date) |
| `date_to` | string | No | — | Filter by date range end (ISO 8601 date) |
| `outcome` | string | No | — | Filter by outcome: `correct` or `incorrect` |
| `source` | string | No | — | Filter by source: `lstm` or `sentiment` |
| `limit` | integer | No | 50 | Results per page (max 200) |
| `offset` | integer | No | 0 | Pagination offset |

---

## Request Examples

### curl

```bash
curl -H "X-API-Key: your_api_key_here" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/prediction-history/?symbol=AAPL&limit=10&offset=0"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/prediction-history/"
headers = {"X-API-Key": API_KEY}
params = {
    "symbol": "AAPL",
    "limit": 10,
    "offset": 0
}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";
const url = new URL("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/prediction-history/");
url.searchParams.append("symbol", "AAPL");
url.searchParams.append("limit", "10");
url.searchParams.append("offset", "0");

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `id` | integer | Unique prediction identifier |
| `date` | string | Date of the prediction (YYYY-MM-DD) |
| `stock_symbol` | string | Stock ticker |
| `headline` | string | Prediction headline or description |
| `sentiment_score` | float | Sentiment score (-1.0 to 1.0) used in the prediction |
| `predicted_movement` | string | Predicted direction: `up`, `down`, or `neutral` |
| `confidence` | float | Confidence score (0.0 to 1.0) |
| `confidence_percent` | float | Confidence score as percentage (0-100%) |
| `source` | string | Prediction source: `lstm` or `sentiment` |
| `price_at_prediction` | string or null | Stock price at the time of prediction |
| `price_at_resolution` | string or null | Stock price at resolution time (after 7 days) |
| `actual_direction` | string or null | Actual movement: `up`, `down`, or `neutral` |
| `is_correct` | boolean or null | Whether the prediction was correct |
| `accuracy_label` | string | Status label: `Pending`, `Correct`, or `Incorrect` |
| `resolution_date` | string or null | Date when the prediction was resolved |
| `time_to_resolution` | string or null | Time duration until resolution |
| `price_change_percent` | string or null | Percentage change from prediction to resolution |
| `shap_values` | object or null | SHAP values for model explainability |
| `feature_importance` | object or null | Feature importance scores |
| `prediction_explanation` | string or null | Human-readable explanation of the prediction |
| `market_context` | object or null | Market context at resolution time |
| `created_at` | string | ISO 8601 timestamp of creation |

---

## Pagination

| Field | Type | Description |
|-------|------|-------------|
| `total` | integer | Total number of results matching the query |
| `results` | array | Array of prediction objects for the current page |
| `limit` | integer | Number of results per page |
| `offset` | integer | Current pagination offset |

### Pagination Example

```bash
# First page (0-24)
/prediction-history/?limit=25&offset=0

# Second page (25-49)
/prediction-history/?limit=25&offset=25

# Third page (50-74)
/prediction-history/?limit=25&offset=50
```

## Filtering Examples

### Filter by Symbol

```bash
/prediction-history/?symbol=AAPL
```

### Filter by Date Range

```bash
/prediction-history/?date_from=2026-07-01&date_to=2026-07-31
```

### Filter by Outcome

```bash
# Get only correct predictions
/prediction-history/?outcome=correct

# Get only incorrect predictions
/prediction-history/?outcome=incorrect
```

### Filter by Source

```bash
# Get only LSTM predictions
/prediction-history/?source=lstm

# Get only sentiment-based predictions
/prediction-history/?source=sentiment
```

### Combined Filters

```bash
# Get correct LSTM predictions for AAPL in July 2026
/prediction-history/?symbol=AAPL&date_from=2026-07-01&date_to=2026-07-31&outcome=correct&source=lstm
```

## Accuracy Labels

| Label | Condition | Description |
|-------|-----------|-------------|
| `Pending` | `is_correct` is null | Prediction not yet resolved |
| `Correct` | `is_correct` is true | Prediction matched actual movement |
| `Incorrect` | `is_correct` is false | Prediction did not match actual movement |

---

## Resolution Information

Predictions are resolved 7 days after the prediction date.

| Field | Description |
|-------|-------------|
| `price_at_prediction` | Price when prediction was made |
| `price_at_resolution` | Price 7 days later |
| `actual_direction` | Actual movement based on price change |
| `is_correct` | Whether the prediction was correct |
| `price_change_percent` | Percentage change over 7 days |

## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.
