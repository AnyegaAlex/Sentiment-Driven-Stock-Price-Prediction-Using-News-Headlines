# 3.9 Symbol Search API

**File:** `/wiki/3.9-Symbol-Search-API.md`

---

## Overview

The Symbol Search API provides dynamic search functionality for stock symbols across multiple data sources. Unlike the fixed Symbols API, this endpoint searches external and internal data sources to return matching symbols based on a search query. It is used for autocomplete functionality in search fields and for discovering new symbols.

---

## Endpoint

**Method:** `GET`

**URL:** `/api/v1/news/symbol-search/`

**Authentication:** Required (API Key or JWT)

---

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `q` | string | Yes | Search query (minimum 2 characters) |

---

## Request Examples

### curl

```bash
curl -H "X-API-Key: your_api_key_here" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/news/symbol-search/?q=Apple"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/news/symbol-search/"
headers = {"X-API-Key": API_KEY}
params = {"q": "Apple"}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";
const url = new URL("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/news/symbol-search/");
url.searchParams.append("q", "Apple");

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

## Search Behavior

### Minimum Query Length

The search query must be at least 2 characters. Shorter queries return an error.

### Search Sources

The endpoint searches the following sources in order:

1. **Internal Symbols List**: Pre-configured list of supported symbols
2. **Alpha Vantage**: External API for symbol lookup
3. **Finnhub**: Secondary external API for symbol lookup

### Search Logic

- Matches are case-insensitive
- Search is performed on both symbol and company name
- Results are deduplicated
- Results are sorted by relevance (exact matches first)

## Error Scenarios

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| 400 | 2001 | Missing `q` parameter |
| 400 | 2002 | Query too short (minimum 2 characters) |
| 401 | 1001/1002 | Invalid or missing API key |
| 429 | 3001 | Rate limit exceeded |
| 500 | 9003 | External API error |

### Example Error (Query Too Short)


## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.

---

## Fallback Behavior

When external APIs are unavailable, the endpoint falls back to internal data:

1. **Internal symbols list** is always available
2. If external API fails, returns only internal matches
3. If no matches found, returns empty array

## Usage Notes

### Frontend Integration

The Symbol Search API is typically used in conjunction with an autocomplete input:

```javascript
// Debounced search example
let timeoutId;

const handleSearch = (query) => {
  clearTimeout(timeoutId);
  
  if (query.length < 2) return;
  
  timeoutId = setTimeout(() => {
    fetch(`/api/v1/news/symbol-search/?q=${encodeURIComponent(query)}`, {
      headers: { "X-API-Key": API_KEY }
    })
    .then(response => response.json())
    .then(data => {
      if (data.success) {
        displayResults(data.data);
      }
    });
  }, 300);
};
```

### Caching

Search results are not cached to ensure fresh data from external sources.

### Rate Limit Considerations

This endpoint calls external APIs, which may have their own rate limits. Consider implementing client-side debouncing to reduce unnecessary requests.
