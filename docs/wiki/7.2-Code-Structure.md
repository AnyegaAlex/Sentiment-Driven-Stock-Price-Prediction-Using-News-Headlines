## Overview

This page provides a comprehensive reference for the Tickflow project directory structure, file naming conventions, module descriptions, and import patterns. Understanding the code structure is essential for navigating the codebase and contributing effectively.

## File Naming Conventions

### Backend (Python)

| File Type | Naming Convention | Example |
|-----------|-------------------|---------|
| Django App | `app_name/` | `authentication/` |
| Models | `models.py` | `models.py` |
| Views | `views.py` | `views.py` |
| Serializers | `serializers.py` | `serializers.py` |
| URLs | `urls.py` | `urls.py` |
| Utilities | `utils.py` | `utils.py` |
| Middleware | `middleware.py` | `middleware.py` |
| Tests | `test_*.py` | `test_models.py` |
| Management Commands | `management/commands/*.py` | `generate_apikey.py` |

### Frontend (JavaScript/React)

| File Type | Naming Convention | Example |
|-----------|-------------------|---------|
| Components | `PascalCase.jsx` | `LoadingSpinner.jsx` |
| Pages | `PascalCase.jsx` | `Dashboard.jsx` |
| Hooks | `camelCase.js` | `useAuth.js` |
| Context | `PascalCase.jsx` | `AuthContext.jsx` |
| Services | `lowercase.js` | `client.js` |
| Utilities | `camelCase.js` | `errorHandler.js` |

## Import Patterns

### Backend Import Examples

```python
# Import from project
from authentication.models import User
from authentication.serializers import UserProfileSerializer
from stocks.utils import save_prediction, calculate_performance_metrics
from news.utils import analyze_sentiment

# Import from Django
from django.db import models
from django.http import JsonResponse
from django.core.cache import cache

# Import from third-party
import yfinance as yf
import torch
import numpy as np
```

### Frontend Import Examples

```javascript
// Import from project
import { useAuth } from '@/hooks/useAuth';
import { Button } from '@/components/ui/Button';
import apiClient from '@/services/client';
import { formatDate } from '@/utils/helpers';

// Import from third-party
import React, { useState, useEffect } from 'react';
import { useNavigate } from 'react-router-dom';
import { useQuery } from '@tanstack/react-query';
import axios from 'axios';
```

### Import Aliases

| Alias | Path |
|-------|------|
| `@/` | `./src/` |
| `@components/` | `./src/components/` |
| `@pages/` | `./src/pages/` |
| `@hooks/` | `./src/hooks/` |
| `@services/` | `./src/services/` |
| `@utils/` | `./src/utils/` |
| `@context/` | `./src/context/` |
