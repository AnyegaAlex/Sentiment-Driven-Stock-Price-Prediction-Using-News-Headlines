# 3.2 Stock Analysis API

**File:** `/wiki/3.2-Stock-Analysis-API.md`

---

## Overview

The Stock Analysis API provides a unified view of a stock's market position. It combines sentiment analysis, technical indicators, price targets, key factors, risk assessment, and an LSTM prediction into a single response. This endpoint is the primary data source for the Tickflow dashboard.

---

## Endpoint

**Method:** `GET`

**URL:** `/api/v1/stock-analysis/`

**Authentication:** Required (API Key or JWT)

---

## Parameters

| Parameter | Type | Required | Default | Valid Values | Description |
|-----------|------|----------|---------|--------------|-------------|
| `symbol` | string | Yes | — | Stock ticker (e.g., AAPL, TSLA) | The stock symbol to analyze |
| `risk_type` | string | No | `medium` | `low`, `medium`, `high` | Investor risk tolerance, influences recommendation |
| `hold_time` | string | No | `medium-term` | `short-term`, `medium-term`, `long-term` | Investment horizon, influences recommendation |

---

## Request Examples

### curl

```bash
curl -H "X-API-Key: your_api_key_here" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/?symbol=AAPL&risk_type=medium&hold_time=medium-term"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/"
headers = {"X-API-Key": API_KEY}
params = {
    "symbol": "AAPL",
    "risk_type": "medium",
    "hold_time": "medium-term"
}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";
const url = new URL("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/");
url.searchParams.append("symbol", "AAPL");
url.searchParams.append("risk_type", "medium");
url.searchParams.append("hold_time", "medium-term");

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

### JavaScript (Axios)

```javascript
import axios from 'axios';

const API_KEY = "your_api_key_here";

axios.get("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/", {
  headers: { "X-API-Key": API_KEY },
  params: {
    symbol: "AAPL",
    risk_type: "medium",
    hold_time: "medium-term"
  }
})
.then(response => console.log(response.data))
.catch(error => console.error(error));
```

## Response Schema

### Top-Level Fields

```json
{
  "success": true,
  "data": {
    "company": "Apple Inc.",
    "symbol": "AAPL",
    "recommendation": "HOLD",
    "confidence": 0.65,
    "sentiment": { ... },
    "technicalIndicators": { ... },
    "priceTargets": { ... },
    "keyFactors": [ ... ],
    "riskAssessment": { ... },
    "lstm_prediction": { ... },
    "lastUpdated": "2026-07-24T10:00:00Z"
  },
  "code": 200,
  "timestamp": "2026-07-24T10:00:00.123456Z"
}
```

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `company` | string | Full company name |
| `symbol` | string | Stock ticker |
| `recommendation` | string | Investment recommendation: `BUY`, `HOLD`, `SELL`, or `STRONG_BUY`/`STRONG_SELL` |
| `confidence` | float | Confidence score for the recommendation (0.0 to 1.0) |
| `sentiment` | object | Sentiment analysis summary (see below) |
| `technicalIndicators` | object | Technical indicators (see below) |
| `priceTargets` | object | Bullish, bearish, and base price targets |
| `keyFactors` | array | List of key factors influencing the analysis |
| `riskAssessment` | object | Risk level and horizon |
| `lstm_prediction` | object | LSTM model prediction (see below) |
| `lastUpdated` | string | ISO 8601 timestamp of the analysis |

---

### Sentiment Object

```json
"sentiment": {
  "overall": "Neutral",
  "score": 0.05,
  "recent_articles": 25
}
```

| Field | Type | Description |
|-------|------|-------------|
| `overall` | string | Sentiment label: `Bullish`, `Bearish`, or `Neutral` |
| `score` | float | Sentiment score (-1.0 to 1.0). Positive > 0.2, Negative < -0.2 |
| `recent_articles` | integer | Number of news articles analyzed in the last 7 days |

---

### Technical Indicators Object

```json
"technicalIndicators": {
  "currentPrice": 116.16,
  "sma50": 114.84,
  "sma200": 111.81,
  "rsi": 70.8,
  "support": 110.35,
  "resistance": 121.97,
  "volume": 12424000
}
```

| Field | Type | Description |
|-------|------|-------------|
| `currentPrice` | float | Latest closing price |
| `sma50` | float | 50-day Simple Moving Average |
| `sma200` | float | 200-day Simple Moving Average |
| `rsi` | float | Relative Strength Index (0-100). Overbought > 70, Oversold < 30 |
| `support` | float | Support level (20-day low) |
| `resistance` | float | Resistance level (20-day high) |
| `volume` | integer | Latest trading volume |

---

### Price Targets Object

```json
"priceTargets": {
  "bearish": 104.54,
  "base": 116.16,
  "bullish": 132.42
}
```

| Field | Type | Description |
|-------|------|-------------|
| `bearish` | float | Bearish price target (10% below base) |
| `base` | float | Current price (base case) |
| `bullish` | float | Bullish price target (14% above base) |

---

### Key Factors Array

```json
"keyFactors": [
  {
    "title": "Market Sentiment",
    "description": "Based on recent news",
    "impact": "neutral"
  }
]
```

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Short title of the factor |
| `description` | string | Detailed description |
| `impact` | string | Impact direction: `positive`, `negative`, or `neutral` |

---

### Risk Assessment Object

```json
"riskAssessment": {
  "level": "medium",
  "horizon": "medium-term"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `level` | string | Risk tolerance: `low`, `medium`, or `high` |
| `horizon` | string | Investment horizon: `short-term`, `medium-term`, or `long-term` |

---

### LSTM Prediction Object

```json
"lstm_prediction": {
  "direction": "UP",
  "confidence": 63.5,
  "fallback": false,
  "message": "LSTM prediction successful"
}
```

| Field | Type | Description |
|-------|------|-------------|
| `direction` | string | Predicted movement: `UP`, `DOWN`, or `HOLD` |
| `confidence` | float | Confidence score (0-100%) |
| `fallback` | boolean | Whether the prediction used fallback (sentiment-only) |
| `message` | string | Additional information about the prediction |

> **Note:** The LSTM prediction may be unavailable if the model is not loaded or if there is insufficient price history. In that case, a sentiment-based fallback is used.

## Error Scenarios

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| 400 | 2001 | Missing `symbol` parameter |
| 400 | 2002 | Invalid `symbol` format or unsupported ticker |
| 401 | 1001/1002 | Invalid or missing API key |
| 429 | 3001 | Rate limit exceeded |
| 500 | 9001 | Internal server error |

### Example Error (Missing Symbol)

```json
{
  "success": false,
  "error": "Stock symbol is required.",
  "code": 2001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

---

## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.
