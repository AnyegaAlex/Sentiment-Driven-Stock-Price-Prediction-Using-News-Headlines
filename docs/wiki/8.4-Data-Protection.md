# 8.6 Security Checklist

**File:** `/wiki/8.6-Security-Checklist.md`

---

## Overview

This page provides a comprehensive security verification checklist for the Tickflow platform. This checklist should be completed before deployment to production, after significant changes, and as part of regular security audits. It covers authentication, authorization, data protection, infrastructure, and incident response.

---

## Pre-Deployment Security Checklist

### Authentication Checks

| Check | Description | Status | Notes |
|-------|-------------|--------|-------|
| [ ] | JWT access token expiry is set (60 minutes) | | `ACCESS_TOKEN_LIFETIME` in settings |
| [ ] | JWT refresh token expiry is set (7 days) | | `REFRESH_TOKEN_LIFETIME` in settings |
| [ ] | API keys are hashed (PBKDF2) | | `UserAPIKey.key_hash` field |
| [ ] | API keys have optional expiry | | `UserAPIKey.expires_at` field |
| [ ] | API keys can be revoked | | `UserAPIKey.is_active` field |
| [ ] | Password validation is enabled | | Django validators |
| [ ] | Password hashing uses PBKDF2 | | `PASSWORD_HASHERS` in settings |
| [ ] | Email verification is required | | `email_verified` field |
| [ ] | Rate limiting is configured | | `DEFAULT_THROTTLE_RATES` |
| [ ] | Account lockout is implemented | | [TODO: Verify] |

### Authorization Checks

| Check | Description | Status | Notes |

| [ ] | Role-based access control is enforced | | Free, Pro, Enterprise tiers |

### Data Protection Checks

| Check | Description | Status | Notes |
|-------|-------------|--------|-------|
| [ ] | Database connections use SSL | | `sslmode=require` |
| [ ] | API keys are never logged | | Review logging code |
| [ ] | Passwords are never logged | | Review logging code |
| [ ] | JWT tokens are never logged | | Review logging code |
| [ ] | PII is not exposed in error responses | | Review error handling |
| [ ] | Data retention policy is defined | | 30 days for logs |
| [ ] | Account deletion process is implemented | | `DeleteAccountView` |
| [ ] | Encryption at rest is configured | | Render-managed |
| [ ] | HTTPS is enforced for all connections | | `SECURE_SSL_REDIRECT` |

### Security Headers Checks

| Check | Description | Status | Notes |
|-------|-------------|--------|-------|
| [ ] | `Strict-Transport-Security` header is set | | max-age=31536000 |
| [ ] | `X-Content-Type-Options: nosniff` | | `SECURE_CONTENT_TYPE_NOSNIFF` |
| [ ] | `X-Frame-Options: DENY` | | `X_FRAME_OPTIONS = 'DENY'` |
| [ ] | `Referrer-Policy: same-origin` | | `SECURE_REFERRER_POLICY` |
| [ ] | `Content-Security-Policy` header is set | | CSP middleware |
| [ ] | `X-XSS-Protection: 1; mode=block` | | `SECURE_BROWSER_XSS_FILTER` |
| [ ] | `X-Request-ID` header is set | | RequestLoggingMiddleware |
| [ ] | CORS is properly configured | | `CORS_ALLOWED_ORIGINS` |
| [ ] | CORS does not allow all origins | | `CORS_ALLOW_ALL_ORIGINS = False` |
