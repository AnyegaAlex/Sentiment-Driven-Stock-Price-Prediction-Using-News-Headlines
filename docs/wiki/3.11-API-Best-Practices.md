## Caching Strategies

### Client-Side Caching

Cache API responses client-side to reduce the number of requests and improve performance.

```javascript
const cache = new Map();
const CACHE_TTL = 5 * 60 * 1000; // 5 minutes

async function getStockAnalysis(symbol) {
  const cacheKey = `analysis_${symbol}`;
  const cached = cache.get(cacheKey);
  
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data;
  }
  
  const response = await apiClient.get(`/stock-analysis/?symbol=${symbol}`);
  cache.set(cacheKey, {
    data: response.data,
    timestamp: Date.now()
  });
  
  return response.data;
}
```

### Cache Headers

Respect cache headers sent by the API:

- `Cache-Control: max-age=300` – Cache for up to 5 minutes
- `Cache-Control: no-cache` – Do not cache this response

### Stale-While-Revalidate

Implement a stale-while-revalidate pattern for a better user experience:

```javascript
let cachedData = null;
let isFetching = false;

async function getDataWithStaleWhileRevalidate(symbol) {
  // Return cached data immediately if available
  if (cachedData) {
    // Refresh in background
    if (!isFetching) {
      isFetching = true;
      refreshData(symbol).finally(() => {
        isFetching = false;
      });
    }
    return cachedData;
  }
  
  // First fetch
  return refreshData(symbol);
}
```

## Error Handling

### Exponential Backoff

Implement exponential backoff for retrying failed requests:

```javascript
async function apiRequestWithBackoff(url, options, maxRetries = 5) {
  let retryCount = 0;
  let delay = 1000; // Start with 1 second
  
  while (retryCount < maxRetries) {
    try {
      const response = await fetch(url, options);
      
      if (response.status === 429) {
        const retryAfter = parseInt(response.headers.get('Retry-After')) || delay;
        console.log(`Rate limited. Waiting ${retryAfter}ms.`);
        await new Promise(resolve => setTimeout(resolve, retryAfter));
        retryCount++;
        delay *= 2; // Exponential backoff
        continue;
      }
      
      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }
      
      return response;
    } catch (error) {
      retryCount++;
      if (retryCount >= maxRetries) throw error;
      await new Promise(resolve => setTimeout(resolve, delay));
      delay *= 2;
    }
  }
}
```

### Error Classification

Classify errors for appropriate handling:

```javascript
function handleApiError(error) {
  if (error.code === 1001 || error.code === 1002) {
    // Authentication error – refresh API key
    refreshApiKey();
  } else if (error.code === 3001) {
    // Rate limit error – wait and retry
    const retryAfter = error.retryAfter || 60;
    setTimeout(() => retryRequest(), retryAfter * 1000);
  } else if (error.code >= 2000 && error.code < 3000) {
    // Validation error – show user feedback
    showValidationError(error.details);
  } else if (error.code >= 4000 && error.code < 5000) {
    // Resource error – show not found message
    showNotFoundError();
  } else if (error.code >= 9000) {
    // Server error – log and alert
    logError(error);
    showServerError();
  }
}
```

### Graceful Degradation

Implement graceful degradation when API calls fail:

```javascript
async function getDataWithFallback(symbol) {
  try {
    const data = await apiClient.get(`/stock-analysis/?symbol=${symbol}`);
    return data;
  } catch (error) {
    console.warn('API request failed, using fallback data', error);
    return getFallbackData(symbol);
  }
}
```

## Idempotency

### Idempotency-Key Header

For POST, PUT, and PATCH requests, use the `Idempotency-Key` header to prevent duplicate requests:

```javascript
function generateIdempotencyKey() {
  return `${Date.now()}-${Math.random().toString(36).substring(2, 9)}`;
}

async function subscribeEmail(email) {
  const response = await apiClient.post('/subscribe/', 
    { email },
    {
      headers: {
        'Idempotency-Key': generateIdempotencyKey()
      }
    }
  );
  return response;
}
```

### Benefits of Idempotency

- Prevents duplicate email subscriptions
- Avoids duplicate predictions
- Ensures data consistency
- Improves reliability in retry scenarios

## Performance Optimization

### Pagination

Use pagination parameters (`limit` and `offset`) to limit response size:

```javascript
// Good – paginated request
const response = await apiClient.get('/prediction-history/?limit=25&offset=0');

// Bad – requesting all data at once
const response = await apiClient.get('/prediction-history/?limit=10000');
```

### Selective Fields

Request only the fields you need:

```javascript
// If supported by the API
const response = await apiClient.get('/prediction-history/?fields=id,symbol,prediction,confidence');
```

### Batch Requests

Combine multiple requests when possible:

```javascript
// Bad – multiple individual requests
for (const symbol of ['AAPL', 'TSLA', 'GOOGL']) {
  await apiClient.get(`/stock-analysis/?symbol=${symbol}`);
}

// Good – batch request (if endpoint supports it)
const response = await apiClient.get('/stock-analysis/?symbols=AAPL,TSLA,GOOGL');
```

### Compression

Enable compression in your HTTP client:

```javascript
// Axios example
const client = axios.create({
  headers: {
    'Accept-Encoding': 'gzip, deflate, br'
  }
});
```

## Rate Limit Management

### Monitor Usage

Monitor rate limit headers to avoid hitting limits:

```javascript
function parseRateLimitHeaders(response) {
  return {
    limit: parseInt(response.headers['x-ratelimit-limit']),
    remaining: parseInt(response.headers['x-ratelimit-remaining']),
    reset: parseInt(response.headers['x-ratelimit-reset'])
  };
}

async function makeRequest() {
  const response = await apiClient.get('/stock-analysis/?symbol=AAPL');
  const rateLimit = parseRateLimitHeaders(response);
  
  if (rateLimit.remaining < 10) {
    console.warn(`Low remaining limit: ${rateLimit.remaining}`);
    // Consider queuing requests or slowing down
  }
  
  return response;
}
```

### Request Queuing

Implement request queuing to smooth out traffic:

```javascript
class RequestQueue {
  constructor(maxConcurrent = 10) {
    this.queue = [];
    this.active = 0;
    this.maxConcurrent = maxConcurrent;
  }
  
  async add(requestFn) {
    return new Promise((resolve, reject) => {
      this.queue.push({ requestFn, resolve, reject });
      this.process();
    });
  }
  
  async process() {
    if (this.active >= this.maxConcurrent || this.queue.length === 0) {
      return;
    }
    
    this.active++;
    const { requestFn, resolve, reject } = this.queue.shift();
    
    try {
      const result = await requestFn();
      resolve(result);
    } catch (error) {
      reject(error);
    } finally {
      this.active--;
      this.process();
    }
  }
}

// Usage
const queue = new RequestQueue(10);
const response = await queue.add(() => 
  apiClient.get('/stock-analysis/?symbol=AAPL')
);
```

## Security Best Practices

### API Key Storage

- **Never** store API keys in client-side code
- Use environment variables or secure secrets management
- Rotate keys regularly (every 90 days recommended)

### HTTPS

Always use HTTPS to encrypt data in transit.

```javascript
// Good
const url = 'https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/';

// Bad
const url = 'http://sentiment-driven-stock-price-prediction.onrender.com/api/v1/';
```

### Input Validation

Validate all user inputs on the client side before sending to the API:

```javascript
function validateSymbol(symbol) {
  if (!symbol || typeof symbol !== 'string') {
    return false;
  }
  if (symbol.length > 10) {
    return false;
  }
  if (!/^[A-Z0-9.]{1,10}$/.test(symbol)) {
    return false;
  }
  return true;
}
```
