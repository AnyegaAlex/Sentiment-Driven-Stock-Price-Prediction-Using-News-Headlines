# 7.1 Setting Up Development Environment

**File:** `/wiki/7.1-Development-Environment.md`

## Overview

This page provides a comprehensive guide for setting up a local development environment for Tickflow. Following these steps will get you a fully functional development instance with hot-reload, debug tools, and mock data support.


## Backend Setup

### 1. Create Virtual Environment

```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment
# macOS/Linux:
source .venv/bin/activate

# Windows:
.venv\Scripts\activate

# Verify activation
which python  # Should point to .venv/bin/python
```

### 2. Install Dependencies

```bash
# Install development dependencies
pip install -r requirements.txt

# Install additional development tools (optional)
pip install pytest pytest-django pytest-cov black flake8 isort bandit
```

### 3. Configure Environment Variables

```bash
# Copy example environment file
cp .env.example .env

# Edit .env file with your settings
nano .env  # or use your preferred editor
```

**.env Configuration:**

```bash
# Django Configuration
SECRET_KEY=django-insecure-abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

# Database Configuration
DATABASE_URL=postgresql://tickflow_user:password@localhost:5432/tickflow_db

# CORS Configuration
FRONTEND_URL=http://localhost:5173

# API Keys (Required for some features)
ALPHA_VANTAGE_KEY=your-alpha-vantage-key-here
FINNHUB_API_KEY=your-finnhub-key-here  # Optional
RAPIDAPI_KEY=your-rapidapi-key-here  # Optional

# Cache Configuration
REDIS_URL=redis://localhost:6379/1

# LSTM Configuration
ENABLE_LSTM=False  # Set to True if model is available
LSTM_MODEL_PATH=./models/stock_prediction_model.pth

# Logging
USE_JSON_LOGS=False
```

### 4. Set Up PostgreSQL Database

```bash
# Start PostgreSQL service
# macOS:
brew services start postgresql@16

# Ubuntu/Debian:
sudo systemctl start postgresql

# Create database and user
psql -U postgres
```

**SQL Commands:**

```sql
CREATE DATABASE tickflow_db;
CREATE USER tickflow_user WITH PASSWORD 'password';
GRANT ALL PRIVILEGES ON DATABASE tickflow_db TO tickflow_user;
\q
```

### 5. Run Migrations

```bash
# Run all migrations
python manage.py migrate

# Create cache table
python manage.py createcachetable

# Verify migrations
python manage.py showmigrations
```

### 6. Create Superuser (Optional)

```bash
python manage.py createsuperuser
# Follow the prompts to create an admin user
```

### 7. Generate API Key

```bash
# Generate an API key for development
python manage.py generate_apikey "Development"

# Save the key for frontend configuration
# Example output: ts_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
```

### 8. Start the Backend Development Server

```bash
# Start the Django development server
python manage.py runserver

# The backend will be available at: http://localhost:8000

# For verbose logging (optional):
python manage.py runserver --verbosity 3
```

### 9. Verify Backend is Working

```bash
# Check health endpoint
curl http://localhost:8000/health/

# Expected response:
# {"status": "ok", "redis": false}

# Check API with API key
curl -H "X-API-Key: your_api_key_here" \
  "http://localhost:8000/api/v1/stock-analysis/?symbol=AAPL"
```

## Frontend Setup

### 1. Navigate to Frontend Directory

```bash
cd frontend
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

```bash
# Copy example environment file
cp .env.example .env.development

# Edit .env.development file
nano .env.development
```

**.env.development Configuration:**

```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_API_KEY=your_api_key_from_backend
VITE_USE_MOCK_DATA=false
VITE_APP_VERSION=1.0.0
```

### 4. Start the Frontend Development Server

```bash
# Start the Vite development server
npm run dev

# The frontend will be available at: http://localhost:5173
```

### 5. Verify Frontend is Working

1. Open `http://localhost:5173` in your browser
2. Login using the superuser credentials or register a new account
3. Verify that the dashboard loads and fetches data

## Docker Setup

### 1. Build and Run with Docker Compose

```bash
# Build the containers
docker-compose build

# Start the containers in detached mode
docker-compose up -d

# View logs
docker-compose logs -f
```

### 2. Run Migrations Inside Container

```bash
# Run migrations
docker-compose exec web python manage.py migrate

# Generate API key
docker-compose exec web python manage.py generate_apikey "Development"

# Create superuser
docker-compose exec web python manage.py createsuperuser
```

### 3. Access the Application

- **Backend:** `http://localhost:8000`
- **Frontend:** `http://localhost:5173`
- **API Docs:** `http://localhost:8000/api/docs/`

### 4. Stop the Containers

```bash
# Stop containers
docker-compose down

# Stop and remove volumes
docker-compose down -v
```

```bash

pip install black flake8 isort

# Configure Black (pyproject.toml)
[tool.black]
line-length = 88
target-version = ['py312']

# Configure flake8 (.flake8)
[flake8]
max-line-length = 88
extend-ignore = E203, W503
```

### Pre-commit Hooks

```bash
# Install pre-commit
pip install pre-commit

# Install the git hook scripts
pre-commit install

# Run against all files
pre-commit run --all-files
```

**.pre-commit-config.yaml:**

```yaml
repos:
  - repo: https://github.com/psf/black
    rev: 23.7.0
    hooks:
      - id: black
  - repo: https://github.com/pycqa/isort
    rev: 5.12.0

      - id: isort
        args: ["--profile", "black"]
  - repo: https://github.com/pycqa/flake8

      - id: flake8
```

## Troubleshooting

### Issue: Database Connection Refused

**Error:** `could not connect to server: Connection refused`

**Solution:**

```bash
# Start PostgreSQL
# macOS:
brew services start postgresql@16

# Ubuntu:
sudo systemctl start postgresql

# Check status
ps aux | grep postgres
```

### Issue: Redis Connection Refused

**Error:** `Connection refused` for Redis

**Solution:**

```bash
# Start Redis
# macOS:
brew services start redis

# Ubuntu:
sudo systemctl start redis-server

# Check status
redis-cli ping  # Should return PONG
```

### Issue: Port Already in Use

**Error:** `Address already in use` or `port already in use`

**Solution:**

```bash
# Find process using port 8000
lsof -i :8000

# Kill process
kill -9 PID

# Or use a different port
python manage.py runserver 8001
```

### Issue: ModuleNotFoundError

**Error:** `ModuleNotFoundError: No module named '...'`

**Solution:**

```bash
# Ensure virtual environment is active
source .venv/bin/activate

# Reinstall dependencies
pip install -r requirements.txt
```

### Issue: CORS Error

**Error:** `No 'Access-Control-Allow-Origin' header`

**Solution:**

```bash
# Verify FRONTEND_URL in .env
FRONTEND_URL=http://localhost:5173

# Restart the backend server
python manage.py runserver
```

### Issue: API Key Invalid

**Error:** `Invalid or inactive API key`

**Solution:**

```bash
# Generate a new API key
python manage.py generate_apikey "Development"

# Update VITE_API_KEY in frontend .env.development
VITE_API_KEY=ts_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
```

## IDE Setup Recommendations

### Visual Studio Code

**Workspace Settings (.vscode/settings.json):**

```json
{
  "python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python",
  "python.formatting.provider": "black",
  "python.linting.flake8Enabled": true,
  "python.linting.enabled": true,
  "[python]": {
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
      "source.organizeImports": "explicit"
    }
  },
  "[javascript]": {
    "editor.formatOnSave": true
  },
  "[javascriptreact]": {
    "editor.formatOnSave": true
  }
}
```

### PyCharm

1. Set Python interpreter: Preferences → Project → Python Interpreter → Add → Existing environment → Select `.venv/bin/python`
2. Enable Black formatting: Preferences → Tools → Black → Enable
3. Configure Django support: Preferences → Languages & Frameworks → Django → Enable Django support
