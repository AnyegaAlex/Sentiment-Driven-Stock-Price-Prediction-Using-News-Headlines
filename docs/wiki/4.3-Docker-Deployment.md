## Overview

This guide covers deploying Tickflow using Docker. Docker provides a consistent, isolated environment for running the application across different platforms. It simplifies dependency management and ensures the same runtime environment in development and production.

## Dockerfile Breakdown

The Dockerfile defines how the backend container is built.

### Dockerfile

```dockerfile
# Dockerfile
FROM python:3.12-slim

# Set environment variables
ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PYTHONPATH=/app \
    DEBIAN_FRONTEND=noninteractive

# Set work directory
WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    gcc \
    libpq-dev \
    curl \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY . .

# Run migrations and collect static files
RUN python manage.py migrate \
    && python manage.py collectstatic --noinput

# Create a non-root user
RUN addgroup --system --gid 1001 appgroup \
    && adduser --system --uid 1001 --gid 1001 appuser \
    && chown -R appuser:appgroup /app

USER appuser

# Expose port
EXPOSE 8000

# Start Gunicorn
CMD ["gunicorn", "sentiment_driven_stock_price_prediction_engine.wsgi:application", \
     "--bind", "0.0.0.0:8000", \
     "--workers", "4", \
     "--threads", "2", \
     "--timeout", "120"]
```

### Dockerfile Sections

| Section | Purpose |
|---------|---------|
| **FROM** | Base image with Python 3.12 |
| **ENV** | Environment variables for Python |
| **WORKDIR** | Working directory inside the container |
| **RUN (system)** | Install system dependencies |
| **RUN (pip)** | Install Python dependencies |
| **COPY** | Copy application code |
| **RUN (migrate)** | Run database migrations |
| **USER** | Switch to non-root user |
| **EXPOSE** | Port 8000 for the application |
| **CMD** | Start Gunicorn server |

## Docker Compose Configuration

The `docker-compose.yml` file defines the multi-container setup.

### docker-compose.yml

```yaml
version: '3.8'

services:
  # PostgreSQL Database
  db:
    image: postgres:16
    container_name: tickflow-db
    environment:
      POSTGRES_USER: tickflow
      POSTGRES_PASSWORD: tickflow
      POSTGRES_DB: tickflow
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U tickflow"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Redis Cache
  redis:
    image: redis:7
    container_name: tickflow-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  # Backend Application
  web:
    build: .
    container_name: tickflow-web
    environment:
      SECRET_KEY: ${SECRET_KEY}
      DEBUG: ${DEBUG:-False}
      DATABASE_URL: postgresql://tickflow:tickflow@db:5432/tickflow
      REDIS_URL: redis://redis:6379/1
      ALLOWED_HOSTS: localhost,127.0.0.1
      FRONTEND_URL: ${FRONTEND_URL:-http://localhost:5173}
      ALPHA_VANTAGE_KEY: ${ALPHA_VANTAGE_KEY}
      FINNHUB_API_KEY: ${FINNHUB_API_KEY}
      ENABLE_LSTM: ${ENABLE_LSTM:-False}
      SENTRY_DSN: ${SENTRY_DSN}
    ports:
      - "8000:8000"
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_healthy
    volumes:
      - ./staticfiles:/app/staticfiles
      - ./media:/app/media

  # Frontend (Optional)
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: tickflow-frontend
    environment:
      VITE_API_BASE_URL: http://localhost:8000
      VITE_API_KEY: ${VITE_API_KEY}
      VITE_USE_MOCK_DATA: false
    ports:
      - "5173:5173"
    depends_on:
      - web

volumes:
  postgres_data:
  redis_data:
```

### Service Descriptions

| Service | Purpose | Port |
|---------|---------|------|
| **db** | PostgreSQL database | 5432 |
| **redis** | Redis cache | 6379 |
| **web** | Django backend | 8000 |
| **frontend** | React frontend (optional) | 5173 |

## Build and Run Commands

### Build Images

```bash
# Build all services
docker-compose build

# Build specific service
docker-compose build web
```

### Start Services

```bash
# Start all services in detached mode
docker-compose up -d

# Start specific service
docker-compose up web

# Start with logs
docker-compose up -d && docker-compose logs -f
```

### Stop Services

```bash
# Stop all services
docker-compose down

# Stop and remove volumes
docker-compose down -v
```

### View Logs

```bash
# View all logs
docker-compose logs

# View specific service logs
docker-compose logs web

# Follow logs in real-time
docker-compose logs -f web
```

### Execute Commands

```bash
# Run migrations
docker-compose exec web python manage.py migrate

# Generate API key
docker-compose exec web python manage.py generate_apikey "Development"

# Create superuser
docker-compose exec web python manage.py createsuperuser

# Open Django shell
docker-compose exec web python manage.py shell

# Access database
docker-compose exec db psql -U tickflow -d tickflow
```

## Production vs Development Configuration

### Development Configuration

```yaml
# docker-compose.yml (development)
environment:
  DEBUG: "True"
  ALLOWED_HOSTS: localhost,127.0.0.1
```

### Production Configuration

```yaml
# docker-compose.yml (production)
environment:
  DEBUG: "False"
  ALLOWED_HOSTS: tickflow.example.com
```

### Production Environment File

```bash
# .env.production
SECRET_KEY=your-production-secret-key
DEBUG=False
FRONTEND_URL=https://tickflow.example.com
ALPHA_VANTAGE_KEY=production-alpha-vantage-key
ENABLE_LSTM=True
```

**Production Run Command:**

```bash
docker-compose --env-file .env.production up -d
```

## Troubleshooting Container Issues

### Issue: Container Not Starting

**Error:** Container exits immediately

**Solution:**
1. Check logs: `docker-compose logs web`
2. Verify environment variables: `docker-compose exec web env`
3. Check for syntax errors: `docker-compose config`

### Issue: Database Connection Failed

**Error:** `can't connect to PostgreSQL`

**Solution:**
1. Wait for database to be healthy: `docker-compose logs db`
2. Verify database credentials in `.env`
3. Check network: `docker-compose exec web ping db`

### Issue: Port Already in Use

**Error:** `port already allocated`

**Solution:**
1. Change ports in `docker-compose.yml`
2. Stop existing containers on the port

```bash
# Find processes using port
lsof -i :8000

# Change port in docker-compose.yml
ports:
  - "8001:8000"
```

### Issue: Volume Permission Errors

**Error:** `Permission denied` for volumes

**Solution:**
1. Check volume permissions
2. Use Docker managed volumes
3. Set correct user/group in Dockerfile

### Issue: Out of Memory

**Error:** `Memory limit exceeded`

**Solution:**
1. Increase memory limit for containers
2. Use `docker-compose` memory limits

```yaml
services:
  web:
    deploy:
      resources:
        limits:
          memory: 2G
        reservations:
          memory: 512M
```

## Deployment on Production Servers

### 1. Server Setup

```bash
# Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Install Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# Add user to docker group
sudo usermod -aG docker $USER
```

### 2. Clone Repository

```bash
git clone https://github.com/AnyegaAlex/Sentiment-Driven-Stock-Price-Prediction-Using-News-Headlines.git
cd sentiment_driven_stock_price_prediction_engine
```

### 3. Configure Production Environment

```bash
cp .env.example .env.production
# Edit .env.production with production values
```

### 4. Deploy

```bash
# Build and start in production mode
docker-compose --env-file .env.production up -d --build

# Verify deployment
curl http://localhost:8000/health/
```

### 5. Reverse Proxy (Nginx)

For production, use Nginx as a reverse proxy:

```nginx
# /etc/nginx/sites-available/tickflow
server {
    listen 80;
    server_name tickflow.example.com;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
