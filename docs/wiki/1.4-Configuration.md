## Backend Environment Variables

The backend configuration is stored in `.env` file located at the project root: `sentiment_driven_stock_price_prediction_engine/.env`.

### Required Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `SECRET_KEY` | Django secret key used for cryptographic signing | `django-insecure-abc123def456...` |
| `DEBUG` | Development mode flag. Set to `True` for development, `False` for production | `True` or `False` |
| `DATABASE_URL` | PostgreSQL database connection string | `postgresql://user:pass@localhost:5432/tickflow` |
| `ALLOWED_HOSTS` | Comma-separated list of allowed hostnames | `localhost,127.0.0.1,api.yourdomain.com` |
| `FRONTEND_URL` | Frontend URL for CORS configuration | `http://localhost:5173` or `https://your-frontend.vercel.app` |
| `ALPHA_VANTAGE_KEY` | Alpha Vantage API key for stock and news data | `your-alpha-vantage-key` |

### Optional Variables

| Variable | Description | Default | Example |
|----------|-------------|---------|---------|
| `FINNHUB_API_KEY` | Finnhub API key for news data | None | `your-finnhub-key` |
| `RAPIDAPI_KEY` | RapidAPI key for additional data sources | None | `your-rapidapi-key` |
| `RAPIDAPI_HOST` | RapidAPI host endpoint | `apidojo-yahoo-finance-v1.p.rapidapi.com` | `your-custom-host` |
| `REDIS_URL` | Redis connection string for caching | `redis://localhost:6379/1` | `redis://redis:6379/1` |
| `ENABLE_LSTM` | Enable LSTM predictions (requires model file) | `False` | `True` or `False` |
| `LSTM_MODEL_PATH` | Path to the LSTM model file | `models/stock_prediction_model.pth` | `/app/models/model.pth` |
| `STATIC_API_KEY` | Static API key fallback (not recommended for production) | None | `your-static-key` |
| `SENTRY_DSN` | Sentry DSN for error tracking | None | `https://your-sentry-dsn` |
| `SENTRY_ENVIRONMENT` | Sentry environment identifier | `production` | `staging` or `production` |
| `USE_JSON_LOGS` | Enable JSON format for logs | `false` | `true` or `false` |

### Example `.env` File

```bash
# Django Configuration
SECRET_KEY=django-insecure-abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

# Database Configuration
DATABASE_URL=postgresql://tickflow_user:secure_password@localhost:5432/tickflow_db

# CORS Configuration
FRONTEND_URL=http://localhost:5173

# API Keys
ALPHA_VANTAGE_KEY=your-alpha-vantage-key-here
FINNHUB_API_KEY=your-finnhub-key-here

# Cache Configuration
REDIS_URL=redis://localhost:6379/1

# LSTM Configuration
ENABLE_LSTM=True
LSTM_MODEL_PATH=./models/stock_prediction_model.pth

# Logging
USE_JSON_LOGS=False
```

## Frontend Environment Variables

The frontend configuration is stored in `.env.development` or `.env.production` file located at: `frontend/.env.development`

### Required Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `VITE_API_BASE_URL` | Backend API base URL | `http://localhost:8000` or `https://your-backend.onrender.com` |
| `VITE_API_KEY` | API key for authentication with the backend | `your-api-key-from-backend` |

### Optional Variables

| Variable | Description | Default | Example |
|----------|-------------|---------|---------|
| `VITE_USE_MOCK_DATA` | Use mock data instead of real API calls | `false` | `true` or `false` |
| `VITE_APP_VERSION` | Application version displayed in the UI | `1.0.0` | `1.0.0` |
| `VITE_GA_MEASUREMENT_ID` | Google Analytics measurement ID | None | `G-XXXXXXXXXX` |
| `VITE_SENTRY_DSN` | Sentry DSN for frontend error tracking | None | `https://your-sentry-dsn` |

### Example `.env.development` File

```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_API_KEY=your-api-key-here
VITE_USE_MOCK_DATA=false
VITE_APP_VERSION=1.0.0
```

### Example `.env.production` File

```bash
VITE_API_BASE_URL=https://sentiment-driven-stock-price-prediction.onrender.com
VITE_API_KEY=your-production-api-key
VITE_USE_MOCK_DATA=false
VITE_APP_VERSION=1.0.0
```

## Database Configuration

### PostgreSQL Setup

1. **Install PostgreSQL**

```bash
# Ubuntu/Debian
sudo apt-get install postgresql-16

# macOS
brew install postgresql@16

# Windows
# Download installer from https://www.postgresql.org/download/windows/
```

2. **Create Database and User**

```sql
CREATE DATABASE tickflow_db;
CREATE USER tickflow_user WITH PASSWORD 'secure_password';
GRANT ALL PRIVILEGES ON DATABASE tickflow_db TO tickflow_user;
```

3. **Configure DATABASE_URL**

```bash
DATABASE_URL=postgresql://tickflow_user:secure_password@localhost:5432/tickflow_db
```

4. **SSL Configuration (Production)**

For production environments, add SSL requirement:

```bash
DATABASE_URL=postgresql://tickflow_user:secure_password@localhost:5432/tickflow_db?sslmode=require
```

## Redis Configuration

Redis is used for caching and rate limiting. It is optional but recommended for production.

### Install Redis

```bash
# Ubuntu/Debian
sudo apt-get install redis-server

# macOS
brew install redis

# Windows
# Use WSL2 or Docker
```

### Start Redis

```bash
# Ubuntu/Debian
sudo systemctl start redis-server

# macOS
brew services start redis

# Docker
docker run -d -p 6379:6379 redis:7
```

### Configure REDIS_URL

```bash
REDIS_URL=redis://localhost:6379/1
```

## API Key Generation

API keys are required for authenticated API access. Generate keys using the Django management command.

### Development Environment

```bash
python manage.py generate_apikey "Development"
```

### Production Environment

```bash
python manage.py generate_apikey "Production Frontend"
```

### Save the Generated Key

The command outputs the key once. Save it in a secure location.

```
Generated API Key: ts_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
```

## Configuration Verification

### Verify Backend Configuration

```bash
# Check environment variables
python manage.py shell
>>> import os
>>> print(os.environ.get('DATABASE_URL'))

# Check database connection
python manage.py dbshell

# Check Redis connection (if configured)
python manage.py shell
>>> from django.core.cache import cache
>>> cache.set('test', 'ok', 10)
>>> cache.get('test')
```

### Verify Frontend Configuration

1. Open the browser console
2. Check that `VITE_API_BASE_URL` is correct:

```javascript
console.log(import.meta.env.VITE_API_BASE_URL);
```

3. Verify that API calls are being made to the correct backend URL using the Network tab in DevTools.

## Troubleshooting Configuration Issues

| Issue | Solution |
|-------|----------|
| `Environment variable not set` | Verify the variable is defined in `.env` file |
| `Database connection refused` | Check PostgreSQL is running and credentials are correct |
| `CORS error` | Verify `FRONTEND_URL` matches your frontend URL exactly |
| `Invalid API key` | Generate a new key and update `VITE_API_KEY` |
| `Redis connection failed` | Verify Redis is running and `REDIS_URL` is correct |
| `LSTM model not found` | Set `ENABLE_LSTM=False` or provide correct `LSTM_MODEL_PATH` |
