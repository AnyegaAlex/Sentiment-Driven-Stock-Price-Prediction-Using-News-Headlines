## Overview

This page provides a detailed overview of the machine learning pipeline in Tickflow. The ML pipeline encompasses LSTM model training and inference, FinBERT sentiment analysis, technical indicator computation, and the hybrid model that combines these components for stock movement prediction.

## LSTM Model Architecture

### Model Definition

The LSTM model is defined in `stocks/lstm_predictor.py`.

```python
# stocks/lstm_predictor.py
class LSTMModel(nn.Module):
    """
    Simple 1-layer LSTM with a linear output head.
    Input size: 7 (sentiment + 6 technicals)
    Hidden size: 32 (as in training)
    Output: 1 (sigmoid for probability of UP)
    """
    def __init__(self, input_size: int, hidden_size: int, output_size: int):
        super(LSTMModel, self).__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        _, (hidden, _) = self.lstm(x)
        return self.fc(hidden[-1])
```

### Model Parameters

| Parameter | Value | Description |
|-----------|-------|-------------|
| Input Size | 7 | Sentiment score + 6 technical indicators |
| Hidden Size | 32 | LSTM hidden layer size |
| Output Size | 1 | Sigmoid output (UP probability) |
| Activation | Sigmoid | Output activation |
| Loss Function | BCELoss | Binary Cross Entropy |
| Optimizer | Adam | Adaptive Moment Estimation |
| Learning Rate | 0.001 | Initial learning rate |
| Epochs | 100 | Training iterations |

### Input Features

The model takes 7 input features:

| Feature | Description | Source |
|---------|-------------|--------|
| Sentiment Score | FinBERT sentiment (-1 to 1) | News analysis |
| MA7 | 7-day Simple Moving Average | Price data |
| MA21 | 21-day Simple Moving Average | Price data |
| STD21 | 21-day Standard Deviation | Price data |
| RSI14 | 14-day Relative Strength Index | Price data |
| UpperBB | Upper Bollinger Band | Price data |
| LowerBB | Lower Bollinger Band | Price data |

### Training Data

| Aspect | Description |
|--------|-------------|
| Data Source | 5+ years of historical price data |
| Data Frequency | Daily closing prices |
| Preprocessing | Normalization, windowing |
| Feature Engineering | Technical indicators computed from price data |
| Sentiment | Simulated sentiment for training (ground truth needed) |

### Training Process

1. **Data Collection**: Historical price data and sentiment scores
2. **Feature Engineering**: Compute technical indicators for each day
3. **Normalization**: Scale features to standard range
4. **Windowing**: Create sequences of 7 features
5. **Labeling**: Direction of next day's movement (UP/DOWN)
6. **Training**: BCELoss with Adam optimizer
7. **Validation**: Hold-out set for evaluation
8. **Model Persistence**: Save as `stock_prediction_model.pth`

## Sentiment Analysis (FinBERT)

### Model Overview

FinBERT is a pre-trained transformer model fine-tuned on financial news for sentiment analysis.

```python
# news/utils.py (simplified)
from transformers import AutoTokenizer, AutoModelForSequenceClassification

class FinBERTClassifier:
    def __init__(self):
        self.model_name = "distilbert-base-uncased-finetuned-sst-2-english"
        self.tokenizer = AutoTokenizer.from_pretrained(self.model_name)
        self.model = AutoModelForSequenceClassification.from_pretrained(self.model_name)

    def analyze(self, text: str) -> dict:
        inputs = self.tokenizer(text, return_tensors="pt", truncation=True, max_length=512)
        outputs = self.model(**inputs)
        probs = torch.softmax(outputs.logits, dim=1)
        confidence = probs.max().item()
        label = "positive" if probs.argmax().item() == 0 else "negative"
        return {"label": label, "confidence": confidence}
```

### Sentiment Scoring

| Score Range | Classification | Meaning |
|-------------|----------------|---------|
| > 0.2 | Positive | Bullish sentiment |
| -0.2 to 0.2 | Neutral | Mixed or neutral sentiment |
| < -0.2 | Negative | Bearish sentiment |

### News Processing Pipeline

```
1. Fetch news articles from external APIs (Alpha Vantage, Finnhub)
2. Deduplicate articles using SHA-256
3. Clean text using spaCy (remove stopwords, punctuation)
4. Run FinBERT inference for sentiment classification
5. Extract key phrases using spaCy
6. Store sentiment scores and metadata in database
7. Cache results in Redis for quick access
```

## Hybrid Model

### Feature Concatenation

The hybrid model combines LSTM output with sentiment score and technical indicators:

```
LSTM Output (prediction probability)
       +
Sentiment Score (-1 to 1)
       +
Technical Indicators (MA7, MA21, RSI, etc.)
       │
       ▼
Final Prediction (UP/DOWN/HOLD)
       │
       ▼
Confidence Score (0-100%)
```

### Weighting Strategy

| Component | Weight | Description |
|-----------|--------|-------------|
| LSTM | 50% | Neural network prediction |
| Sentiment | 30% | FinBERT sentiment analysis |
| Technicals | 20% | Technical indicator analysis |

### Fallback Mechanisms

| Scenario | Fallback | Response |
|----------|----------|----------|
| LSTM model not loaded | Sentiment + technicals | `fallback: true` |
| Insufficient price history | Sentiment only | `fallback: true` |
| Feature computation error | Sentiment only | `fallback: true` |
| Model inference error | Sentiment only | `fallback: true` |

### Fallback Logic

```python
# stocks/lstm_predictor.py
def get_sentiment_fallback(symbol: str, news_text: str = "") -> dict:
    """Generate prediction based on sentiment when LSTM is unavailable."""
    sentiment_score = analyze_sentiment(news_text or get_recent_news(symbol))
    
    if sentiment_score > 0.2:
        direction = 'UP'
        confidence = min(abs(sentiment_score) * 100, 90) + 10
    elif sentiment_score < -0.2:
        direction = 'DOWN'
        confidence = min(abs(sentiment_score) * 100, 90) + 10
    else:
        direction = 'HOLD'
        confidence = 50.0
    
    return {
        'prediction': direction,
        'confidence': round(confidence, 1),
        'sentiment_score': sentiment_score,
        'fallback': True,
        'message': 'Using sentiment-based fallback'
    }
```

## Model Evaluation

### Performance Metrics

| Metric | Description | Formula |
|--------|-------------|---------|
| Accuracy | Correct predictions / Total predictions | (TP + TN) / (TP + TN + FP + FN) |
| Precision | True positives / All positive predictions | TP / (TP + FP) |
| Recall | True positives / All actual positives | TP / (TP + FN) |
| F1 Score | Harmonic mean of Precision and Recall | 2 * (P * R) / (P + R) |
| Balanced Accuracy | Average of recall per class | (TP/(TP+FN) + TN/(TN+FP)) / 2 |

### Confusion Matrix

### Drift Detection

**Drift Thresholds:**

| Metric | Condition | Severity |
|--------|-----------|----------|
| F1 Score Drop | > 10% | Low |
| F1 Score Drop | > 15% | Medium |
| F1 Score Drop | > 20% | High |
| Absolute Drop | > 0.1 | Any |

**Drift Detection Implementation:**

```python
# stocks/utils.py
def detect_drift(recent_period_days=30, baseline_period_days=90):
    recent_f1 = get_f1_score(recent_period_days)
    baseline_f1 = get_f1_score(baseline_period_days)
    
    drop = baseline_f1 - recent_f1
    drop_pct = (drop / baseline_f1) * 100 if baseline_f1 > 0 else 0
    
    if drop_pct > 10 or drop > 0.1:
        severity = 'high' if drop_pct > 20 else 'medium' if drop_pct > 15 else 'low'
        return {'drift_detected': True, 'severity': severity, 'drop_percent': drop_pct}
    
    return {'drift_detected': False}
```

### Resolution Implementation

```python
# stocks/utils.py
def resolve_prediction(prediction, resolution_days=7):
    try:
        resolution_date = prediction.date + timedelta(days=resolution_days)
        
        # Get prices
        pred_price = get_price_at_date(prediction.stock_symbol, prediction.date)
        res_price = get_price_at_date(prediction.stock_symbol, resolution_date)
        
        if pred_price is None or res_price is None:
            return False
        
        # Determine direction
        if res_price > pred_price:
            prediction.actual_direction = 'up'
        elif res_price < pred_price:
            prediction.actual_direction = 'down'
        else:
            prediction.actual_direction = 'neutral'
        
        prediction.is_correct = (prediction.actual_direction == prediction.predicted_movement)
        prediction.price_at_prediction = pred_price
        prediction.price_at_resolution = res_price
        prediction.price_change_percent = ((res_price - pred_price) / pred_price) * 100
        prediction.resolution_date = timezone.now()
        prediction.save()
        
        return True
    except Exception as e:
        logger.error(f"Error resolving prediction {prediction.id}: {e}")
        return False
```

### Production Serving

In production, the model is loaded by `LSTMPredictor` class and used for inference on-demand:

```python
# stocks/lstm_predictor.py
class LSTMPredictor:
    def __init__(self, model_path=None):
        self.model_path = model_path or getattr(settings, 'LSTM_MODEL_PATH')
        self.device = torch.device("cpu")
        self.model = None
        self._load_model()

    def _load_model(self):
        """Load the LSTM model from the .pth file."""
        try:
            model = LSTMModel(7, 32, 1)
            state_dict = torch.load(self.model_path, map_location=self.device)
            model.load_state_dict(state_dict)
            model.to(self.device)
            model.eval()
            self.model = model
            logger.info(f"LSTM model loaded from {self.model_path}")
        except Exception as e:
            logger.error(f"Failed to load LSTM model: {e}")
            self.model = None

    def predict(self, symbol: str, news_text: str = "") -> dict:
        """Generate a prediction for a given symbol."""
        if self.model is None:
            return get_sentiment_fallback(symbol, news_text)
        
        # Compute features
        features = compute_lstm_features(symbol)
        if features is None:
            return get_sentiment_fallback(symbol, news_text)
        
        # Run inference
        input_tensor = torch.tensor(features, device=self.device).unsqueeze(0).unsqueeze(1)
        with torch.no_grad():
            output = self.model(input_tensor)
            prob = torch.sigmoid(output).item()
        
        prediction = 'UP' if prob >= 0.5 else 'DOWN'
        confidence = round((prob if prob >= 0.5 else 1 - prob) * 100, 1)
        
        return {
            'prediction': prediction,
            'confidence': confidence,
            'sentiment_score': sentiment_score,
            'fallback': False,
            'message': 'LSTM prediction successful'
        }
```
