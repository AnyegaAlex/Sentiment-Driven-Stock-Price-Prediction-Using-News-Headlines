# 5.2 Frontend Architecture

**File:** `/wiki/5.2-Frontend-Architecture.md`

---

## Overview

This page provides a detailed overview of the Tickflow frontend architecture. The frontend is a single-page application (SPA) built with React, designed to provide a responsive, real-time dashboard experience for users. It integrates with the backend API through a dedicated API client layer.

---

## Technology Stack

| Component | Technology | Purpose |
|-----------|------------|---------|
| Framework | React 18 | UI rendering and component lifecycle |
| Routing | React Router 6 | Client-side navigation |
| State Management | React Query 5 | Data fetching, caching, and synchronization |
| Styling | Tailwind CSS 3 | Utility-first CSS framework |
| Build Tool | Vite 5 | Fast development and production builds |
| HTTP Client | Axios | API communication with interceptors |
| Charts | Recharts | Data visualization |
| UI Components | Radix UI | Accessible, unstyled components |
| Animations | Framer Motion | Smooth transitions and animations |
| Forms | React Hook Form | Form handling and validation |

## State Management

### React Query

React Query is the primary state management tool for server-state data.

**Key Features Used:**
- Data fetching with automatic caching
- Background refetching for real-time updates
- Mutation for POST/PUT/PATCH operations
- Invalidation after mutations
- Optimistic updates
- Stale-while-revalidate pattern

**Query Configuration:**

```javascript
// src/services/api.js
export const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 30 * 1000,      // 30 seconds
      gcTime: 5 * 60 * 1000,     // 5 minutes
      refetchOnWindowFocus: false,
      retry: 1,
      placeholderData: (previousData) => previousData,
    },
    mutations: {
      retry: 1,
    },
  },
});
```

**Example Query Usage:**

```javascript
// pages/Dashboard.jsx
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';

// Query
const { data: predictions, isLoading, error } = useQuery({
  queryKey: ['predictions', { symbol, page }],
  queryFn: () => apiClient.get(`/predictions/?symbol=${symbol}&limit=25&offset=${page}`),
  staleTime: 30 * 1000,
  enabled: !!user,
});

// Mutation
const mutation = useMutation({
  mutationFn: (newData) => apiClient.post('/predictions/', newData),
  onSuccess: () => {
    queryClient.invalidateQueries(['predictions']);
  },
});
```

### ProtectedRoute Component

The `ProtectedRoute` component handles authentication, email verification, and tier-based access control.

```javascript
// components/auth/ProtectedRoute.jsx
const ProtectedRoute = ({
  children,
  requiredTiers = [],
  requireVerified = true,
  fallbackPath = '/login',
}) => {
  const { user, isAuthenticated, isLoading, hasPermission } = useAuth();
  const location = useLocation();

  if (isLoading) {
    return <LoadingSpinner fullScreen label="Verifying your session..." />;
  }

  if (!isAuthenticated || !user) {
    return <Navigate to={fallbackPath} state={{ from: location }} replace />;
  }

  // Redirect to onboarding if not completed
  if (!user.onboarded && location.pathname !== '/onboarding') {
    return <Navigate to="/onboarding" state={{ from: location }} replace />;
  }

  // Redirect to dashboard if already onboarded
  if (user.onboarded && location.pathname === '/onboarding') {
    return <Navigate to="/dashboard" replace />;
  }

  // Email verification check
  if (requireVerified && !user.email_verified && location.pathname !== '/verify-email') {
    return <Navigate to="/verify-email" state={{ from: location }} replace />;
  }

  // Tier-based access control
  if (requiredTiers.length > 0 && !hasPermission(requiredTiers)) {
    return <Navigate to="/unauthorized" replace />;
  }

  return children;
};
```

### Theme Support

The application supports light, dark, and system themes.

**Theme Implementation:**

```javascript
// hooks/useTheme.js
import { useState, useEffect } from 'react';

export const useTheme = () => {
  const [theme, setTheme] = useState(() => {
    const stored = localStorage.getItem('theme');
    if (stored) return stored;
    if (window.matchMedia('(prefers-color-scheme: dark)').matches) return 'dark';
    return 'light';
  });

  useEffect(() => {
    const root = document.documentElement;
    if (theme === 'dark') {
      root.classList.add('dark');
    } else {
      root.classList.remove('dark');
    }
    localStorage.setItem('theme', theme);
  }, [theme]);

  return { theme, setTheme };
};
```

## API Client Layer

### Axios Client with Interceptors

The API client is configured with request and response interceptors.

```javascript
// services/client.js
import axios from 'axios';

const apiClient = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
  withCredentials: false,
});

// Request interceptor - Add authentication
apiClient.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('accessToken') || sessionStorage.getItem('accessToken');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    
    // Add API key for public endpoints
    if (!config.headers['X-API-Key'] && import.meta.env.VITE_API_KEY) {
      config.headers['X-API-Key'] = import.meta.env.VITE_API_KEY;
    }
    
    return config;
  },
  (error) => Promise.reject(error)
);

// Response interceptor - Handle token refresh
apiClient.interceptors.response.use(
  (response) => response.data,
  async (error) => {
    const originalRequest = error.config;
    
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      try {
        const refreshToken = localStorage.getItem('refreshToken');
        if (refreshToken) {
          const response = await axios.post(
            `${import.meta.env.VITE_API_BASE_URL}/auth/refresh/`,
            { refresh: refreshToken }
          );
          const newToken = response.data.data?.access || response.data.access;
          if (newToken) {
            localStorage.setItem('accessToken', newToken);
            originalRequest.headers.Authorization = `Bearer ${newToken}`;
            return apiClient(originalRequest);
          }
        }
      } catch (refreshError) {
        // Refresh failed, logout
        localStorage.clear();
        sessionStorage.clear();
        window.location.href = '/login';
      }
    }
    
    return Promise.reject(error);
  }
);

export default apiClient;
```

## Error Handling

### Error Handler Utility

```javascript
// utils/errorHandler.js
export const useErrorHandler = () => {
  const [error, setError] = useState(null);
  const [isError, setIsError] = useState(false);

  const handleError = useCallback((err, context = {}) => {
    const errorResponse = formatError(err, context);
    setError(errorResponse);
    setIsError(true);
    
    // Log to console in development
    if (import.meta.env.DEV) {
      console.error('[Error Handler]', errorResponse);
    }
    
    return errorResponse;
  }, []);

  const clearError = useCallback(() => {
    setError(null);
    setIsError(false);
  }, []);

  return { error, isError, handleError, clearError };
};
```
