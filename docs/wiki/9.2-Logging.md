## Overview

This page provides a comprehensive reference for the logging strategy in Tickflow. Logging is essential for debugging, monitoring, security auditing, and performance analysis. The platform uses structured JSON logging, multiple log levels, and integration with external monitoring tools like Sentry.

---

## Logging Strategy

### Principles

| Principle | Description |
|-----------|-------------|
| **Structured Logging** | Logs are in JSON format for easy parsing and analysis |
| **Contextual Logging** | Logs include request IDs, user IDs, and other context |
| **Appropriate Levels** | Use correct log levels (DEBUG, INFO, WARNING, ERROR, CRITICAL) |
| **No Sensitive Data** | Never log passwords, API keys, or PII |
| **Centralized Storage** | Logs are aggregated for analysis |
| **Retention Policy** | Logs are retained for 30 days |

### Log Format

All logs are in JSON format for consistency and machine readability.

```json
{
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "level": "INFO",
  "logger": "django.request",
  "module": "middleware",
  "line_number": 42,
  "message": "Request completed",
  "request_id": "abc123def456",
  "user_id": 29,
  "username": "moses",
  "trace_id": "trace123",
  "method": "GET",
  "path": "/api/v1/stock-analysis/",
  "status_code": 200,
  "duration_ms": 123.45
}
```

## Log Levels

| Level | Purpose | Usage |
|-------|---------|-------|
| **DEBUG** | Development debugging | `logger.debug()` |
| **INFO** | General application events | `logger.info()` |
| **WARNING** | Potential issues | `logger.warning()` |
| **ERROR** | Application errors | `logger.error()` |
| **CRITICAL** | System failures | `logger.critical()` |

### Custom JSON Formatter

```python
# logging_config.py
import json
import logging
from datetime import datetime

class CustomJsonFormatter(logging.Formatter):
    """Custom JSON formatter for structured logging."""

    def format(self, record):
        log_data = {
            'timestamp': datetime.utcnow().isoformat() + 'Z',
            'level': record.levelname,
            'logger': record.name,
            'module': record.module,
            'line_number': record.lineno,
            'message': record.getMessage(),
        }
        
        # Add extra fields
        if hasattr(record, 'request_id'):
            log_data['request_id'] = record.request_id
        
        if hasattr(record, 'user_id'):
            log_data['user_id'] = record.user_id
        
        if hasattr(record, 'username'):
            log_data['username'] = record.username
        
        if hasattr(record, 'trace_id'):
            log_data['trace_id'] = record.trace_id
        
        # Include extra attributes
        if hasattr(record, 'extra'):
            log_data.update(record.extra)
        
        return json.dumps(log_data)
```

## Request Logging

### Request Logging Middleware

```python
# authentication/middleware.py
import time
import uuid
import logging
from django.utils import timezone

logger = logging.getLogger(__name__)

class RequestLoggingMiddleware:
    """Log all requests with timing and context."""

    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        request_id = request.headers.get('X-Request-ID', str(uuid.uuid4()))
        request.request_id = request_id
        request._start_time = time.time()

        response = self.get_response(request)

        duration = (time.time() - request._start_time) * 1000
        self._log_request(request, response, duration)

        return response

    def _log_request(self, request, response, duration):
        log_data = {
            'method': request.method,
            'path': request.path,
            'status_code': response.status_code,
            'duration_ms': round(duration, 2),
            'request_id': getattr(request, 'request_id', None),
            'ip': request.META.get('REMOTE_ADDR', 'Unknown'),
            'user_agent': request.META.get('HTTP_USER_AGENT', 'Unknown'),
        }

        user = getattr(request, 'user', None)
        if user and user.is_authenticated:
            log_data['user_id'] = user.id
            log_data['username'] = user.username

        if hasattr(request, 'api_key_obj') and request.api_key_obj:
            log_data['api_key_id'] = request.api_key_obj.id
            log_data['api_key_name'] = request.api_key_obj.name

        if response.status_code >= 500:
            logger.error(f"Request failed: {log_data}")
        elif response.status_code >= 400:
            logger.warning(f"Request error: {log_data}")
        else:
            logger.info(f"Request completed: {log_data}")
```

## Error Logging

### Exception Logging

```python
# utils/error_handler.py
import logging
import traceback

logger = logging.getLogger(__name__)

def log_exception(exc, context=None):
    """Log an exception with context."""
    error_data = {
        'exception_type': exc.__class__.__name__,
        'exception_message': str(exc),
        'traceback': traceback.format_exc(),
    }
    
    if context:
        error_data['context'] = context
    
    logger.error(f"Exception occurred: {error_data}")

# Usage
try:
    # Some code
except Exception as e:
    log_exception(e, {'user_id': request.user.id})
```

## Audit Logging

### Audit Log Model

```python
# authentication/models.py
class AuditLog(models.Model):
    user = models.ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True)
    action = models.CharField(max_length=100, db_index=True)
    details = models.JSONField(default=dict, blank=True)
    timestamp = models.DateTimeField(auto_now_add=True, db_index=True)

    class Meta:
        indexes = [
            models.Index(fields=['user', '-timestamp']),
            models.Index(fields=['action', '-timestamp']),
        ]
        ordering = ['-timestamp']
```

### Audit Logging Implementation

```python
# authentication/utils.py
from .models import AuditLog

def log_audit_event(user, action, details=None):
    """Log an audit event."""
    try:
        AuditLog.objects.create(
            user=user,
            action=action,
            details=details or {},
        )
        logger.info(f"Audit event: {action} - User: {user.id if user else 'None'}")
    except Exception as e:
        logger.error(f"Failed to log audit event: {e}")
```

### Log Cleanup Command

```python
# management/commands/cleanup_logs.py
from django.core.management.base import BaseCommand
from datetime import datetime, timedelta
import os
import glob

class Command(BaseCommand):
    help = 'Clean up old log files'

    def add_arguments(self, parser):
        parser.add_argument(
            '--days',
            type=int,
            default=30,
            help='Number of days to keep logs',
        )

    def handle(self, *args, **options):
        days = options['days']
        cutoff = datetime.now() - timedelta(days=days)
        
        log_files = glob.glob('logs/*.log*')
        for file_path in log_files:
            if os.path.getmtime(file_path) < cutoff.timestamp():
                os.remove(file_path)
                self.stdout.write(f"Deleted: {file_path}")
```

## Logging Best Practices

### Do's

| Practice | Description |
|----------|-------------|
| **Use structured logging** | JSON format for machine readability |
| **Include context** | request_id, user_id, trace_id |
| **Use appropriate log levels** | INFO for normal events, ERROR for failures |
| **Log at the start and end** | Track execution boundaries |
| **Log performance metrics** | Duration, query counts |
| **Include correlation IDs** | Trace requests across services |

### Don'ts

| Practice | Description |
|----------|-------------|
| **Don't log passwords** | Security risk |
| **Don't log API keys** | Security risk |
| **Don't log PII** | Privacy risk |
| **Don't log excessive data** | Performance overhead |
| **Don't log in loops** | Performance overhead |
| **Don't log sensitive data** | Compliance risk |

### Example: Good Logging

```python
logger.info(
    "User logged in successfully",
    extra={
        'user_id': user.id,
        'username': user.username,
        'ip': request.META.get('REMOTE_ADDR'),
        'user_agent': request.META.get('HTTP_USER_AGENT'),
    }
)
```

### Example: Bad Logging

```python
# BAD - Logging password
logger.info(f"Login attempt: {username}:{password}")

# BAD - Logging API key
logger.info(f"API key used: {api_key}")

# BAD - Logging PII
logger.info(f"User email: {user.email}")
```
