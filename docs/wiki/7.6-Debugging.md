# 7.6 Debugging

**File:** `/wiki/7.6-Debugging.md`

## Overview

This page provides a comprehensive reference for debugging the Tickflow platform. It covers debugging techniques, tools, and common issues for both the backend and frontend components.

---

## Debugging Philosophy

| Principle | Description |
|-----------|-------------|
| **Reproduce First** | Reproduce the issue consistently before debugging |
| **Isolate the Problem** | Narrow down to the specific component |
| **Check Logs** | Always check logs first |
| **Test Hypotheses** | Make one change at a time |
| **Document Findings** | Record solutions for future reference |

## Backend Debugging

### Django Debugging

#### 1. Enable Debug Mode

```python
# settings.py
DEBUG = True  # Only for development
```

When `DEBUG = True`, Django provides:
- Detailed error pages with stack traces
- SQL query logging
- Request/response headers

#### 2. Django Debug Toolbar

```bash
# Install
pip install django-debug-toolbar

# Add to installed apps
INSTALLED_APPS += ['debug_toolbar']

# Add middleware
MIDDLEWARE += ['debug_toolbar.middleware.DebugToolbarMiddleware']

# Add internal IPs
INTERNAL_IPS = ['127.0.0.1']
```

**Features:**
- SQL query profiling
- Cache statistics
- Request/response headers
- Template rendering time
- Signals and middleware execution

#### 3. Runserver with Verbose Logging

```bash
python manage.py runserver --verbosity 3
```

| Verbosity Level | Output |
|-----------------|--------|
| 0 | Minimal output |
| 1 | Normal output (default) |
| 2 | More detailed output |
| 3 | Full debug output |

#### 4. Django Shell

```bash
python manage.py shell
```

**Useful Commands:**

```python
# Import models
from authentication.models import User
from stocks.models import Prediction

# Query data
user = User.objects.get(username='testuser')
predictions = Prediction.objects.filter(user=user)

# Debug ORM queries
from django.db import connection
print(connection.queries)

# Test functions
from stocks.utils import calculate_performance_metrics
metrics = calculate_performance_metrics(Prediction.objects.all())
print(metrics)
```

#### 5. Logging

**Configure logging in settings.py:**

```python
LOGGING = {
    'version': 1,
    'disable_existing_loggers': False,
    'handlers': {
        'console': {
            'class': 'logging.StreamHandler',
            'level': 'DEBUG',
        },
    },
    'root': {
        'handlers': ['console'],
        'level': 'DEBUG',
    },
    'loggers': {
        'django.db.backends': {
            'level': 'DEBUG',  # Log all SQL queries
        },
        'authentication': {
            'level': 'DEBUG',
        },
        'stocks': {
            'level': 'DEBUG',
        },
    },
}
```

**Add debug logs in code:**

```python
import logging
logger = logging.getLogger(__name__)

def my_function():
    logger.debug(f"Debug message: {variable}")
    logger.info(f"Info message: {data}")
    logger.warning(f"Warning: {issue}")
    logger.error(f"Error: {error}")
```

#### 2. Django Debug Toolbar - SQL Panel

The SQL panel shows:
- Query execution time
- Query count
- Duplicate queries
- Slow queries

#### 3. PostgreSQL Debugging

```bash
# Connect to database
psql -U tickflow_user -d tickflow_db

# Show active connections
SELECT pid, usename, application_name, client_addr, state, query
FROM pg_stat_activity;

# Show slow queries
SELECT query, total_time, calls
FROM pg_stat_statements
ORDER BY total_time DESC
LIMIT 10;

# Show table sizes
SELECT schemaname, tablename,
       pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;
```

#### 4. Query Optimization

```python
# Use select_related for foreign keys
queryset = Prediction.objects.select_related('user')

# Use only/defer for specific fields
queryset = Prediction.objects.only('id', 'stock_symbol', 'predicted_movement')

# Use prefetch_related for many-to-many
queryset = User.objects.prefetch_related('predictions')

# Debug query count
```

#### 4. API Response Validation

```python
# Validate response structure
def validate_api_response(response):
    required_fields = ['success', 'data', 'code', 'timestamp']
    for field in required_fields:
        if field not in response:
            raise ValueError(f"Missing field: {field}")
    
    if response['success'] is not True:
        print(f"API Error: {response.get('error', 'Unknown error')}")
        print(f"Error Code: {response.get('code', 'Unknown')}")
```

#### 2. FinBERT Debugging

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

def debug_finbert(text):
    model_name = "distilbert-base-uncased-finetuned-sst-2-english"
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    model = AutoModelForSequenceClassification.from_pretrained(model_name)
    
    try:
        inputs = tokenizer(text, return_tensors="pt", truncation=True)
        with torch.no_grad():
            outputs = model(**inputs)
            probs = torch.softmax(outputs.logits, dim=1)
            print(f"Text: {text}")
            print(f"Probabilities: {probs}")
            print(f"Predicted: {probs.argmax().item()}")
    except Exception as e:
        print(f"FinBERT error: {e}")
```

### API Client Debugging

#### 1. Axios Interceptors

```javascript
// services/client.js
import axios from 'axios';

const apiClient = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
});

// Request interceptor
apiClient.interceptors.request.use(
  (config) => {
    // Log request details
    console.log('[API Request]', {
      method: config.method?.toUpperCase(),
      url: config.url,
      params: config.params,
      data: config.data,
      headers: config.headers,
    });
    
    return config;
  },
  (error) => {
    console.error('[API Request Error]', error);
    return Promise.reject(error);
  }
);

// Response interceptor
apiClient.interceptors.response.use(
  (response) => {
    // Log response details
    console.log('[API Response]', {
      url: response.config.url,
      status: response.status,
      data: response.data,
    });
    
    return response;
  },
  (error) => {
    console.error('[API Error]', {
      status: error.response?.status,
      data: error.response?.data,
      config: error.config,
    });
    return Promise.reject(error);
  }
);
```

#### 2. Mock API Responses

## Common Issues and Solutions

### Backend Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| **500 Internal Server Error** | Server-side exception | Check logs, enable DEBUG |
| **401 Unauthorized** | Invalid API key or JWT | Verify key/token, check expiry |
| **429 Rate Limited** | Too many requests | Wait, implement backoff |
| **CORS Error** | Frontend origin not allowed | Add origin to CORS_ALLOWED_ORIGINS |
| **Database Connection Failed** | PostgreSQL not running | Start PostgreSQL, check credentials |
| **Redis Connection Failed** | Redis not running | Start Redis, check REDIS_URL |
| **LSTM Model Not Loaded** | Model file missing | Set ENABLE_LSTM=False or fix path |
| **Migration Error** | Schema mismatch | Run migrate, check for conflicts |

### Frontend Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| **Blank Page** | JavaScript error | Check console for errors |
| **API Calls Failing** | CORS or network error | Check Network tab, verify URL |
| **Data Not Loading** | React Query error | Check query cache, error handling |
| **Slow Rendering** | Large component tree | Use React.memo, virtualization |
| **Build Failing** | Dependency issue | Clear node_modules, reinstall |
| **Theme Not Applying** | Tailwind config issue | Check tailwind.config.js, rebuild |

## Debugging Checklist

| Step | Action |
|------|--------|
| 1 | Reproduce the issue consistently |
| 2 | Check browser console for errors |
| 3 | Check Django logs for errors |
| 4 | Check network tab for API failures |
| 5 | Enable DEBUG mode for detailed errors |
| 6 | Check database for data issues |
| 7 | Check cache for stale data |
| 8 | Test with curl or Postman |
| 9 | Isolate the component (frontend) |
| 10 | Isolate the view (backend) |
