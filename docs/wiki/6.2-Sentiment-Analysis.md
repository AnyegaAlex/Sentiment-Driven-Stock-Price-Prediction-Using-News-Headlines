## Overview

This page provides a detailed reference for the sentiment analysis component of Tickflow, powered by FinBERT (Financial BERT). FinBERT is a pre-trained transformer model fine-tuned on financial news and earnings reports for sentiment classification. It is a critical component of the ML pipeline, providing sentiment scores that feed into the LSTM model and the hybrid prediction system.

---

## FinBERT Model Overview

### What is FinBERT?

FinBERT is a variant of BERT (Bidirectional Encoder Representations from Transformers) specifically fine-tuned for financial sentiment analysis. It is pre-trained on a large corpus of financial news and earnings call transcripts.

| Aspect | Description |
|--------|-------------|
| **Base Model** | BERT (Bidirectional Encoder Representations from Transformers) |
| **Fine-tuning Data** | Financial news, earnings call transcripts |
| **Task** | Sentiment classification (Positive, Negative, Neutral) |
| **Framework** | Hugging Face Transformers |
| **Model Name** | `distilbert-base-uncased-finetuned-sst-2-english` |

### Model Specifications

| Parameter | Value | Description |
|-----------|-------|-------------|
| **Architecture** | Transformer | Bidirectional encoder |
| **Layers** | 6 | Transformer layers |
| **Hidden Size** | 768 | Hidden state dimension |
| **Attention Heads** | 12 | Multi-head attention |
| **Parameters** | 66M | Trainable parameters |
| **Input Length** | 512 | Maximum token length |

## Sentiment Analysis Implementation

### Model Loading

The sentiment model is loaded lazily to optimize startup time and memory usage.

```python
# news/utils.py
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

class FinBERTClassifier:
    """
    FinBERT sentiment classifier for financial news.
    """
    def __init__(self, model_name: str = "distilbert-base-uncased-finetuned-sst-2-english"):
        self.model_name = model_name
        self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        self.tokenizer = None
        self.model = None
        self._load_model()
    
    def _load_model(self):
        """Load the model and tokenizer."""
        try:
            self.tokenizer = AutoTokenizer.from_pretrained(self.model_name)
            self.model = AutoModelForSequenceClassification.from_pretrained(self.model_name)
            self.model.to(self.device)
            self.model.eval()
            logger.info(f"FinBERT model loaded: {self.model_name}")
        except Exception as e:
            logger.error(f"Failed to load FinBERT model: {e}")
            self.model = None
    
    def analyze(self, text: str) -> dict:
        """
        Analyze sentiment of a given text.
        
        Returns:
            dict: {
                'label': 'positive' | 'negative' | 'neutral',
                'confidence': float (0-1),
                'score': float (-1 to 1)
            }
        """
        if not text or not text.strip():
            return {'label': 'neutral', 'confidence': 0.5, 'score': 0.0}
        
        try:
            inputs = self.tokenizer(
                text,
                return_tensors="pt",
                truncation=True,
                max_length=512,
                padding=True
            )
            inputs = {k: v.to(self.device) for k, v in inputs.items()}
            
            with torch.no_grad():
                outputs = self.model(**inputs)
                probs = torch.softmax(outputs.logits, dim=1)
                confidence = probs.max().item()
                predicted_class = probs.argmax().item()
            
            # Label mapping: 0 = negative, 1 = positive (for distilbert-base-uncased-finetuned-sst-2-english)
            label = 'positive' if predicted_class == 1 else 'negative'
            score = probs[0][predicted_class].item()
            
            return {
                'label': label,
                'confidence': confidence,
                'score': round(score * 2 - 1, 4)  # Map 0-1 to -1 to 1
            }
        except Exception as e:
            logger.error(f"Sentiment analysis failed: {e}")
            return {'label': 'neutral', 'confidence': 0.0, 'score': 0.0}
```

### Sentiment Scoring

Sentiment scores are mapped to a range of -1.0 to 1.0 for consistency.

| Score Range | Classification | Meaning |
|-------------|----------------|---------|
| > 0.2 | Positive | Bullish sentiment |
| -0.2 to 0.2 | Neutral | Mixed or neutral sentiment |
| < -0.2 | Negative | Bearish sentiment |

### Confidence Scoring

Confidence scores represent the model's certainty in its prediction.

| Confidence | Interpretation |
|------------|----------------|
| > 0.8 | High confidence |
| 0.6 - 0.8 | Moderate confidence |
| < 0.6 | Low confidence |

```python
# news/utils.py
def process_news_for_symbol(symbol: str, refresh: bool = False) -> dict:
    """
    Process news articles for a given symbol.
    """
    cache_key = f"news:{symbol}"
    
    # Check cache
    if not refresh:
        cached = cache.get(cache_key)
        if cached:
            return cached
    
    # Fetch news from sources
    articles = []
    for source in [fetch_alpha_vantage_news, fetch_finnhub_news, fetch_yahoo_news]:
        try:
            result = source(symbol)
            articles.extend(result)
            break  # Stop after first successful source
        except Exception as e:
            logger.warning(f"Source {source.__name__} failed: {e}")
            continue
    
    if not articles:
        logger.warning(f"No news found for {symbol}")
        return {'symbol': symbol, 'news': [], 'count': 0}
    
    # Deduplicate
    seen = set()
    unique_articles = []
    for article in articles:
        hash_key = f"{article.get('title', '')}_{article.get('source', '')}"
        article_hash = hashlib.sha256(hash_key.encode()).hexdigest()
        if article_hash not in seen:
            seen.add(article_hash)
            unique_articles.append(article)
    
    # Process each article
    processed_articles = []
    for article in unique_articles[:100]:  # Limit to 100 articles
        # Clean text
        text = clean_text(article.get('title', '') + ' ' + article.get('summary', ''))
        
        # Sentiment analysis
        sentiment = finbert_classifier.analyze(text)
        
        # Key phrase extraction
        key_phrases = extract_key_phrases(text)
        
        # Build article object
        processed = {
            'id': article.get('id', generate_id()),
            'title': article.get('title', ''),
            'summary': article.get('summary', ''),
            'source': article.get('source', 'Unknown'),
            'source_reliability': get_source_reliability(article.get('source', '')),
            'published_at': article.get('published_at'),
            'sentiment': sentiment['label'],
            'confidence': sentiment['confidence'],
            'sentiment_score': sentiment['score'],
            'key_phrases': key_phrases,
            'url': article.get('url', ''),
            'banner_image_url': article.get('banner_image_url', ''),
        }
        processed_articles.append(processed)
    
    # Store in database
    ProcessedNews.objects.bulk_create([
        ProcessedNews(
            symbol=symbol,
            title=a['title'],
            summary=a['summary'],
            source=a['source'],
            source_reliability=a['source_reliability'],
            published_at=a['published_at'],
            sentiment_score=a['sentiment_score'],
            confidence=a['confidence'],
            key_phrases=a['key_phrases'],
            url=a['url'],
            banner_image_url=a['banner_image_url'],
        ) for a in processed_articles
    ])
    
    response = {
        'symbol': symbol,
        'news': processed_articles,
        'count': len(processed_articles),
        'refresh_queued': False,
        'cache_stale': False,
    }
    
    # Cache for 5 minutes
    cache.set(cache_key, response, timeout=300)
    return response
```

## Source Reliability Ranking

### Reliability Scores

Source reliability is scored on a scale of 1 to 100 based on the credibility and accuracy history of the news source.

| Tier | Reliability Score | Sources |
|------|-------------------|---------|
| Tier 1 | 80-100 | Reuters, Bloomberg, CNBC, Wall Street Journal, Financial Times |
| Tier 2 | 50-79 | Yahoo Finance, MarketWatch, Seeking Alpha |
| Tier 3 | 1-49 | Less established sources, blogs |

### Implementation

```python
# news/utils.py
RELIABLE_SOURCES = {
    'Reuters': 95,
    'Bloomberg': 94,
    'CNBC': 90,
    'Wall Street Journal': 92,
    'Financial Times': 93,
    'Yahoo Finance': 75,
    'MarketWatch': 72,

def get_source_reliability(source_name: str) -> int:
    """Get reliability score for a source."""
    return RELIABLE_SOURCES.get(source_name, 50)  # Default to 50 for unknown sources
```

## Cache Behavior

### Cache Strategy

| Scenario | Behavior |
|----------|----------|
| Cache hit (data < 30 min old) | Returns cached data immediately |
| Cache hit (data > 30 min old) | Returns cached data and queues background refresh |
| Cache miss | Fetches fresh data from external sources |
| `refresh=true` | Bypasses cache and fetches fresh data |

### Cache Implementation

```python
# news/views.py
class NewsView(APIView):
    def get(self, request):
        symbol = request.query_params.get('symbol')
        refresh = request.query_params.get('refresh', False) == 'true'
        
        cache_key = f"news:{symbol}"
        
        # Check cache
        if not refresh:
            cached = cache.get(cache_key)
            if cached:
                return Response(cached)
        
        # Fetch fresh data
        response = process_news_for_symbol(symbol, refresh)
        
        # Cache the response
        cache.set(cache_key, response, timeout=300)
        
        return Response(response)
```

### Secondary Source: Finnhub

| Aspect | Description |
|--------|-------------|
| **Type** | Secondary |
| **Rate Limit** | 60 requests/minute (free tier) |
| **Data** | News articles |
| **Reliability** | Medium |

### Fallback Source: Yahoo Finance

| Aspect | Description |
|--------|-------------|
| **Type** | Fallback |
| **Rate Limit** | None |
| **Data** | News articles (via RapidAPI) |
| **Reliability** | Medium |

### Fallback Chain

1. Try Alpha Vantage first
2. If Alpha Vantage fails, try Finnhub
3. If Finnhub fails, try Yahoo Finance
4. If all sources fail, return cached data with `cache_stale: true`

## Error Handling

### Error Scenarios

| Error | Handling |
|-------|----------|
| Model not loaded | Return neutral sentiment (0.0) |
| Text too long | Truncate to 512 tokens |
| API rate limit | Exponential backoff, fallback to cache |
| Empty response | Return empty news list |
| Invalid symbol | Return 400 Bad Request |
