# 2.4 Error Codes

**File:** `/wiki/2.4-Error-Codes.md`

---

## Overview

Tickflow API uses standardized error responses with specific error codes to help clients identify and resolve issues. This page provides a complete reference of all error codes, their meanings, and recommended resolution steps.

---

## Standard Error Response Format

All error responses follow a consistent format:

```json
{
  "success": false,
  "error": "Human-readable error message",
  "code": 1001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456",
  "details": {}
}
```

| Field | Description |
|-------|-------------|
| `success` | Always `false` for error responses |
| `error` | Human-readable error message |
| `code` | Numeric error code for programmatic handling |
| `timestamp` | ISO 8601 timestamp of when the error occurred |
| `request_id` | Unique identifier for the request (for tracing) |
| `details` | Additional error context (optional) |

---

## Error Code Categories

| Code Range | Category | Description |
|------------|----------|-------------|
| 1000-1999 | Authentication | API key, JWT, or authentication errors |
| 2000-2999 | Validation | Invalid parameters or request data |
| 3000-3999 | Rate Limiting | Rate limit exceeded |
| 4000-4999 | Resource | Resource not found or unavailable |
| 9000-9999 | Server | Internal server errors |

---

## Complete Error Code Reference

### Authentication Errors (1000-1999)

| Code | Description | HTTP Status | Resolution |
|------|-------------|-------------|------------|
| 1001 | Invalid API key | 401 | Generate a new API key and verify it is correct |
| 1002 | Missing API key | 401 | Add `X-API-Key` header to the request |
| 1003 | Expired API key | 401 | Generate a new API key or extend expiry date |
| 1004 | Revoked API key | 401 | Generate a new API key |
| 1005 | Invalid JWT token | 401 | Refresh the token or re-authenticate |
| 1006 | Expired JWT token | 401 | Use the refresh token to get a new access token |
| 1007 | Missing JWT token | 401 | Add `Authorization: Bearer <token>` header |

### Validation Errors (2000-2999)

| Code | Description | HTTP Status | Resolution |
|------|-------------|-------------|------------|
| 2001 | Missing required parameter | 400 | Add the required parameter to the request |
| 2002 | Invalid parameter value | 400 | Check parameter format and valid values |
| 2003 | Invalid symbol format | 400 | Use valid stock symbols (e.g., AAPL, TSLA) |
| 2004 | Invalid email format | 400 | Provide a valid email address |
| 2005 | Password validation failed | 400 | Password must meet complexity requirements |
| 2006 | Validation failed | 400 | Check the `details` field for specific validation errors |

### Rate Limiting Errors (3000-3999)

| Code | Description | HTTP Status | Resolution |
|------|-------------|-------------|------------|
| 3001 | Rate limit exceeded | 429 | Wait and retry after the period specified in `Retry-After` header |

### Resource Errors (4000-4999)

| Code | Description | HTTP Status | Resolution |
|------|-------------|-------------|------------|
| 4001 | Resource not found | 404 | Verify the resource ID or symbol exists |
| 4002 | Email already subscribed | 400 | Email is already in the subscription list |
| 4003 | User not found | 404 | Verify the user ID or username exists |
| 4004 | Prediction not found | 404 | Verify the prediction ID exists |

### Server Errors (9000-9999)

| Code | Description | HTTP Status | Resolution |
|------|-------------|-------------|------------|
| 9001 | Internal server error | 500 | Contact support with the request_id |
| 9002 | Database error | 500 | Check database connection and logs |
| 9003 | External API error | 503 | Data source unavailable, retry later |
| 9004 | Rate limiter error | 500 | Internal rate limiting issue, contact support |

## Debugging Common Errors

### 401 Unauthorized

**Possible causes:**
- Invalid or missing API key
- Expired JWT token
- Revoked API key

**Resolution steps:**
1. Verify the `X-API-Key` header is included and spelled correctly
2. Generate a new API key if the current one is invalid
3. Refresh the JWT token if expired

### 400 Bad Request

**Possible causes:**
- Missing required parameters
- Invalid parameter values
- Malformed request body

**Resolution steps:**
1. Check the `details` field for specific validation errors
2. Verify all required parameters are included
3. Validate parameter formats (e.g., symbol length, email format)

### 429 Too Many Requests

**Possible causes:**
- Rate limit exceeded

**Resolution steps:**
1. Check the `Retry-After` header for wait time
2. Implement exponential backoff in your client
3. Cache responses to reduce request volume

### 500 Internal Server Error

**Possible causes:**
- Server-side error
- Database connection issues
- External API failures

**Resolution steps:**
1. Include the `request_id` when contacting support
2. Check if the issue is temporary (retry later)
3. Review the error logs (if accessible)
