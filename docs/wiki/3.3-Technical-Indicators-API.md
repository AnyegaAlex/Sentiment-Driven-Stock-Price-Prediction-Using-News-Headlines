# 3.3 Technical Indicators API

**File:** `/wiki/3.3-Technical-Indicators-API.md`

---

## Overview

The Technical Indicators API provides pure technical analysis metrics for a given stock symbol. It returns SMA, RSI, support and resistance levels, pivot points, volume, volatility, and historical price data. This endpoint is useful for traders and analysts who need raw technical data without the sentiment or prediction components.

---

## Endpoint

**Method:** `GET`

**URL:** `/api/v1/technical-indicators/`

**Authentication:** Required (API Key or JWT)

---

## Parameters

| Parameter | Type | Required | Default | Valid Values | Description |
|-----------|------|----------|---------|--------------|-------------|
| `symbol` | string | Yes | — | Stock ticker (e.g., AAPL, TSLA) | The stock symbol to analyze |
| `timeframe` | string | No | `1d` | `1d`, `1w`, `1m`, `3m` | Timeframe for historical data |

---

## Request Examples

### curl

```bash
curl -H "X-API-Key: your_api_key_here" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/technical-indicators/?symbol=AAPL&timeframe=1m"
```

### Python

```python
import requests

API_KEY = "your_api_key_here"
url = "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/technical-indicators/"
headers = {"X-API-Key": API_KEY}
params = {
    "symbol": "AAPL",
    "timeframe": "1m"
}

response = requests.get(url, headers=headers, params=params)
data = response.json()
print(data)
```

### JavaScript (Fetch)

```javascript
const API_KEY = "your_api_key_here";
const url = new URL("https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/technical-indicators/");
url.searchParams.append("symbol", "AAPL");
url.searchParams.append("timeframe", "1m");

fetch(url, {
  headers: { "X-API-Key": API_KEY }
})
.then(response => response.json())
.then(data => console.log(data));
```

## Response Schema

### Top-Level Fields

```json
{
  "success": true,
  "data": {
    "technical": {
      "current_price": 116.16,
      "sma_50": 114.84,
      "sma_200": 111.81,
      "rsi": 70.8,
      "support": 110.35,
      "resistance": 121.97,
      "pivot": 116.16,
      "volume": 12424000,
      "volatility": 0.15,
      "price_history": [112.00, 112.58, 113.21, ...]
    }
  },
  "code": 200,
  "timestamp": "2026-07-24T10:00:00.123456Z"
}
```

---

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `current_price` | float | Latest closing price |
| `sma_50` | float | 50-day Simple Moving Average. If insufficient data, falls back to mean of all available data |
| `sma_200` | float | 200-day Simple Moving Average. If insufficient data, falls back to mean of all available data |
| `rsi` | float | Relative Strength Index (0-100). Overbought > 70, Oversold < 30 |
| `support` | float | Support level derived from 20-day low |
| `resistance` | float | Resistance level derived from 20-day high |
| `pivot` | float | Pivot point calculated as (High + Low + Close) / 3 from the most recent day |
| `volume` | integer | Latest trading volume |
| `volatility` | float | Volatility as percentage, calculated from daily returns standard deviation |
| `price_history` | array | Array of closing prices for the requested timeframe |

---

## Interpretation Guide

### Simple Moving Averages (SMA)

| Condition | Interpretation |
|-----------|----------------|
| Price > SMA_50 > SMA_200 | Bullish trend (golden cross) |
| Price < SMA_50 < SMA_200 | Bearish trend (death cross) |
| Price crosses above SMA_50 | Potential bullish reversal |
| Price crosses below SMA_50 | Potential bearish reversal |

### Relative Strength Index (RSI)

| RSI Value | Interpretation |
|-----------|----------------|
| > 70 | Overbought – potential sell signal |
| 50 - 70 | Bullish momentum |
| 30 - 50 | Bearish momentum |
| < 30 | Oversold – potential buy signal |

### Support and Resistance

| Level | Interpretation |
|-------|----------------|
| Support | Price level where buying interest is strong enough to prevent decline |
| Resistance | Price level where selling interest is strong enough to prevent advance |
| Break above resistance | Potential bullish breakout |
| Break below support | Potential bearish breakdown |

### Pivot Point

The pivot point is calculated as:
```
Pivot = (High + Low + Close) / 3
```

| Level | Interpretation |
|-------|----------------|
| Above pivot | Bullish bias |
| Below pivot | Bearish bias |

### Volatility

| Volatility | Interpretation |
|------------|----------------|
| High (> 2%) | High-risk, high-reward potential |
| Medium (1-2%) | Moderate risk |
| Low (< 1%) | Stable, lower risk |

## Error Scenarios

| HTTP Status | Error Code | Description |
|-------------|------------|-------------|
| 400 | 2001 | Missing `symbol` parameter |
| 400 | 2002 | Invalid `symbol` format |
| 401 | 1001/1002 | Invalid or missing API key |
| 429 | 3001 | Rate limit exceeded |
| 500 | 9001 | Internal server error |

### Example Error (Missing Symbol)

```json
{
  "success": false,
  "error": "Symbol is required.",
  "code": 2001,
  "timestamp": "2026-07-24T10:00:00.123456Z",
  "request_id": "abc123def456"
}
```

---

## Fallback Behavior

When yfinance data is unavailable, the endpoint falls back to static data:

- **Popular symbols** (AAPL, TSLA, GOOGL, etc.): Uses pre-configured static data
- **Unknown symbols**: Generates realistic synthetic data based on a base price of $100 with random variation

The `price_history` array always contains 30 days of data, either from yfinance or generated.

---

## Rate Limiting

| User Type | Rate Limit |
|-----------|------------|
| Anonymous | 100 requests/hour |
| JWT User | 1,000 requests/hour |
| API Key | 200 requests/minute |

This endpoint counts toward the rate limit for the authenticated user or API key.
