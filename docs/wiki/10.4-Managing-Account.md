## Overview

This page provides a complete guide to managing your Tickflow account. It covers profile management, password security, API key management, email preferences, and account deletion. Proper account management ensures your data is secure and your preferences are up to date.

## Profile Management

### Viewing Your Profile

1. Navigate to **"Profile"** in the sidebar
2. Your profile page displays:

| Section | Information |
|---------|-------------|
| **User Info** | Avatar, username, email, display name, bio |
| **Account Status** | Email verification, onboarding status, tier |
| **Statistics** | Analyses count, predictions count, news read, accuracy |
| **Watchlist** | List of stocks you are tracking |
| **Preferences** | Investment goal, risk tolerance, experience, persona |

### Editing Your Profile

1. Navigate to **"Profile"** in the sidebar
2. Click **"Edit Profile"**
3. Update the following fields:

| Field | Description | Required |
|-------|-------------|----------|
| **Nickname** | Your display name | Yes |
| **Full Name** | Your full name | No |
| **Bio** | Short biography | No |
| **Persona** | Your role or interest | No |
| **Investment Goal** | Your primary investment objective | No |
| **Risk Tolerance** | Your risk tolerance level | No |
| **Experience Level** | Your trading experience | No |

4. Click **"Save"**

### Profile Fields Explanation

| Field | Description | Example |
|-------|-------------|---------|
| **Nickname** | Display name used throughout the platform | "Moses" |
| **Full Name** | Your legal name | "Moses Kamau" |
| **Bio** | Short description about yourself | "Passionate trader and AI enthusiast" |
| **Persona** | Your role or interest | "Trader", "Researcher", "Developer" |

| **Risk Tolerance** | Your comfort with risk | "Conservative", "Moderate", "Aggressive" |

## Password Management

### Changing Your Password

1. Navigate to **"Profile"** in the sidebar
2. Click **"Change Password"**
3. Enter the following:

| Field | Description |
|-------|-------------|
| **Current Password** | Your current password |
| **New Password** | Your new password (8+ characters, not too common) |
| **Confirm New Password** | Re-enter your new password |

4. Click **"Save"**

### Password Requirements

| Requirement | Description |
|-------------|-------------|
| **Minimum Length** | 8 characters |
| **Complexity** | Not too common (e.g., "password123" is rejected) |
| **Similarity** | Not similar to your username or email |
| **Numeric** | At least one number is recommended |

### Password Reset

If you forgot your password:

1. Go to `https://sentiment-driven-stock-price-predic.vercel.app/forgot-password`
2. Enter your email address
3. Click **"Reset Password"**
4. Check your email for the password reset link
5. Follow the link and set a new password

## API Key Management

### What is an API Key?

API keys allow you to programmatically access Tickflow's API. They are used for:

- Building custom applications
- Integrating with trading platforms
- Automating analysis
- Developing scripts

### Generating an API Key

1. Navigate to **"Profile"** in the sidebar
2. Click **"API Key"**
3. Enter a descriptive name for the key:
   - Example: "Production Frontend"
   - Example: "Trading Bot"
   - Example: "Analysis Script"
4. Click **"Generate"**
5. **Copy and save the API key immediately** – it will only be shown once

### API Key Format

API keys follow this format:
```
ts_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz
```

### Using Your API Key

Include the API key in the `X-API-Key` header of your requests:

```bash
curl -H "X-API-Key: ts_abc123def456ghi789jkl012mno345pqr678stu901vwx234yz" \
  "https://sentiment-driven-stock-price-prediction.onrender.com/api/v1/stock-analysis/?symbol=AAPL"
```

### Viewing Your API Keys

1. Navigate to **"Profile"** in the sidebar
2. Click **"API Key"**
3. You will see a list of your active API keys with:
   - **Name**: The key's descriptive name
   - **Created**: Creation date
   - **Last Used**: Last usage timestamp
   - **Status**: Active or Revoked

### Revoking an API Key

1. Navigate to **"Profile"** in the sidebar
2. Click **"API Key"**
3. Find the key you want to revoke
4. Click **"Revoke"** next to the key
5. Confirm the revocation

### API Key Security Best Practices

| Practice | Description |
|----------|-------------|
| **Never Commit Keys** | Never commit API keys to version control |
| **Use Environment Variables** | Store keys in environment variables |
| **Rotate Keys** | Rotate keys regularly (every 90 days) |
| **Use Different Keys** | Use different keys for different applications |
| **Revoke Unused Keys** | Revoke keys that are no longer in use |
| **Monitor Usage** | Monitor key usage for anomalies |

## Account Deletion

### Requesting Account Deletion

1. Navigate to **"Settings"** in the sidebar
2. Go to the **"Account"** tab
3. Click **"Delete Account"**
4. Enter your password and type `DELETE` to confirm
5. Click **"Delete Account"**

### Deletion Process

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ACCOUNT DELETION PROCESS                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐ │
│  │  Request    │───▶│  30-Day     │───▶│  Account    │───▶│   Data      │ │
│  │  Deletion   │    │  Grace      │    │  Deleted    │    │   Removed   │ │
│  │             │    │  Period     │    │             │    │             │ │
│  └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘ │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  What Happens:                                                       │   │
│  │  - Account is marked for deletion                                    │   │
│  │  - You have 30 days to cancel                                       │   │
│  │  - After 30 days, account is permanently deleted                   │   │
│  │  - All data is removed                                              │   │
│  │  - You will receive a confirmation email                            │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │  Data Removed:                                                        │   │
│  │  - User profile                                                      │   │
│  │  - Predictions history                                               │   │
│  │  - Watchlist                                                         │   │
│  │  - Preferences                                                       │   │
│  │  - API keys                                                          │   │
│  │  - Audit logs (anonymized)                                          │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Cancelling Account Deletion

If you change your mind during the 30-day grace period:

1. Navigate to **"Settings"** in the sidebar
2. Go to the **"Account"** tab
3. Click **"Cancel Deletion"**
4. Your account will be reactivated

### Data Removed on Deletion

| Data Type | Removed? | Notes |
|-----------|----------|-------|
| User Profile | Yes | Complete removal |
| Predictions | Yes | Complete removal |
| Watchlist | Yes | Complete removal |
| Preferences | Yes | Complete removal |
| API Keys | Yes | Complete removal |
| Audit Logs | Anonymized | User reference removed |

## Troubleshooting

### Issue: I Can't Change My Password

**Possible causes:**
- Incorrect current password
- New password doesn't meet requirements

**Resolution:**
1. Verify your current password
2. Ensure new password is at least 8 characters
3. Try again

### Issue: I Didn't Receive the Verification Email

**Possible causes:**
- Email in spam folder
- Incorrect email address

**Resolution:**
1. Check spam folder
2. Use the resend verification option
3. Ensure your email address is correct

### Issue: API Key Not Working

**Possible causes:**
- Incorrect key format
- Key is revoked
- Key has expired

**Resolution:**
1. Generate a new API key
2. Ensure key is copied correctly
3. Check key status in your profile

### Issue: Account Deletion Request Not Processing

**Possible causes:**
- Incorrect password
- Confirmation phrase not typed correctly

**Resolution:**
1. Verify your password
2. Type `DELETE` exactly as shown
3. Try again
