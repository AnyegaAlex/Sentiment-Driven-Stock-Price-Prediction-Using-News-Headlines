# 14.3 API Changelog

**File:** `/wiki/14.3-API-Changelog.md`

---

## Overview

This page documents the version history of the Tickflow API, including changes, new features, bug fixes, deprecations, and breaking changes. The API follows Semantic Versioning (SemVer) for versioning.

---

## Versioning Scheme

Tickflow API uses Semantic Versioning:

| Component | Description |
|-----------|-------------|
| **MAJOR** | Incompatible API changes |
| **MINOR** | New features (backward compatible) |
| **PATCH** | Bug fixes (backward compatible) |

**Format:** `vMAJOR.MINOR.PATCH`

---

## Current Version: v1.0.0

### Release Date

**2026-07-24**

### Overview

Initial production release of the Tickflow API. All core endpoints are stable and fully documented.

### New Features

| Feature | Description | Endpoint |
|---------|-------------|----------|
| **Unified Stock Analysis** | Comprehensive stock analysis combining sentiment, technicals, and predictions | `GET /api/v1/stock-analysis/` |
| **Technical Indicators** | Pure technical analysis metrics | `GET /api/v1/technical-indicators/` |
| **News and Sentiment** | News articles with sentiment analysis | `GET /api/v1/news/get-news/` |
| **LSTM Prediction** | AI-powered stock movement predictions | `GET /api/v1/lstm-predict/` |
| **Prediction History** | Historical predictions with filtering | `GET /api/v1/prediction-history/` |
| **Subscription** | Email subscription management | `POST /api/v1/subscribe/` |
| **Symbols** | List of supported stock symbols | `GET /api/v1/symbols/` |
| **Symbol Search** | Dynamic symbol search | `GET /api/v1/news/symbol-search/` |
| **Health Check** | System health monitoring | `GET /health/` |

### Authentication

| Feature | Description |
|---------|-------------|
| **API Key Authentication** | `X-API-Key` header for external access |
| **JWT Authentication** | `Authorization: Bearer` header for frontend |
| **Rate Limiting** | 200/min for API keys, 1000/hour for users |
| **Multiple Keys** | Multiple API keys per user |

### Response Format

```json
{
  "success": true,
  "data": { ... },
  "code": 200,
  "timestamp": "2026-07-24T10:00:00.123456Z"
}
```

### Error Codes

| Code | Description |
|------|-------------|
| 1001 | Invalid API key |
| 1002 | Missing API key |
| 2001 | Missing required parameter |
| 2002 | Invalid parameter value |
| 3001 | Rate limit exceeded |
| 4001 | Resource not found |
| 9001 | Internal server error |

## Migration Guides

### Migrating from Legacy API

**Step 1: Update Base URL**

| Legacy | New |
|--------|-----|
| `/api/` | `/api/v1/` |

**Step 2: Update Endpoints**

| Legacy Endpoint | New Endpoint |
|-----------------|--------------|
| `/api/stock-opinion/` | `/api/v1/stock-analysis/` |
| `/api/news/analyzed/` | `/api/v1/news/get-news/` |

**Step 3: Update Authentication**

| Legacy | New |
|--------|-----|
| `Authorization: Token` | `X-API-Key: key` |

**Step 4: Update Response Parsing**

| Legacy | New |
|--------|-----|
| Response directly contains data | Response contains `data` field |
