## Key Performance Metrics

### Metrics Summary

| Metric | Description | Formula | Current Value |
|--------|-------------|---------|---------------|
| **Accuracy** | Correct predictions / Total predictions | (TP + TN) / (TP + TN + FP + FN) | 63% |
| **F1 Score** | Harmonic mean of Precision and Recall | 2 * (P * R) / (P + R) | 60% |
| **Precision** | True positives / All positive predictions | TP / (TP + FP) | 62% |
| **Recall** | True positives / All actual positives | TP / (TP + FN) | 61% |
| **Balanced Accuracy** | Average recall per class | (TP/(TP+FN) + TN/(TN+FP)) / 2 | 62% |

### Metric Definitions

**Accuracy:** The proportion of correct predictions among all predictions made.

**F1 Score:** The harmonic mean of precision and recall. Provides a balanced measure of model performance, especially useful when classes are imbalanced.

**Precision:** The proportion of correct positive predictions among all positive predictions. Measures how often a prediction of UP is correct.

**Recall:** The proportion of actual positive cases correctly identified. Measures how well the model catches actual UP movements.

**Balanced Accuracy:** The average of recall for each class. Useful when classes are imbalanced.

### Confusion Matrix Calculation

```python
# stocks/utils.py
def calculate_performance_metrics(queryset):
    """
    Calculate precision, recall, f1, confusion matrix from queryset.
    """
    resolved = queryset.filter(is_correct__isnull=False)
    if resolved.count() == 0:
        return { /* default zero metrics */ }
    
    # Extract actual and predicted
    y_true = []
    y_pred = []
    for pred in resolved:
        if pred.actual_direction in ['up', 'down']:
            y_true.append(1 if pred.actual_direction == 'up' else 0)
            y_pred.append(1 if pred.predicted_movement == 'up' else 0)
    
    if len(y_true) == 0:
        return { /* default zero metrics */ }
    
    tn, fp, fn, tp = confusion_matrix(y_true, y_pred, labels=[0, 1]).ravel()
    
    accuracy = (tp + tn) / (tp + tn + fp + fn)
    precision = tp / (tp + fp) if (tp + fp) > 0 else 0
    recall = tp / (tp + fn) if (tp + fn) > 0 else 0
    f1 = 2 * (precision * recall) / (precision + recall) if (precision + recall) > 0 else 0
    
    return {
        'accuracy': round(accuracy * 100, 1),
        'precision': round(precision * 100, 1),
        'recall': round(recall * 100, 1),
        'f1': round(f1 * 100, 1),
        'confusion_matrix': {'TP': tp, 'FP': fp, 'TN': tn, 'FN': fn}
    }
```

## Backtesting Methodology

### Rolling Window Validation

| Aspect | Description |
|--------|-------------|
| **Window Size** | 30 days of training data |
| **Test Size** | 7 days of test data |
| **Walk Forward** | 1 day step |
| **Period** | 5+ years of historical data |

### Backtesting Process

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     ROLLING WINDOW BACKTESTING                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Training Window (30 days)    Test Window (7 days)                         │
│  ┌──────────────────────┐    ┌──────────┐                                   │
│  │  Train →→→→→→→→→→→→→│    │  Test    │                                   │
│  └──────────────────────┘    └──────────┘                                   │
│  └─────────────────────────────────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────────────────────────────────┐│
│  │  Step 1: Train on days 1-30, test on days 31-37                        ││
│  │  Step 2: Train on days 2-31, test on days 32-38                        ││
│  │  Step 3: Train on days 3-32, test on days 33-39                        ││
│  │  ...                                                                   ││
│  └─────────────────────────────────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────────────────────────────────┐│
│  │  Performance is averaged across all test windows                        ││
│  └─────────────────────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────────────────────┘
```

### Implementation

```python
# stocks/utils.py (conceptual)
def rolling_backtest(symbol, training_days=30, test_days=7):
    """
    Perform rolling window backtesting.
    """
    data = fetch_historical_data(symbol, "5y")
    
    results = []
    for i in range(0, len(data) - training_days - test_days):
        train_data = data[i:i+training_days]
        test_data = data[i+training_days:i+training_days+test_days]
        
        # Train model
        model = train_lstm(train_data)
        
        # Test model
        for day in test_data:
            features = compute_features(day)
            prediction = model.predict(features)
            actual = day['next_direction']
            results.append((prediction, actual))
    
    # Calculate metrics
    accuracy = sum(1 for p, a in results if p == a) / len(results)
    return {'accuracy': accuracy}
```

## Drift Detection

### What is Drift?

Model drift occurs when the performance of a machine learning model degrades over time due to changes in the data distribution or market conditions.

### Drift Detection Implementation

```python
# stocks/utils.py
def detect_drift(recent_period_days=30, baseline_period_days=90):
    """
    Detect performance drift by comparing recent vs baseline F1.
    """
    recent_start = timezone.now() - timedelta(days=recent_period_days)
    baseline_start = timezone.now() - timedelta(days=baseline_period_days)
    
    # Recent predictions
    recent_qs = Prediction.objects.filter(
        resolution_date__gte=recent_start,
        is_correct__isnull=False
    )
    recent_metrics = calculate_performance_metrics(recent_qs)
    recent_f1 = recent_metrics['f1'] / 100
    
    # Baseline predictions
    baseline_qs = Prediction.objects.filter(
        resolution_date__gte=baseline_start,
        resolution_date__lt=recent_start,
        is_correct__isnull=False
    )
    baseline_metrics = calculate_performance_metrics(baseline_qs)
    baseline_f1 = baseline_metrics['f1'] / 100
    
    # Detect drift
    drift_detected = False
    severity = 'none'
    drop = baseline_f1 - recent_f1
    drop_pct = (drop / baseline_f1) * 100 if baseline_f1 > 0 else 0
    
    if drop_pct > 10 or drop > 0.1:
        drift_detected = True
        if drop_pct > 20:
            severity = 'high'
        elif drop_pct > 15:
            severity = 'medium'
        else:
            severity = 'low'
    
    return {
        'drift_detected': drift_detected,
        'severity': severity,
        'recent_f1': recent_f1 * 100,
        'baseline_f1': baseline_f1 * 100,
        'drop_percent': round(drop_pct, 1),
        'recent_metrics': recent_metrics,
        'baseline_metrics': baseline_metrics
    }
```

### Drift Thresholds

| Severity | F1 Drop | Absolute Drop | Action |
|----------|---------|---------------|--------|
| **None** | < 10% | < 0.05 | No action |
| **Low** | 10-15% | 0.05-0.10 | Monitor |
| **Medium** | 15-20% | 0.10-0.15 | Alert, prepare retraining |
| **High** | > 20% | > 0.15 | Retrain immediately |

### Drift Detection Frequency

| Aspect | Frequency |
|--------|-----------|
| Detection Run | Daily |
| Recent Window | 30 days |
| Baseline Window | 90 days |
| Alert Trigger | When drift detected |

### Implementation

```python
# stocks/views.py
class PerformanceSummaryView(APIView):
    def get(self, request):
        symbol = request.query_params.get('symbol')
        days = int(request.query_params.get('days', 30))
        
        start_date = timezone.now() - timedelta(days=days)
        qs = Prediction.objects.filter(
            resolution_date__gte=start_date,
            is_correct__isnull=False
        )
        if symbol:
            qs = qs.filter(stock_symbol=symbol.upper())
        
        metrics = calculate_performance_metrics(qs)
        
        # Per-symbol breakdown
        symbols = qs.values_list('stock_symbol', flat=True).distinct()
        symbol_metrics = {}
        for sym in symbols:
            sym_qs = qs.filter(stock_symbol=sym)
            symbol_metrics[sym] = calculate_performance_metrics(sym_qs)
        
        total_preds = qs.count()
        correct_preds = qs.filter(is_correct=True).count()
        
        recent_start = datetime.now() - timedelta(days=7)
        recent_qs = qs.filter(resolution_date__gte=recent_start)
        recent_metrics = calculate_performance_metrics(recent_qs)
        
        return Response({
            'total_predictions': total_preds,
            'correct_predictions': correct_preds,
            'overall': metrics,
            'recent_accuracy': recent_metrics.get('accuracy', 0),
            'by_symbol': symbol_metrics
        })
```

## Error Analysis

### Common Error Patterns

| Error Type | Description | Mitigation |
|------------|-------------|------------|
| **False Positives** | Predicted UP, but stock went DOWN | Increase confidence threshold |
| **False Negatives** | Predicted DOWN, but stock went UP | Adjust weighting strategy |
| **High Volatility** | Errors during high volatility | Add volatility-adjusted weighting |
| **News-Driven** | Errors when news diverges from technicals | Increase sentiment weight |

### Error Analysis Implementation

```python
def analyze_errors(predictions):
    """
    Analyze prediction errors for patterns.
    """
    errors = {
        'false_positives': [],
        'false_negatives': [],
        'high_volatility': [],
        'news_divergence': []
    }
    
    for pred in predictions:
        if pred.is_correct is False:
            if pred.predicted_movement == 'up' and pred.actual_direction == 'down':
                errors['false_positives'].append(pred)
            elif pred.predicted_movement == 'down' and pred.actual_direction == 'up':
                errors['false_negatives'].append(pred)
            
            # Check volatility
            if pred.market_context and pred.market_context.get('volatility', 0) > 2.0:
                errors['high_volatility'].append(pred)
    
    return {
        'total_errors': len(errors['false_positives']) + len(errors['false_negatives']),
        'false_positives': len(errors['false_positives']),
        'false_negatives': len(errors['false_negatives']),
        'high_volatility_errors': len(errors['high_volatility']),
        'error_rate': (len(errors['false_positives']) + len(errors['false_negatives'])) / len(predictions)
    }
```
