## Overview

The Hybrid Model combines LSTM neural network predictions, FinBERT sentiment analysis, and technical indicators to generate a final stock movement prediction with confidence scoring. This ensemble approach leverages the strengths of each component while mitigating individual weaknesses.

## Feature Concatenation

The hybrid model combines outputs from three components into a unified feature vector.

### Component Outputs

| Component | Output | Range | Weight |
|-----------|--------|-------|--------|
| LSTM | Probability of UP movement | 0.0 to 1.0 | 50% |
| Sentiment (FinBERT) | Sentiment score | -1.0 to 1.0 | 30% |
| Technicals | Technical indicator values | Variable | 20% |

### Feature Vector

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         FEATURE VECTOR                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │

│  Feature 2: Sentiment Score (-1.0 - 1.0)                                   │
│  Feature 3: MA7 Value                                                       │
│  Feature 4: MA21 Value                                                      │
│  Feature 5: RSI14 Value (0 - 100)                                          │

│  Feature 7: Bollinger Band Position                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Weighting Strategy

### Default Weights

| Component | Weight | Rationale |
|-----------|--------|-----------|
| LSTM | 50% | Core predictive model |
| Sentiment | 30% | Market sentiment indicator |
| Technicals | 20% | Price-based indicators |

### Weighted Average Calculation

```
Final Score = (0.5 * lstm_probability) + (0.3 * sentiment_score) + (0.2 * technical_score)

Where:
- lstm_probability: LSTM output (0.0 to 1.0)
- sentiment_score: Sentiment score (-1.0 to 1.0, normalized to 0.0 to 1.0)
- technical_score: Technical indicator score (0.0 to 1.0)
```

### Normalization

| Component | Raw Range | Normalized Range | Method |
|-----------|-----------|------------------|--------|
| LSTM | 0.0 to 1.0 | 0.0 to 1.0 | Direct |
| Sentiment | -1.0 to 1.0 | 0.0 to 1.0 | `(score + 1) / 2` |
| Technicals | Variable | 0.0 to 1.0 | Min-Max scaling based on historical data |

### Technical Score Calculation

```python
def calculate_technical_score(tech_features: dict) -> float:
    """Calculate a technical indicator score."""
    scores = []
    
    # MA7 vs MA21
    if tech_features['MA7'] > tech_features['MA21']:
        scores.append(0.7)
    else:
        scores.append(0.3)
    
    # RSI interpretation
    rsi = tech_features['RSI14']
    if rsi < 30:
        scores.append(0.8)  # Oversold - potential buy
    elif rsi > 70:
        scores.append(0.2)  # Overbought - potential sell
    else:
        scores.append(0.5)  # Neutral
    
    # Bollinger Band position
    upper = tech_features['UpperBB']
    lower = tech_features['LowerBB']
    close = tech_features['Close']
    bb_position = (close - lower) / (upper - lower) if (upper - lower) > 0 else 0.5
    scores.append(bb_position)
    
    return sum(scores) / len(scores)
```

## Ensemble Approach

### Voting Mechanism

The hybrid model uses a weighted voting mechanism where each component contributes to the final decision.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         VOTING MECHANISM                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Component: LSTM                                                           │
│  Direction: UP                                                             │
│  Confidence: 65%                                                           │
│  Weight: 50%                                                               │
│                                                                             │
│  Component: Sentiment                                                      │
│  Direction: UP                                                             │
│  Confidence: 55%                                                           │
│  Weight: 30%                                                               │
│                                                                             │
│  Component: Technicals                                                     │
│  Direction: HOLD                                                           │
│  Confidence: 50%                                                           │
│  Weight: 20%                                                               │
│                                                                             │
│  Final Decision:                                                           │
│  Direction: UP                                                             │
│  Confidence: (65*0.5 + 55*0.3 + 50*0.2) = 59.0%                           │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Implementation

```python
def hybrid_prediction(symbol: str, news_text: str = "") -> dict:
    """
    Generate a prediction using the hybrid model.
    """
    # 1. Get LSTM prediction
    lstm_result = lstm_predictor.predict(symbol, news_text)
    lstm_direction = lstm_result.get('prediction')
    lstm_confidence = lstm_result.get('confidence', 50) / 100
    
    # 2. Get sentiment score
    sentiment_result = finbert_classifier.analyze(news_text or get_recent_news(symbol))
    sentiment_score = sentiment_result.get('score', 0.0)  # -1 to 1
    
    # 3. Get technical indicators
    tech_features = compute_lstm_features(symbol)
    if tech_features is None:
        tech_score = 0.5
    else:
        tech_score = calculate_technical_score(tech_features)
    
    # 4. Normalize sentiment (0 to 1)
    sentiment_normalized = (sentiment_score + 1) / 2
    
    # 5. Weighted average
    final_score = (0.5 * lstm_confidence) + (0.3 * sentiment_normalized) + (0.2 * tech_score)
    
    # 6. Determine direction
    if final_score >= 0.6:
        final_direction = 'UP'
    elif final_score <= 0.4:
        final_direction = 'DOWN'
    else:
        final_direction = 'HOLD'
    
    # 7. Calculate final confidence
    final_confidence = round(
        abs(final_score - 0.5) * 2 * 100,  # Scale to 0-100%
        1
    )
    
    return {
        'prediction': final_direction,
        'confidence': final_confidence,
        'lstm': {
            'direction': lstm_direction,
            'confidence': lstm_result.get('confidence', 0),
        },
        'sentiment': {
            'score': sentiment_score,
            'label': 'positive' if sentiment_score > 0.2 else 'negative' if sentiment_score < -0.2 else 'neutral',
        },
        'technical_score': round(tech_score * 100, 1),
        'fallback': lstm_result.get('fallback', False),
        'message': 'Hybrid prediction successful'
    }
```

## Fallback Mechanisms

### Fallback Scenarios

| Scenario | Fallback | Response |
|----------|----------|----------|
| LSTM model unavailable | Sentiment + Technicals | `fallback: true` |
| Insufficient price history | Sentiment only | `fallback: true` |
| Feature computation error | Sentiment only | `fallback: true` |
| News unavailable | LSTM + Technicals | `fallback: true` |

### Fallback Hierarchy

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         FALLBACK HIERARCHY                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Level 1: Full Hybrid (LSTM + Sentiment + Technicals)                      │
│  └───▶ All components available                                            │
│                                                                             │
│  Level 2: LSTM + Sentiment (No Technicals)                                 │
│  └───▶ Technical indicators unavailable                                    │
│                                                                             │
│  Level 3: Sentiment + Technicals (No LSTM)                                 │
│  └───▶ LSTM model unavailable                                              │
│                                                                             │
│  Level 4: Sentiment Only                                                   │
│  └───▶ Insufficient data or model errors                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Fallback Implementation

```python
def predict_with_fallback(symbol: str, news_text: str = "") -> dict:
    """
    Generate prediction with fallback handling.
    """
    # Try full hybrid
    try:
        return hybrid_prediction(symbol, news_text)
    except Exception as e:
        logger.warning(f"Hybrid prediction failed: {e}")
    
    # Fallback 1: LSTM + Sentiment
    try:
        lstm = lstm_predictor.predict(symbol, news_text)
        sentiment = finbert_classifier.analyze(news_text or get_recent_news(symbol))
        return {
            'prediction': lstm.get('prediction', 'HOLD'),
            'confidence': (lstm.get('confidence', 50) + sentiment.get('confidence', 50) * 100) / 2,
            'fallback': True,
            'message': 'Using LSTM + Sentiment fallback'
        }
    except Exception as e:
        logger.warning(f"LSTM + Sentiment fallback failed: {e}")
    
    # Fallback 2: Sentiment + Technicals
    try:
        sentiment = finbert_classifier.analyze(news_text or get_recent_news(symbol))
        tech_features = compute_lstm_features(symbol)
        tech_score = calculate_technical_score(tech_features) if tech_features else 0.5
        
        final_score = (0.6 * sentiment.get('score', 0.5)) + (0.4 * tech_score)
        direction = 'UP' if final_score > 0.6 else 'DOWN' if final_score < 0.4 else 'HOLD'
        confidence = abs(final_score - 0.5) * 2 * 100
        
        return {
            'prediction': direction,
            'confidence': round(confidence, 1),
            'fallback': True,
            'message': 'Using Sentiment + Technicals fallback'
        }
    except Exception as e:
        logger.warning(f"Sentiment + Technicals fallback failed: {e}")
    
    # Fallback 3: Sentiment Only
    try:
        sentiment = finbert_classifier.analyze(news_text or get_recent_news(symbol))
        score = sentiment.get('score', 0.0)
        
        if score > 0.2:
            direction = 'UP'
            confidence = min(abs(score) * 100, 90) + 10
        elif score < -0.2:
            direction = 'DOWN'
            confidence = min(abs(score) * 100, 90) + 10
        else:
            direction = 'HOLD'
            confidence = 50.0
        
        return {
            'prediction': direction,
            'confidence': round(confidence, 1),
            'fallback': True,
            'message': 'Using sentiment-only fallback'
        }
    except Exception as e:
        logger.error(f"All fallbacks failed for {symbol}: {e}")
    
    # Ultimate fallback
    return {
        'prediction': 'HOLD',
        'confidence': 0.0,
        'fallback': True,
        'message': 'All prediction methods failed'
    }
```

## Use Cases

### Best Use Cases for Hybrid Model

| Use Case | Recommendation |
|----------|----------------|
| **Long-term investing** | Use hybrid with equal weighting |
| **Short-term trading** | Use hybrid with higher LSTM weight |
| **News-driven stocks** | Use hybrid with higher sentiment weight |
| **Technical stocks** | Use hybrid with higher technicals weight |

### Weight Adjustments

| Scenario | LSTM Weight | Sentiment Weight | Technicals Weight |
|----------|-------------|------------------|-------------------|
| Default | 50% | 30% | 20% |
| News-heavy | 40% | 50% | 10% |
| Technical | 40% | 10% | 50% |
| Conservative | 60% | 20% | 20% |
| Aggressive | 40% | 40% | 20% |

---

## Error Handling

### Error Scenarios

| Error | Handling |
|-------|----------|
| LSTM failure | Fallback to Sentiment + Technicals |
| Sentiment failure | Fallback to LSTM + Technicals |
| Technicals failure | Fallback to LSTM + Sentiment |
| All components fail | Return HOLD with 0% confidence |
