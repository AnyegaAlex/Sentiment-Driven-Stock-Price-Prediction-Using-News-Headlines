# 13.3 Data Attribution

**File:** `/wiki/13.3-Data-Attribution.md`

## Overview

Tickflow uses data from third-party sources for stock data, news, and sentiment analysis. This page provides the required attributions for these data sources. All data is subject to the terms and conditions of the respective providers.

---

## Data Sources Summary

| Source | Data Type | Attribution Required |
|--------|-----------|---------------------|
| **Alpha Vantage** | Stock data, news | Yes |
| **Finnhub** | News data | Yes |
| **Yahoo Finance** | Stock data | Yes |
| **Hugging Face** | ML model (FinBERT) | Yes |

---

## Alpha Vantage

### Data Provided
- Stock price data
- News articles
- Technical indicators (via API)

### Terms and Conditions

Alpha Vantage provides financial data under the following terms:

- Data is provided for personal and non-commercial use
- Attribution is required when using the data
- Rate limits apply (5 requests per minute for free tier)
- Data may not be redistributed without permission

### Attribution Requirement

When using data from Alpha Vantage, include the following attribution:

> "Data provided by Alpha Vantage (alphavantage.co)"

### Usage Limitations

| Limitation | Description |
|------------|-------------|
| **Commercial Use** | Requires a paid license |
| **Redistribution** | Not permitted without authorization |
| **Rate Limiting** | 5 requests per minute (free tier) |

### Reference

- Website: https://www.alphavantage.co/
- Terms: https://www.alphavantage.co/terms_of_service/

## Hugging Face (FinBERT)

### Data Provided
- FinBERT model for sentiment analysis
- Pre-trained transformer model

### Model Details

| Aspect | Description |
|--------|-------------|
| **Model Name** | `distilbert-base-uncased-finetuned-sst-2-english` |
