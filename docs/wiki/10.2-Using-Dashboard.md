## Top Header

### Symbol Search Bar

The symbol search bar allows you to search for stock symbols by ticker or company name.

**Features:**

| Feature | Description |
|---------|-------------|
| **Autocomplete** | Suggestions appear as you type |
| **Symbols Supported** | AAPL, TSLA, GOOGL, AMZN, MSFT, NVDA, JPM, IBM, PLTR, LULU |
| **Case Insensitive** | Search is case-insensitive |

**Usage:**

1. Click on the search bar
2. Type a stock symbol or company name
3. Select from the autocomplete suggestions or press Enter

## Overview Cards

The overview cards provide a snapshot of key metrics.

| Card | Metric | Description |
|------|--------|-------------|
| **Accuracy** | Prediction accuracy | Percentage of correct predictions (7-day rolling) |

## Stock Analysis

### Analysis Input

**Fields:**

| Field | Description | Example |
|-------|-------------|---------|
| **Symbol** | Stock ticker to analyze | `AAPL` |
| **Risk Type** | Investor risk tolerance | `medium` |
| **Hold Time** | Investment horizon | `medium-term` |

**Risk Type Options:**

| Risk Type | Description |
|-----------|-------------|
| **Low** | Conservative, lower risk tolerance |
| **Medium** | Balanced risk tolerance |
| **High** | Aggressive, higher risk tolerance |

**Hold Time Options:**

| Hold Time | Description |
|-----------|-------------|
| **Short-term** | Days to weeks |
| **Medium-term** | Weeks to months |
| **Long-term** | Months to years |

### Analysis Results

#### Sentiment Analysis

| Field | Description |
|-------|-------------|
| **Overall** | Sentiment label (Bullish, Bearish, Neutral) |
| **Score** | Sentiment score (-1.0 to 1.0) |
| **Recent Articles** | Number of articles analyzed in the last 7 days |

**Interpretation:**
- Score > 0.2 → **Bullish**
- Score -0.2 to 0.2 → **Neutral**
- Score < -0.2 → **Bearish**

#### Technical Indicators

| Indicator | Description | Interpretation |
|-----------|-------------|----------------|
| **Current Price** | Latest closing price | Current market price |
| **SMA 50** | 50-day Simple Moving Average | Bullish if price > SMA |
| **SMA 200** | 200-day Simple Moving Average | Bullish if price > SMA |
| **RSI** | Relative Strength Index | Overbought > 70, Oversold < 30 |
| **Support** | Support level | Price floor |
| **Resistance** | Resistance level | Price ceiling |
| **Volume** | Trading volume | High volume indicates interest |

#### LSTM Prediction

| Field | Description |
|-------|-------------|
| **Direction** | Predicted movement (UP, DOWN, HOLD) |
| **Confidence** | Confidence score (0-100%) |
| **Fallback** | Whether the prediction used fallback |
| **Message** | Additional information |

**Confidence Interpretation:**
- 70%+ → **High confidence**
- 50-69% → **Moderate confidence**
- < 50% → **Low confidence** (treat with caution)

#### Price Targets

| Target | Description |
|--------|-------------|
| **Bearish** | Downside price target (10% below current) |
| **Base** | Current price |
| **Bullish** | Upside price target (14% above current) |

## Prediction History

### Table Columns

| Column | Description |
|--------|-------------|
| **Date** | Date of the prediction |
| **Symbol** | Stock symbol |
| **Prediction** | Predicted direction (UP, DOWN, HOLD) |
| **Actual** | Actual movement (if resolved) |
| **Status** | Pending, Correct, Incorrect |
| **Price at Pred** | Price when prediction was made |
| **Price Change** | Percentage change (if resolved) |
| **Confidence** | Confidence score |
| **Resolves In** | Days until resolution |
| **Actions** | View details |

### Filtering

| Filter | Description |
|--------|-------------|
| **Symbol** | Filter by stock symbol |
| **Date Range** | Filter by prediction date |
| **Outcome** | Filter by Correct, Incorrect, or Pending |
| **Source** | Filter by LSTM or Sentiment |

### Actions

| Action | Description |
|--------|-------------|
| **Refresh** | Refresh the prediction list |
| **Export CSV** | Export predictions to CSV |
| **View Details** | Open the prediction modal |

## Watchlist

### Managing Your Watchlist

**Add a Symbol:**

1. Enter a symbol in the input field
2. Click **"Add"**

**Remove a Symbol:**

1. Click the **"X"** icon on the symbol

**View Summary:**

- Total symbols in watchlist
- Quick access to analysis for each symbol
