## Backend Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AnyegaAlex/Sentiment-Driven-Stock-Price-Prediction-Using-News-Headlines.git
cd sentiment_driven_stock_price_prediction_engine
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Copy the example environment file:

```bash
cp .env.example .env
```

Open `.env` in your editor and configure the following required variables:

```bash
# Django Configuration
SECRET_KEY=your-secret-key-here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

# Database Configuration
DATABASE_URL=postgresql://username:password@localhost:5432/tickflow

# CORS Configuration
FRONTEND_URL=http://localhost:5173

# API Keys
ALPHA_VANTAGE_KEY=your-alpha-vantage-key
FINNHUB_API_KEY=your-finnhub-key  # Optional
```

### 5. Create the Database

```bash
# Connect to PostgreSQL
psql -U postgres

# Create database
CREATE DATABASE tickflow;
CREATE USER your_username WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE tickflow TO your_username;
\q
```

### 6. Run Migrations

```bash
python manage.py migrate
python manage.py createcachetable
```

### 7. Create a Superuser (Optional)

```bash
python manage.py createsuperuser
```

### 8. Generate an API Key

```bash
python manage.py generate_apikey "Development"
```

Save the generated key for API access.

### 9. Start the Development Server

```bash
python manage.py runserver
```

The backend will be available at `http://localhost:8000`.

## Frontend Setup

### 1. Navigate to the Frontend Directory

```bash
cd frontend
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Copy the example environment file:

```bash
cp .env.example .env.development
```

Open `.env.development` in your editor:

```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_API_KEY=your-api-key-from-backend
VITE_USE_MOCK_DATA=false
```

### 4. Start the Development Server

```bash
npm run dev
```

The frontend will be available at `http://localhost:5173`.

## Docker Setup

### 1. Build and Run with Docker Compose

```bash
docker-compose up --build
```

### 2. Run Migrations

```bash
docker-compose exec web python manage.py migrate
```

### 3. Generate an API Key

```bash
docker-compose exec web python manage.py generate_apikey "Development"
```

### 4. Create a Superuser (Optional)

```bash
docker-compose exec web python manage.py createsuperuser
```

### 5. Access the Application

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:8000`
- API Documentation: `http://localhost:8000/api/docs/`

### 6. Stop the Containers

```bash
docker-compose down
```

## Dockerfile Breakdown

The Dockerfile for the backend is located at `Dockerfile`:

```dockerfile
FROM python:3.12-slim

WORKDIR /app

# Install system dependencies
RUN apt-get update && apt-get install -y \
    gcc \
    libpq-dev \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy application code
COPY . .

# Run migrations and collect static files
RUN python manage.py migrate
RUN python manage.py collectstatic --noinput

# Start the server
CMD ["gunicorn", "sentiment_driven_stock_price_prediction_engine.wsgi:application", "--bind", "0.0.0.0:8000"]
```

## Docker Compose Configuration

The `docker-compose.yml` file defines the services:

```yaml
version: '3.8'

services:
  db:
    image: postgres:16
    environment:
      POSTGRES_USER: tickflow
      POSTGRES_PASSWORD: tickflow
      POSTGRES_DB: tickflow
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7
    ports:
      - "6379:6379"

  web:
    build: .
    environment:
      SECRET_KEY: ${SECRET_KEY}
      DEBUG: ${DEBUG}
      DATABASE_URL: postgresql://tickflow:tickflow@db:5432/tickflow
      REDIS_URL: redis://redis:6379/1
      FRONTEND_URL: ${FRONTEND_URL}
      ALPHA_VANTAGE_KEY: ${ALPHA_VANTAGE_KEY}
    ports:
      - "8000:8000"
    depends_on:
      - db
      - redis

volumes:
  postgres_data:
```

## Common Installation Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| `ModuleNotFoundError: No module named 'psycopg2'` | PostgreSQL driver not installed | `pip install psycopg2-binary` |
| `relation "authentication_apikey" does not exist` | Migrations not run | `python manage.py migrate` |
| `SSL connection has been closed unexpectedly` | Database SSL configuration | Set `sslmode=require` in DATABASE_URL |
| `Invalid HTTP_HOST header` | ALLOWED_HOSTS missing | Add domain to ALLOWED_HOSTS |
| `Port already in use` | Port conflict | Change port: `python manage.py runserver 8001` |
| `ModuleNotFoundError: No module named 'drf_spectacular'` | Package missing | `pip install drf-spectacular` |

## Verification Commands

```bash
# Health check
curl http://localhost:8000/health/

# API key test
curl -H "X-API-Key: your_api_key" \
  "http://localhost:8000/api/v1/stock-analysis/?symbol=AAPL"
```

```bash
# Check if frontend is running
curl http://localhost:5173

# Should return HTML content
```

```bash
# Connect to database
psql -U username -d tickflow

# List tables
\dt

# Check migrations
SELECT * FROM django_migrations;
```
