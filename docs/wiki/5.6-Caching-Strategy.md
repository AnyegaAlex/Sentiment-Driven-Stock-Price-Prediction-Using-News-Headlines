## Overview

This page describes the caching strategy used in Tickflow to improve performance, reduce database load, and enhance user experience. The platform uses Redis as the primary cache backend with a Django LocMemCache fallback.

## Cache Configuration

### Django Cache Settings

```python
# settings.py
REDIS_URL = os.getenv('REDIS_URL')

if REDIS_URL:
    CACHES = {
        'default': {
            'BACKEND': 'django_redis.cache.RedisCache',
            'LOCATION': REDIS_URL,
            'OPTIONS': {
                'CLIENT_CLASS': 'django_redis.client.DefaultClient',
                'SOCKET_CONNECT_TIMEOUT': 10,
                'SOCKET_TIMEOUT': 5,
                'COMPRESSOR': 'django_redis.compressors.zlib.ZlibCompressor',
                'IGNORE_EXCEPTIONS': True,  # Fail silently if Redis is down
                'MAX_ENTRIES': 1000,
                'CULL_FREQUENCY': 3,
            },
            'KEY_PREFIX': 'sentiment_analysis',
        }
    }
else:
    # Fallback to local memory cache
    CACHES = {
        'default': {
            'BACKEND': 'django.core.cache.backends.locmem.LocMemCache',
            'LOCATION': 'unique-snowflake',
        }
    }
```

### Cache Key Prefix

All cache keys are prefixed with `sentiment_analysis:` to avoid collisions with other applications using the same Redis instance.

| Prefix | Purpose |
|--------|---------|
| `sentiment_analysis:api:` | API response cache |
| `sentiment_analysis:query:` | Database query cache |
| `sentiment_analysis:session:` | Session data |
| `sentiment_analysis:rate_limit:` | Rate limit tracking |
| `sentiment_analysis:lstm:` | LSTM prediction cache |
| `sentiment_analysis:price:` | Stock price cache |

## Cache Layers

### 1. API Response Cache

| Endpoint | Cache Key | TTL | Description |
|----------|-----------|-----|-------------|
| `/stock-analysis/` | `api:analysis:{symbol}` | 10 minutes | Stock analysis results |
| `/technical-indicators/` | `api:technical:{symbol}_{timeframe}` | 10 minutes | Technical indicators |
| `/news/get-news/` | `api:news:{symbol}` | 5 minutes | News articles with sentiment |
| `/lstm-predict/` | `api:lstm:{symbol}_{news_hash}` | 5 minutes | LSTM predictions |
| `/symbols/` | `api:symbols` | 1 hour | Supported symbols list |
| `/prediction-history/` | `api:history:{symbol}_{limit}_{offset}` | 5 minutes | Prediction history |

**Implementation:**

```python
# stocks/views.py
from django.core.cache import cache

class StockAnalysisView(APIView):
    def get(self, request):
        symbol = request.query_params.get('symbol')
        cache_key = f"api:analysis:{symbol}"
        
        cached_response = cache.get(cache_key)
        if cached_response:
            return Response(cached_response)
        
        # Compute analysis
        response_data = compute_analysis(symbol)
        
        # Cache for 10 minutes
        cache.set(cache_key, response_data, timeout=600)
        return Response(response_data)
```

### 2. Database Query Cache

| Query | Cache Key | TTL | Description |
|-------|-----------|-----|-------------|
| User Profile | `query:user:{user_id}` | 5 minutes | User profile data |
| User Preferences | `query:preferences:{user_id}` | 5 minutes | User preferences |
| Prediction Count | `query:prediction_count:{user_id}` | 1 minute | Prediction count |
| Symbol Usage | `query:symbol_usage:{symbol}` | 1 hour | Symbol popularity |

**Implementation:**

```python
# authentication/views.py
class ProfileView(APIView):
    def get(self, request):
        user_id = request.user.id
        cache_key = f"query:user:{user_id}"
        
        user_data = cache.get(cache_key)
        if user_data:
            return Response(user_data)
        
        # Query database
        user = User.objects.get(id=user_id)
        serializer = UserProfileSerializer(user)
        
        cache.set(cache_key, serializer.data, timeout=300)  # 5 minutes
        return Response(serializer.data)
```

### 3. Session Cache

Session data is stored in Redis to provide fast, scalable session management.

```python

SESSION_COOKIE_SECURE = True
SESSION_COOKIE_HTTPONLY = True
```

| Session Data | TTL | Description |
|--------------|-----|-------------|
| Authentication | 60 minutes | User authentication session |
| User Preferences | Session | User theme, language settings |

### 4. Rate Limit Cache

Rate limit data is stored in Redis to support distributed rate limiting.

| Rate Limit | Cache Key | TTL | Description |
|------------|-----------|-----|-------------|
| Anonymous Users | `rate_limit:anon:{ip}` | 1 hour | 100 requests/hour |
| JWT Users | `rate_limit:user:{user_id}` | 1 hour | 1,000 requests/hour |
| API Key Users | `rate_limit:apikey:{key_id}` | 60 seconds | 200 requests/minute |

**Implementation:**

```python
# authentication/throttles.py
from django.core.cache import cache
from rest_framework.throttling import BaseThrottle

class APIKeyRateThrottle(BaseThrottle):
    def allow_request(self, request, view):
        if not hasattr(request, 'api_key_obj'):
            return True
        
        key = f"rate_limit:apikey:{request.api_key_obj.id}"
        
        # Get current usage
        usage = cache.get(key, {'count': 0, 'reset_at': time.time() + 60})
        
        if usage['count'] >= 200:
            return False
        
        usage['count'] += 1
        cache.set(key, usage, timeout=60)
        return True
```

### 5. LSTM Prediction Cache

LSTM predictions are cached to avoid repeated model inference.

```python
# stocks/lstm_predictor.py
def predict(self, symbol: str, news_text: str = "") -> dict:
    cache_key = f"lstm:{symbol}:{hash(news_text)}"
    
    cached = cache.get(cache_key)
    if cached:
        return cached
    
    # Generate prediction
    result = self._generate_prediction(symbol, news_text)
    cache.set(cache_key, result, timeout=300)
    return result
```

### 6. Stock Price Cache

Stock prices are cached to reduce yfinance API calls.

```python
# stocks/utils.py
def get_cached_price(symbol, date):
    cache_key = f"price:{symbol}:{date.strftime('%Y%m%d')}"
    return cache.get(cache_key)

def set_cached_price(symbol, date, price):
    cache_key = f"price:{symbol}:{date.strftime('%Y%m%d')}"
    cache.set(cache_key, price, timeout=60*60*24*7)  # 7 days
```

## Cache Invalidation

### Invalidation Strategies

| Strategy | Trigger | Implementation |
|----------|---------|----------------|
| **Time-based** | TTL expires | Automatic Redis expiry |
| **Write-through** | Data changes | Invalidate cache on update |
| **Pattern-based** | Related changes | Delete by key pattern |
| **Manual** | Admin action | Manual cache clearing |

### Invalidation Examples

```python
# Invalidate user cache on profile update
def update_profile(user_id, data):
    # Update database
    User.objects.filter(id=user_id).update(**data)
    
    # Invalidate cache
    cache_key = f"query:user:{user_id}"
    cache.delete(cache_key)
    
    # Invalidate preferences cache
    cache.delete(f"query:preferences:{user_id}")

# Invalidate symbol-related caches
def invalidate_symbol_cache(symbol):
    # Delete all caches related to a symbol
    cache.delete_pattern(f"*:{symbol}:*")
```

## Cache Monitoring

### Metrics Tracked

| Metric | Description | Alert Threshold |
|--------|-------------|-----------------|
| Cache Hit Rate | Percentage of requests served from cache | < 70% |
| Cache Memory Usage | Memory used by Redis | > 80% |
| Cache Eviction Rate | Keys evicted per minute | > 1000/minute |
| Cache Response Time | Time to get/set cache | > 10ms |

## Cache Performance Optimization

### Best Practices

| Practice | Description |
|----------|-------------|
| **Use Appropriate TTL** | Short TTL for volatile data, long TTL for static data |
| **Cache Expensive Operations** | Cache API calls, database queries, ML inference |
| **Avoid Cache Storms** | Use stale-while-revalidate pattern |
| **Monitor Hit Rate** | Track and optimize cache hit rates |
| **Use Compression** | Compress large cache values |
| **Batch Operations** | Use Redis pipeline for multiple operations |

### Stale-While-Revalidate Pattern

```python
def get_data_with_stale_while_revalidate(cache_key, fetch_function, ttl=300):
    data = cache.get(cache_key)
    
    if data is not None:
        # Return stale data, refresh in background
        refresh_cache.delay(cache_key, fetch_function)
        return data
    
    # Cache miss – fetch fresh data
    data = fetch_function()
    cache.set(cache_key, data, timeout=ttl)
    return data
```

### Cache Key Design

| Key Pattern | Example | Description |
|-------------|---------|-------------|
| `{prefix}:{entity}:{identifier}` | `api:analysis:AAPL` | API response cache |
| `{prefix}:{entity}:{identifier}:{scope}` | `query:user:123:profile` | User profile cache |
| `{prefix}:{entity}:{identifier}:{params}` | `api:lstm:AAPL:news_hash` | Parameterized cache |

## Fallback Behavior

### Redis Unavailable

When Redis is unavailable, the system falls back to Django's LocMemCache.

| Scenario | Behavior |
|----------|----------|
| Redis connection failed | Use LocMemCache (in-memory) |
| Redis timeout | Use LocMemCache |
| Redis memory full | Use LocMemCache for new entries |

### Cache Miss Handling

| Scenario | Behavior |
|----------|----------|
| Cache miss | Compute fresh data and cache |
| Stale cache | Return stale data, refresh in background |
| Rate limit cache miss | Treat as first request |

## Cache Monitoring Dashboard

```python
# views/cache_metrics.py
class CacheMetricsView(APIView):
    def get(self, request):
        """Return cache performance metrics."""
        stats = {}
        
        # Redis stats
        try:
            from django.core.cache import cache
            client = cache.client.get_client()
            info = client.info()
            
            stats.update({
                'redis': {
                    'connected': True,
                    'used_memory': info.get('used_memory_human', 'N/A'),
                    'hit_rate': self._calculate_hit_rate(info),
                    'keys': info.get('db0', {}).get('keys', 0),
                }
            })
        except:
            stats['redis'] = {'connected': False}
        
        # Application cache stats
        stats['app'] = {
            'api_cache_hits': cache.get('stats:api:hits', 0),
            'api_cache_misses': cache.get('stats:api:misses', 0),
            'query_cache_hits': cache.get('stats:query:hits', 0),
            'query_cache_misses': cache.get('stats:query:misses', 0),
        }
        
        return Response(stats)
    
    def _calculate_hit_rate(self, info):
        hits = info.get('keyspace_hits', 0)
        misses = info.get('keyspace_misses', 0)
        total = hits + misses
        return round((hits / total) * 100, 1) if total > 0 else 0
```
